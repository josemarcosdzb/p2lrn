# P2LRN: permisos y alcance

La licencia base es P2LRN Non-Commercial Source License 1.0, con el Anexo A vinculante del 30 de octubre de 2026. El anexo permite leer, crear y comercializar documentos `.p2lrn`, y otorga permisos adicionales de uso educativo comercial de Player, Toolkit y lanzador. Studio y Analytics mantienen condiciones diferentes para versiones oficiales sin modificar y restricciones sobre modificación y oferta como producto/servicio comercial. El conjunto no es Open Source aprobado por OSI.

El texto legal autoritativo y avisos de terceros está en https://github.com/josemarcosfrodo/p2lrn/blob/main/LICENSE.

La Skill no incluye binarios de Toolkit, Studio, Player o Analytics; ejecuta los instalados con permiso o usa un empaquetador Python limitado.
