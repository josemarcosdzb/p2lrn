# P2LRN Security Policy

Report vulnerabilities privately using the [P2LRN contact form](https://p2lrn.org/contacto/) with the subject **Seguridad / Security vulnerability**. Describe the version, affected component, reproduction and impact. Do not include passwords, secret keys or real user data.

Please do not reveal unpatched exploits in public issues.

## Supported versions

Security fixes apply to current maintained source and published releases. An update to GitHub does not repair earlier npm packages, installed Windows file associations or copies of the CDN hosted elsewhere.

## Scope

Toolkit, Player, Studio, Windows Reader integration, imported packages, CDN and contact endpoint. Imported content is untrusted and must run with minimal permissions.

## Disclosure

Reports are evaluated for security impact and coordinated remediation. Avoid testing vulnerabilities on systems you do not own or have permission to assess.
