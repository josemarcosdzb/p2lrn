DELIVERY WITHOUT LMS

Self-running offline delivery

Includes this course and the Player. The learner opens it in his browser and returns a file .p2lrn-result. See how it works.

Authorship and provenance. Delivery is only generated if the course has Author and Rights holder informed in their authorship data. These data and “Who delivers this course” are shown to the learner before starting.

Delivery security. The learner should open the file only if they know the teacher, center or organization that sent it to them and expected to receive that course. If Windows displays a source warning, you should not ignore it when faced with a file of unknown origin. Delivery can register openings and apply a local expiration from the first opening. In completely offline mode these measures reduce casual reuse, but cannot absolutely prevent someone from keeping or copying the file before opening it for the first time.

Signed delivery generated. Save the teacher's receipt before sending the file to the learner. Without it you will not be able to match his signature.
