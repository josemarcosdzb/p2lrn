PRACTICAL EXAMPLE

Create an educational course with AI and verify the actual file

Suppose you need a digital safety course for beginners. Ask the assistant to prepare two units, four lessons, review questions and an activity matching related concepts. Specify the level, objectives and language before requesting the package.

An AI-generated text reply is not a downloadable course. The .p2lrn file must be generated with authorized execution tools and pass Toolkit validation. If the assistant lacks those tools, it can prepare a draft but must not claim to have created a package.

Before delivering the course, check content accuracy, image licensing, quiz results and accessibility. Open the file in Studio and try it on Player. To work with courses already on your computer, use the conector MCP autorizadorather than a Skill for creating a new course.

P2LRN Skills FAQ

Can I create free educational courses with AI?

The included generator does not require a P2LRN payment API, but the ability to run tools depends on the wizard you use. Please check the P2LRN license conditions before redistributing.

Does the Skill include executable 3D games?

It may describe supported activities in the package, but it does not by itself prove 3D rendering. For this verification, use the official Player.

Are ZIPs published in official catalogues?

They are offered for download and installation. Approval in each provider's boards is an independent process.
