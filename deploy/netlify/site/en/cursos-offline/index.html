SHARE / NO LMS

Create offline courses to share without installing an LMS

With P2LRN you can prepare a self-reproducing delivery that includes the course and the Player. The learner opens the delivery on their device, performs the activities in the browser and returns a results file when finished.

Prepare course in StudioRead delivery instructions

A FLOW FROM BEGINNING TO END

From a Studio course to a learner delivery

  1. 01

    Prepare the content

    Create or open the course in Studio. Check lessons, quizzes and learner view.

  2. 02

    Identify and configure delivery

    Studio requires author, rights holder and who delivers the course. Then you can generate an EXE for 64-bit Windows or a portable ZIP and set attempts, available time and, if you need it, expiration from the first opening.

  3. 03

    The learner works in their browser

    Open the delivery only if you recognize the teacher, center or organization that sent it to you. The course is taken locally in the browser without enrolling in an LMS.

  4. 04

    Receive the results

    The learner returns a .p2lrn-result file that you can open directly in P2LRN Analytics or review in Studio.

VERIFIED CAPABILITIES

What changes compared to an LMS

No course server

Self-reproducing delivery can run on the learner's computer without first deploying an academic platform.

View options →

Reusable package

The course still uses the .p2lrn format. The delivery incorporates around the playback environment.

See format →

Portable results

The learner returns a .p2lrn-result with the available activity, openings and registered sessions. The teacher can analyze it in Analytics or review it in Studio; Offline scores remain informative until confirmed by an authorized source.

Review a delivery →

Expiration from first opening

The teacher can set, for example, 30 days from the first use. In Windows, the delivery retains that state on the same computer and blocks new openings when it expires.

OFFLINE OPERATION

Does a learner need internet access to take the course?

Not for content included in a compatible offline delivery. If the course depends on externally hosted videos, outside pages or remote services, those resources will require connectivity.

COMMON QUESTION

Is an exam app tamper-proof?

No. On a learner-controlled computer, offline delivery alone cannot guarantee a tamper-resistant exam environment. It is a way to distribute and run the course without LMS.
