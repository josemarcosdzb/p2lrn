REFERENCE / GLOSSARY

Glossary

Use this glossary to understand terms used across the guides. Technical format names are preserved, with each component's responsibilities explained.

Package and structure

package

portable file .p2lrn that delivers structure, content, profiles and integrity data.

Manifest / manifiesto

Document that identifies the package and declares profiles, entrypoints and integrity.

Graph / grafo

Course structure, units, activities, resources and relationships.

Entrypoint

Entity from which the Player can start a playback.

Representation / representation

Concrete form in which a resource is available to be delivered.

contentRoot

Integrity root derived from the normalized description of the content.

Authorship

Workspace

Authored editable project that preserves materials and settings needed to rebuild a package.

Profile / perfil

Additional contract that adds semantics or capabilities to the base format.

Reader

Tool that extracts structure and content from documents so that an application decides how to incorporate them into the course.

Multipart

Transport that replaces a large resource with a descriptor and several verified parts.

Reproduction

Player

Component that opens, verifies, and plays a package.

Renderer

Implementation that converts a compatible representation into an interface for the learner.

Runtime / execution environment

Additional environment or logic that requires certain content to run.

Preserve

The ability to preserve an artifact within a stream without claiming that P2LRN can interpret or reproduce it.

Deliver

Ability to deliver or play content using a supported real-world environment.

Integration

Host/platform

Application that integrates Player or Studio and has users, permissions, persistence and secrets.

Host Adapter

Five-operation contract for status, scoring, events, and protected resources.

Capability Broker

Deny-by-default broker that connects semantic capabilities of the course with providers configured by the Host.

Offline Host Adapter

Host Adapter wrapper with local state and outbox; It does not save history within the package.

Package Cache

Opt-in store of full bytes of already verified courses; separate from the learner's status.

Resource Library

Library content-addressed by SHA-256; the bytes remain after a verified resolver.

Learning event

Sorted/categorized projection of a runtime event with optional session/attempt.

Authoritative Host

A server-side service that authorizes identities, resolves conflicts and confirms official grades; it can deduplicate offlineDeliveryId.

LTI provider

Self-hosted service that translates OIDC/JWT, Deep Linking and AGS from the LMS to authorized P2LRN sessions.

Verified resource

Object whose delivery was authorized and whose integrity was verified according to the Host contract.

Useful relationships

Workspace → package: the workspace is edited; the package is published. Representation → renderer: the representation describes how the resource is available; the renderer decides how to display a compatible representation. Player → Host Adapter: the Player plays; Host Adapter communicates that playback with your platform.
