TEACHERS / COLLABORATIVE ACTIVITIES

Create polls and collaborative activities in Studio

Prepare a live poll, shared board or peer review using the course editor. For several learners to participate together, your institution must enable collaboration in its learning platform.

1. Choose what learners will do

Live poll

Ask a question and provide choices. Learners can vote when your learning platform has the collaboration service enabled.

Shared board

Set a topic so that the class can post notes and read contributions from other learners.

Peer review

Ask learners to submit their own work and comment on contributions from their classmates.

2. Create the activity with Studio controls

  1. Open Studio and select the lesson where you want the activity.
  2. On the Insert tab, select Add content. Under Collaboration, choose Live poll, Shared board or Peer review.
  3. Select the new activity in the course tree and write the question or instructions. For a poll, review the choices and whether learners may change their vote or see results.
  4. Use Learner preview to review instructions, controls and messages. Also test the individual experience when no collaboration service is connected.
  5. Save your work, export the .p2lrn file and open that file in the Viewer before sharing it.

3. Classroom example: choosing a project

Ask “Which topic should we explore this week?” and offer “Solar energy”, “Recycling” and “Water conservation”. Enter those choices in Studio and check that they remain legible on mobile. A poll collects preferences; it is not a quiz with right and wrong answers.

4. What learner preview can verify

Learner preview checks the activity layout and individual interaction. It does not prove that two learners can share a room. To test live collaboration, the institution must open the activity with two authorized learner sessions and verify that votes, notes or comments are exchanged.

If collaboration is not connected yet

Player may offer individual participation when the collaboration service is optional. Group contributions are not stored or synchronized without an authorized service. For an assessable activity without live collaboration, use quizzes and games.

5. Technical setup belongs elsewhere

Teachers do not need to write code or configure servers. Session identity, room permissions and shared storage are documented separately for developers.
