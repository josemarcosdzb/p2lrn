TEACHERS / COLLABORATIVE ACTIVITIES

Create polls and collaborative activities in Studio

Prepare a live poll, shared board or peer review using the course editor. For several learners to participate together, your institution must enable collaboration in its learning platform.

1. Choose what learners will do

Live poll

Ask a question and provide choices. Learners can vote when your learning platform has the collaboration service enabled.

Shared board

Set a topic so that the class can post notes and read contributions from other learners.

Peer review

Ask learners to submit their own work and comment on contributions from their classmates.

2. Create the activity with Studio controls

  1. Open Studio and select the lesson where you want the activity.
  2. On the Insert tab, select Add content. Under Collaboration, choose Live poll, Shared board or Peer review.
  3. Select the new activity in the course tree and write the question or instructions. For a poll, review the choices and whether learners may change their vote or see results.
  4. Use Learner preview to review instructions, controls and messages. Also test the individual experience when no collaboration service is connected.
  5. Save your work, export the .p2lrn file and open that file in the Viewer before sharing it.

Choose the activity that matches the group task below. Authoring the activity and connecting a real shared session are two different steps.

Live poll: decide as a class

Set up in Studio. Enter one clear question and its answer choices. Review the choices and any available settings for changing votes or displaying results. Do not present a poll as a graded quiz: it collects preferences rather than right answers.

Example. “What topic should we investigate?” with “Water”, “Energy” and “Recycling”. In Learner preview, check that an option can be selected and confirmation feedback is clear.

Shared-session check. With an institution-hosted room, open the same activity using two authorized learner accounts; cast two votes and verify aggregation and vote-changing rules. Without a connected Host you can only check the individual flow, not a class poll.

Shared board: build ideas together

Set up in Studio. Write a specific prompt and explain what a note should contain. For example: “Suggest one way to reduce waste at school.” Give learners guidance on how to write contributions and check text legibility in Learner preview.

Class activity. Ask learners to post one note and read classmates' ideas before discussing them. Do not assume notes will synchronize without a shared session supplied by the platform.

Shared-session check. With two authorized accounts, post a note, confirm it appears in the other session and verify that participants can withdraw their own notes according to Host permissions. Reopen the activity to check recovery of shared state when supported by the service.

Peer review: submit and give feedback

Set up in Studio. Define what learners should submit and two or three clear feedback criteria: clarity, evidence and one suggested improvement. Example: “Describe a renewable energy source and comment on one benefit and one limitation in a classmate's work.”

Learner journey. One participant submits a contribution; a second authorized participant reads it and adds a review. Check the instructions and submission messages so both learners know the next step.

Shared-session check. Test the exchange with two authorized identities, access rights for contributions and visibility of comments. The activity does not by itself assign peer pairs, official grades or institutional identities: those rules depend on the Host and course settings.

3. Classroom example: choosing a project

Ask “Which topic should we explore this week?” and offer “Solar energy”, “Recycling” and “Water conservation”. Enter those choices in Studio and check that they remain legible on mobile. A poll collects preferences; it is not a quiz with right and wrong answers.

4. What learner preview can verify

Learner preview checks the activity layout and individual interaction. It does not prove that two learners can share a room. To test live collaboration, the institution must open the activity with two authorized learner sessions and verify that votes, notes or comments are exchanged.

If collaboration is not connected yet

Player may offer individual participation when the collaboration service is optional. Group contributions are not stored or synchronized without an authorized service. For an assessable activity without live collaboration, use quizzes and games.

5. Technical setup belongs elsewhere

Teachers do not need to write code or configure servers. Session identity, room permissions and shared storage are documented separately for developers.
