ANALYTICS / CDN

Analytics via CDN

Display results for the current course without requiring a Host endpoint.

1. Load the component

Load the Analytics browser bundle once, then add its element to your page. The course-id attribute identifies the current course; it does not fetch the course package.

HTML
<script src="https://p2lrn.org/analytics/current/dist/p2lrn-analytics.js"></script>
<p2lrn-analytics id="analytics-course" course-id="current-course"></p2lrn-analytics>
<script>
  // Provide validated results for the opened course, supplied by Player
  // or imported .p2lrn-result files.
  document.querySelector('#analytics-course').data = courseResults;
</script>

2. Connect results for the current course

Player or your authorized application supplies the learner activity and results for that course. Imported .p2lrn-result files can also provide offline evidence. The variable courseResults in the example is a placeholder for validated data, not an included JavaScript variable.

To open the .p2lrn course itself, use Player. A direct package path is not a supported Analytics src: that property expects metrics JSON.

3. Open and inspect Analytics

Use the Analytics dashboard to inspect course progress, attempts and available results. You can import supported offline result files from its interface. Official grades must come from an authorized source.

4. Advanced integration: authorized API

Only when your platform manages centralized learner records, authentication or authoritative grades should you configure a protected metrics endpoint. The URL must return the Analytics dataset as JSON, enforce per-user access and never expose private learner data publicly.

HTML
<p2lrn-analytics src="/api/p2lrn/analytics/snapshot"></p2lrn-analytics>

See the full Analytics guide for the dataset contract, datasource API, permissions and grading rules.
