ANALYTICS / CDN

Analytics via CDN

Display results for the current course without requiring a Host endpoint.

1. Load Analytics from CDN

Analytics reads a .p2lrn-result file directly from the URL given in src. This URL points to the result file, not the .p2lrn course package. There is no database and no obligatory API endpoint.

HTML
<script src="https://p2lrn.org/analytics/current/dist/p2lrn-analytics.js"></script>
<p2lrn-analytics id="panel.analytics" src="/resultados/ana.p2lrn-result"></p2lrn-analytics>

2. View results from multiple learners

Host the results as ordinary files and create a static index listing them. Every result is SHA-256 checked before appearing in Analytics. Importing multiple local files or selecting a local folder also works directly from the dashboard.

index.p2lrn-results.json
{
  "schema": "https://p2lrn.org/schema/analytics-results-index/1",
  "results": ["ana.p2lrn-result", "luis.p2lrn-result"]
}
HTML
<p2lrn-analytics id="panel.analytics" src="/resultados/index.p2lrn-results.json"></p2lrn-analytics>

The index is a list of paths, not a database. When using URLs, the files must be accessible to the browser and access must be restricted by the host if they contain private learner information. Do not publish them on a public CDN.

3. Identify each learner: two options

Option A — signed-in learner on a platform

When using a website or LMS with authenticated users, the host supplies an issuer and its real user identifier. The identity is part of the generated .p2lrn-result; Analytics groups attempts by those fields.

JavaScript
// Provided by your platform AFTER authenticating the user.
const identity = {
  mode: 'platform',
  issuer: session.issuer,
  subjectId: session.userId,
  label: session.displayName
};

Option B — teacher-assigned code, without a platform

Give each learner a different code. They enter that code when starting the offline delivery. The generated result includes the code and Analytics associates their attempts, without requiring accounts.

JavaScript
const identity = {
  mode: 'code',
  issuer: 'my-school',
  code: 'ALU-007', // Individual code assigned by the teacher
  label: 'Ana'
};

Security: SHA-256 detects altered result files; it does not prove a learner's real identity. A typed code is not authentication, and declaring a platform identity in JavaScript does not by itself verify it. Only the authorized host can attest a login or an official grade.

4. How to generate a result on the web

Player exposes result capture for both identities. Configure it before the learner interacts, and download or save the result when the attempt finishes. It is never silently uploaded.

JavaScript
import {mountP2LRN} from '@p2lrn/player';
const player = await mountP2LRN('#reproductor', {
  src: '/cursos/curso.p2lrn',
  resultIdentity: identity
});
// After the learner finishes, from a user action:
document.getElementById('descargar').addEventListener('click', () => {
  player.resultRecorder.download('resultado.p2lrn-result');
});

With the browser CDN loader, player.startResultCapture({identity}) exposes the same functionality. In offline deliveries the .p2lrn-result is generated when the learner finishes.
