Analytics with NPM

Read learner results directly from .p2lrn-result files, with no required database or analytics API. Generate results with Player and associate them with an authenticated account or teacher-assigned code.

1. Install the NPM packages

Install the Player and Analytics packages using matching versions. Both implement the same .p2lrn-result result contract.

Terminal
npm install @p2lrn/player@0.5.0-alpha.12 @p2lrn/analytics@0.5.0-alpha.12

2. Load results via src

With src, Analytics reads a .p2lrn-result file, not a course package. Each result is SHA-256 checked and converted automatically into Analytics metrics. No custom converter or backend is required.

JavaScript / TypeScript
import '@p2lrn/analytics';
// HTML: <p2lrn-analytics id="panel.analytics"></p2lrn-analytics>
const panel = document.getElementById('panel.analytics');
panel.src = '/resultados/ana.p2lrn-result';

3. Read several learners without a database

Put the result files in a protected static folder and add a small JSON index. The browser reads those files; it does not read a remote folder automatically. You can also import multiple local files directly in Analytics.

index.p2lrn-results.json
{
  "schema": "https://p2lrn.org/schema/analytics-results-index/1",
  "results": ["ana.p2lrn-result", "luis.p2lrn-result"]
}
JavaScript / TypeScript
import '@p2lrn/analytics';
import {loadAnalyticsResultSource} from '@p2lrn/analytics/results';
// Reads a SHA-256-verified result or index, without manual conversion.
const dataset = await loadAnalyticsResultSource('/resultados/index.p2lrn-results.json');
document.getElementById('panel.analytics').data = dataset;

Private data: make result URLs available only to authorized users. Static hosting without access restrictions is not suitable for personal learner data.

4. Generate a result: teacher code

Without accounts, give each learner a different code, ideally scoped to your school. Configure result capture before the learner interacts. At the end, call download from a user-initiated action to save the file.

JavaScript / TypeScript
import {mountP2LRN} from '@p2lrn/player';
const player = await mountP2LRN('#player', {
  src: '/cursos/curso.p2lrn',
  resultIdentity: {
    mode: 'code',
    issuer: 'centro-educativo',
    code: codigoIndividualAsignado,
    label: nombreAlumno
  }
});
document.getElementById('download-result').addEventListener('click', () =>
  player.resultRecorder.download('alumno.p2lrn-result')
);

The code links attempts but does not authenticate the student. The downloadable file is not automatically transferred to the teacher.

5. Generate a result: authenticated platform

If an LMS or website has authenticated the learner, provide its trusted issuer and subject identifier. Do not read these values from a user-editable input field.

JavaScript / TypeScript
const player = await mountP2LRN('#player', {
  src: '/cursos/curso.p2lrn',
  resultIdentity: {
    mode: 'platform',
    issuer: sesionAutenticada.issuer,
    subjectId: sesionAutenticada.userId,
    label: sesionAutenticada.nombre
  }
});

A SHA-256 digest protects result integrity, not the identity claim. Official grades require confirmation by the authorized platform.

6. Advanced integration (optional)

For institutions that already provide authenticated metrics datasets, src can still address an authorized JSON dataset API, or you can set panel.data/panel.dataSource. This is an optional advanced integration, not part of the basic result-file workflow.
