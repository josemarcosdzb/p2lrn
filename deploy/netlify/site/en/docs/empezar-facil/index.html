GET STARTED / VISUAL EDITOR

Create your first course in Studio

Use the visual interface to build a lesson, add an activity and preview the learner experience. You do not need to write HTML, install a developer tool or prepare a server to follow this course-creation guide.

Your first course, step by step

Start with a short lesson and one quiz question. You can expand the course after checking how it appears to learners.

  1. Open Studio. Create a new course and enter a title.
  2. Add a lesson. Use the course tree to create a unit or lesson, then type the explanation in the editor.
  3. Insert a question. Open "Add content" and choose a quiz or another activity. Enter the question, answer choices and correct solution.
  4. Check the learner view. Answer the question yourself, confirm the feedback and return to the editor if anything needs fixing.
  5. Save and export. Save your work, export the course as a .p2lrn file and open it in the viewer to check the file you will share.

For developers: embed a course in a website

These optional instructions use HTML, a CDN script and a local HTTP server to embed Player in another application. They are not required to create courses with the visual editor.

Show the technical HTML and local server walkthrough

1. Download an example package

Save the example to a working folder. The rest of this guide assumes that the file is called scorm12-browser-demo.p2lrn.

Download example packageOpen the example in the viewer

2. Create an HTML page

Save this file as index.html in the same folder as the package. The script loads Player from the CDN and the <p2lrn-player> element opens the course from the same folder.

index.html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>P2LRN</title>
  <script src="__P2LRN_PINNED_PLAYER_URL__" integrity="__P2LRN_PINNED_PLAYER_SRI__" crossorigin="anonymous" referrerpolicy="no-referrer"></script>
</head>
<body>
  <p2lrn-player src="./scorm12-browser-demo.p2lrn"></p2lrn-player>
</body>
</html>

3. Open the folder in your editor and serve it over HTTP

Open the example folder in your usual text or code editor. So that the browser can load the package and its resources correctly, open the page from a local HTTP server instead of opening index.html directly using file://.

  1. Locate index.html and confirm that scorm12-browser-demo.p2lrn is in the same folder.
  2. Use your editor's preview or local server option, or any static HTTP server you prefer.
  3. Open the local address provided by that server in your browser, usually based on localhost or 127.0.0.1.

You do not need a specific editor or extension; the important thing is to serve the folder over HTTP.

4. Check the result

The page should display the quiz within the Player. If it appears, you have already checked the essential path: loading the component, opening a package and running its contents from a web application.

What have you integrated?

The Player has been loaded from CDN; the course remains a separate .p2lrn file. From here you can decide how you want to maintain that integration in your project.

5. Continue with the installation

The next step is Installation. The documentation first introduces CDN—the natural continuation of this example—and then NPM for projects that manage their dependencies through packages.
