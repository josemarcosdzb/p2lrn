Create your first course in Studio

Use the visual interface to build a lesson, add an activity and preview the learner experience. You will work in the editor using its authoring tools and learner preview.

Your first course, step by step

Start with a short lesson and one quiz question. You can expand the course after checking how it appears to learners.

  1. Open Studio. Create a new course and enter a title.
  2. Add a lesson. Use the course tree to create a unit or lesson, then type the explanation in the editor.
  3. Insert a question. Open "Add content" and choose a quiz or another activity. Enter the question, answer choices and correct solution.
  4. Check the learner view. Answer the question yourself, confirm the feedback and return to the editor if anything needs fixing.
  5. Save and export. Save your work, export the course as a .p2lrn file and open it in the viewer to check the file you will share.

No programming is required to create a course: use Studio and test Learner preview. Embedding Player in your own website is a separate workflow for developers.

HTML example for developers

Use a text or code editor to create index.html and serve it from a local HTTP server. Do not open it via file://, because Player must load the course and its resources from a web origin.

Put the course beside the page or at an accessible URL. See the developer guide for pinned versions, integrity and authorization.

Review learner results with Analytics

Once the course works in Learner preview, use an authorized delivery or Host record to review a learner's work. The public Analytics example contains sample data, not real student records.

  1. Build the course in Studio, then complete its activities in Player to check their presentation.
  2. For offline work, collect the learner's .p2lrn-result and confirm which course and assignment it belongs to.
  3. Choose Open result in Analytics. Inspect progress, attempts and available scores.
  4. Keep informative scores distinct from official grades; only an authorized LMS or Host can supply the latter.

Continue with Analytics for teachers and the offline delivery guide.
