Integrations Status

The MCP connector provides reading, validation, and controlled creation/editing of drafts; The P2LRN Skill can create packages in supported environments. The LTI 1.3 self-hosted provider already implements OIDC/JWT, JWKS, catalog, Deep Linking, Player, persistence and AGS.

Some capabilities depend on the environment where they are deployed: AI connector authentication, optional LTI services, and support for specific versions of Moodle, Canvas, Sakai, Chamilo, or Open edX. Each guide indicates the requirements and limits that must be checked before a real implementation.
