Install and use P2LRN Skills

Download the appropriate Skill for ChatGPT, Codex, Claude, Gemini or Grok Build and generate educational courses .p2lrn from a conversation. This guide explains the installation, its requirements, and what to check before submitting the file.

See all five downloadsVerify SHA-256

What the Skill does and what it doesn't

“P2LRN – Create and Download” uses the official Toolkit when installed and authorized, to create, import, edit and validate courses; when missing Node retains a limited standalone Python generator for new courses within the contract P2LRN Core 0.4.0. It allows you to structure units and lessons, create quizzes, true/false questions with various statements, games and authorship metadata, and deliver a file .p2lrn real.

Requirements: Node 22+ and Toolkit 0.5.0-alpha.12 for official authoring; Python 3.10+ for limited packager only. File access and execute permission required. If the platform does not support running code, you can write content, but you should not claim to have created the package.

The Skill does not replace Studio, the visual execution of the Player, the 3D games of the official engine nor the entregas Windows autoejecutables. To consult real courses from an authorized folder, use the P2LRN MCP separately.

ChatGPT: download and installation

Download Skill for ChatGPT (.zip)
  1. Download the ZIP type Skills only with the manifesto plugin.json and the folder skills/p2lrn-creator/.
  2. Import the Skill into a ChatGPT space that supports it. For a public distribution of the plugin, the owner must submit it for review by OpenAI; Downloading it does not constitute approval.
  3. It requests a full course and requires the generator to be run and verified before delivering the file.

OpenAI Publishing Portal. Access and review process depend on account permissions.

Codex: project Skill installation

Download Skill for Codex (.zip)
  1. Extract the ZIP under .agents/skills/p2lrn-creator/ inside the project. Verify that SKILL.md and the scripts are present.
  2. Confirm Codex can discover the Skill and that your environment authorizes local file operations. Installation never grants unrestricted execution.
  3. Use the official Toolkit and verify the generated .p2lrn before playback. Creating a document alone does not certify execution.

This ZIP is separate from the ChatGPT plugin. Use the package matching the platform.

Claude: Custom Skill and Claude Code

Download Skill for Claude (.zip)
  1. The ZIP contains the folder p2lrn-creator/ with SKILL.md, scripts and references.
  2. Import it into Claude's Custom Skills management when your plan has that option; for Claude Code, place the folder in the Skills location that supports your installation.
  3. Trigger Python execution and verify that the wizard can save and return the .p2lrn.

A Skill installed on your account or computer is not automatically published to a global directory.

Gemini: web interface and Gemini CLI

Download Skill for Gemini (.zip)

The ZIP includes SKILL.md at the root. In Gemini web, the option to import Skills may be account-dependent and does not guarantee Python execution. For Gemini CLI, extract those files into your Skill folder:

Gemini CLI project path
.gemini/skills/p2lrn-creator/SKILL.md
.gemini/skills/p2lrn-creator/scripts/p2lrn_package.py

Check detection with gemini skills list and run the Skill's Python tests in the appropriate directory.

Grok Build: install in a project

Download Skill for Grok Build (.zip)
  1. Extract the ZIP to the root of the project that you will use with Grok Build.
  2. Confirm that it exists .grok/skills/p2lrn-creator/SKILL.md and that the Python files are in the subfolder scripts/.
  3. Use the Client Skills inspection options to verify that it is detected and allows Python to run.

Grok web no es Grok Build. It is not guaranteed that the website will import this ZIP directly or distribute it publicly.

Generate presentations directly in P2LRN courses

All five AI Skills include the same scripts and instructions: references/presentations.md, a sample slide deck, and optional PPTX/PDF export tools. Create a real course using python scripts/p2lrn_presentations.py build --input assets/presentacion-curso.json --output slides-course.p2lrn. Native PowerPoint export requires PptxGenJS and PDF export requires ReportLab, installed separately with permission; neither is silently bundled. Edit slides in Studio with Insert > Presentation.

Verify the ZIP and generate a sample course

Before installing, compare the SHA-256 of the downloaded ZIP with the download manifest. All five packages are rebuilt from the same versioned sources, but have different folder structures.

Try Python 3.10+
python -m unittest discover -s scripts -p "test_*.py"
python scripts/p2lrn_package.py build --input assets/example-course.json --output test-course.p2lrn
python scripts/p2lrn_package.py verify test-course.p2lrn

Run these commands from the folder where it is SKILL.md. In the Grok variant, enter first .grok/skills/p2lrn-creator/; in Claude's, enter p2lrn-creator/.

The output must include a package present and successful validation. Then open the course with the P2LRN viewer. Generator tests verify structure and integrity; They do not certify 3D graphic performance.

Security, rights and publication

The code is distributed under P2LRN-NCSL 1.0, a non-commercial license that should not be described as an OSI-approved Open Source license. Review the Skill files before running them and do not grant access permissions to the computer that you do not need.

The SHA-256 verification allows you to verify that the ZIP matches the one published, but it is not a digital signature of the author or an anti-fraud certification. ZIPs can be downloaded from here; publication in the official catalogs of each attendee is a separate process.
