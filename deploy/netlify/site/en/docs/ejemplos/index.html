How to use the examples

Each example can be opened in the viewer and the file .p2lrn can be downloaded to try it in another integration. Interoperability examples show formats that P2LRN can preserve or reproduce; not all involve full authorship within the editor.

Real free samples across learning formats

Technical fixtures and complete courses are different. Instructure's Canvas cartridge contains just three minimal assignment submission-type tests; its sparse text belongs to the original source. We preserve it to exercise import, not to present a full course. For a more extensive learning package, open TOPkit in Player (about 66 MiB).

Machine-readable catalog

/examples/catalog.json contains profiles, entrypoints, packageId, size and renderer when applicable. The viewer consumes it directly, without a second manually coded list.
