REFERENCE / EXAMPLES

Examples

Reference packages to open in the viewer, review structures and try the different presentations available.

How to use the examples

Each example can be opened in the viewer and the file .p2lrn can be downloaded to try it in another integration. Interoperability examples show formats that P2LRN can preserve or reproduce; not all involve full authorship within the editor.
