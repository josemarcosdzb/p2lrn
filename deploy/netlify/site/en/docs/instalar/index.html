INSTALL

Installation

Incorporate P2LRN into the project with the method that corresponds to your application. The documentation presents CDN first and then NPM; Hosted Studio is still available without local installation.

CDN

Load Player or Studio directly from published web files. It is the continuation of the journey Quick start and does not require adding packages to the project.

Continue with CDNStudio via CDN

NPM

Use published packages when your project manages dependencies and versions using NPM. Player, Studio, Toolkit and Analytics are installed depending on the function you need; @p2lrn/h5p-libraries adds the reusable catalog of H5P libraries when the content does not incorporate them by itself.

Continue with NPMStudio with NPM

Hosted Studio

If you only want to create or edit a course from the web editor, open P2LRN Studio. You do not need to prepare a local installation for that use.

Which component you need

Player

To play packages .p2lrn in the browser. Available via CDN or NPM.

Studio

To integrate the visual editor within an application. Use Player for the learner view.

Toolkit

For Authoring, Reference Host, Validation, Reader and Code Processing. It is installed using NPM.

Analytics

Embeddable panel for learners, courses, progress, activity, attempts and Host notes. Available via CDN or NPM.

H5P Libraries

@p2lrn/h5p-libraries is optional: provides shared H5P libraries when the H5P package does not carry them.
