GET STARTED / ORIENTATION

Before you start

Get to know the pieces of P2LRN and the structure of the package first. Afterwards you can do a simple first integration with CDN and then prepare the installation that you are going to maintain in your project.

1. What do you want to do

Create a course visually

You can use hosted Studio directly or integrate Studio within your application.

Create courses by code

Toolkit offers the authoring and processing API and CLI.

Play a course

Player opens and runs packages .p2lrn in the browser.

Connect progress and users

Player connects to your platform via Host Adapter when you reach the integration phase.

Submit a course without LMS

Studio can prepare an offline delivery that the learner opens with a double click and returns as .p2lrn-result.

2. Understand the model before trying it

You don't need to memorize the specification. Before creating or integrating it is enough to know what components exist, what the main concepts mean and what a package actually contains.

Component Map

Fundamental concepts

Package, manifest, graph, resource, representation, profile and renderer.

P2LRN format

What's inside the file .p2lrn, how its parts are related and what data remains outside.

3. Make a simple first integration

The most direct route to check how the Player integrates is to load it from CDN. The guide Quick start uses an example package and a small HTML so you can see the result before setting up a full installation.

Quick start with CDN

4. Then prepare your project

Once you have seen the basic integration, continue with Installation. There you have first the integration via CDN and then the installation with NPM, in addition to the specific Studio guides.

5. If you will use hosted Studio

You don't need a local installation to create content. you can open P2LRN Studio and follow directly the visual creation guide.

6. If you want to deliver it without LMS

After creating and testing the course you can generate a self-playing delivery for Windows or a portable ZIP. The guide Offline delivery explains the complete route teacher → learner → .p2lrn-result → teacher, plus security metrics and limits.

View offline delivery

7. When to read Progression and Metrics

When the course can be created, played, and integrated, the block Tracking gather Progress and Metrics and analytics. That block belongs to a later phase, when you need to define completion, approval, status, notes and reports.
