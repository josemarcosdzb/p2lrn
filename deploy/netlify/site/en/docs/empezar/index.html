Before creating your first course

Start in Studio by creating one lesson and one activity. Website installation and LMS configuration belong in the separate developer documentation.

Create and test a short course

Begin with one concept and one question. Add more content after checking the first activity as a learner.

  1. Give the course a title that identifies its topic.
  2. Add a lesson and write a clear explanation.
  3. Insert a question, enter the choices and mark the correct answer.
  4. Solve it in learner preview and review the feedback.
  5. Save the work and export the package for testing in Player.
