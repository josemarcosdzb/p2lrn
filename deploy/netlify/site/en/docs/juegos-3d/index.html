3D learning games: ordering, matching and assembly

Create activities for ordering, matching, classifying or assembling 3D objects. Check piece placement in Studio, then complete the activity in learner preview.

Create with StudioNo programming required.For developersRendering, physics, JSON and Toolkit.

Choose how learners work with objects in 3D

Ordering, matching and classification are edited with question forms. Assembly uses a separate piece-and-target editor. Start by choosing the action pupils need to practise, then open the matching mode from Add content → Games.

  1. Select the mode.Choose 3D ordering, matching, classification or assembly in the Games menu.
  2. Set the exercise.Fill in the fields shown in the relevant example below, including the correct solution or target positions.
  3. Check the actual scene.Open Learner preview, try the task and its alternative controls, then inspect the exported file in Viewer.

Match objects with their partners

In 3D matching, enter the two sides of each match, such as Spain–Madrid, France–Paris and Italy–Rome. Each pair is defined in the editing form.

How it is configured

3D scene entry frame

What the learner must do: After entering, select a blue country and its purple capital: España–Madrid, Francia–París and Italia–Roma. The image shows the boxes with the entry prompt, not the linking action or its score.

Sort objects into categories

Use 3D classification to create categories and assign a destination to each item. In this example, items belong to astronomy, geology or the hydrosphere.

How it is configured

3D scene entry frame

What the learner must do: After entering, place Luna and Cometa in Astros, Granito and Volcán in Geología, and Río and Océano in Hidrosfera. The frame shows the objects and targets with the entry prompt, not a verified classification.

Assemble pieces at their target positions

3D assembly opens its own editor. Add pieces and targets, adjust their orientation and placement zones, then inspect the assembly from the editor camera.

How it is configured

3D scene entry frame

What the learner must do: The task is to place the two parts in their corresponding target volumes. The picture shows pieces and destinations but not the dragging operation or the final attachment. Completion cannot be inferred from this image.

Accessible interaction and alternatives

The 3D scene is not the only control. Sorting, matching and classification maintain equivalent HTML controls next to the canvas. The learner can complete the same activity without depending exclusively on graphic precision or 3D pointer.
