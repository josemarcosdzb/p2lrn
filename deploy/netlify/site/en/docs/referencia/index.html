Resource library and cache

resource.library exposes only metadata search/describe/has. The bytes are resolved by digest using a verified resolver. The package cache is independent and retains complete courses after validating them.

ESM / Web SDK
const resources = P2LRN.createCacheStorageResourceLibrary();
const resolver = P2LRN.createResourceLibraryResolver({store: resources});
const cache = P2LRN.createCacheStoragePackageCache();

player.resourceResolver = resolver;
player.packageCache = cache;

Trust / Ed25519

Terminal
p2lrn-trust keygen private.pem public.pem
p2lrn-trust sign course.p2lrn private.pem
p2lrn-trust verify course.p2lrn course.p2lrn.sig --trust-key public.pem --require-trusted
p2lrn-trust inspect course.p2lrn.sig
Integrity and trust are different concepts.

SHA-256 detects changes. The Ed25519 signature verifies that the content was signed by a key; --require-trusted It also requires that that key be in the supplied set.
