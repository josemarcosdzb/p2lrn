AUTHORSHIP / STUDIO

P2LRN Studio

Studio is the visual editor to create and maintain courses .p2lrn. This guide explains the work inside the editor, from an empty course to the learner view and the final export.

STUDIO / PRACTICAL GUIDE

Learn Studio visually, one real action at a time

Each screenshot comes from the actual Studio interface. Follow the steps, open any capture at its original size and understand what the button does, when to use it and what to verify afterwards.

Open StudioOpen Player demo

BEFORE YOU START

Identify the three working areas

  1. Top toolbar — open, edit, preview and save actions.
  2. Course tree — units and lessons; select the item you are about to modify.
  3. Editing canvas — the text, resources and activities learners will encounter.

A real editor screenshot is a visual reference, not proof that every feature is deployed or fully tested.

01 / Start

Create a new course or reopen an existing one

The inspected English interface presents direct controls rather than the Spanish File dropdown.

  1. Choose New course to begin from an empty course, or Open file to continue an existing .p2lrn file.
  2. Use Open URL only when the course package is available at an address the editor can read.
  3. Verify the course title before making changes so you do not edit the wrong project.

Expected result. Opening a course does not publish or save any new work.

02 / Organize

Understand the course tree

The outline is the navigation structure for the course you are building.

  1. Create or select a unit to group related material.
  2. Create a lesson under the appropriate unit, then select it before editing.
  3. Confirm that the selected title matches the content displayed in the editing canvas.

Expected result. The screenshot shows a new course, not a completed or certified activity.

03 / Navigate

Edit, learner preview and course actions

These controls separate authoring actions from checking what learners will see.

  1. Use Edit while changing the structure or content.
  2. Use New unit, New lesson and Add content to build the course.
  3. Switch to Learner preview to inspect the Player experience, then return to editing for revisions.

Expected result. Switching to learner preview is not equivalent to saving or exporting.

04 / Add activities

Choose the right content or assessment

The picker groups supported authoring paths instead of turning every resource into the same kind of activity.

  1. Choose Content for lesson resources and supported media.
  2. Choose Assessment for questions and their answer rules; configure scoring before treating the activity as complete.
  3. Choose Games according to the interaction you need, then inspect its instructions and completion state.
  4. For Collaboration, remember that identities and shared state require a configured host.

Expected result. A visible menu option does not certify end-to-end execution across LMS platforms.

05 / Edit

Write and structure the lesson canvas

The canvas is where the lesson becomes editable learner material.

  1. Select the lesson in the tree and enter a meaningful title and explanation.
  2. Add supporting blocks and media that help learners understand the subject before attempting questions.
  3. Review the content hierarchy and confirm that the selected activity is in the intended unit.

Expected result. This screenshot captures a blank lesson ready for editing; it is not a completed lesson.

06 / Format

Formatting toolbar: readable content

Formatting should make the lesson clearer without requiring an image for every paragraph.

  1. Place the cursor or select text before applying a style.
  2. Use paragraph styles and font size to distinguish headings from explanations.
  3. Apply emphasis and alignment consistently, then check legibility on a narrower screen.

Expected result. Review the actual learner rendering before exporting.

07 / Save

Save a draft and export a .p2lrn file

Saving an editable draft is a separate task from producing a portable package.

  1. Use Save draft during editing to preserve your working state.
  2. Select Export .p2lrn when you need a portable file to open with the Player.
  3. Use Offline delivery and Review delivery only when following the respective delivery and review procedures.

Expected result. Confirm that the exported file exists; do not assume Preview itself saves anything.

08 / Check

Learner preview: verify the course journey

The Player is the place to inspect navigation and activities before a course is distributed.

  1. Open Learner preview and move through the lesson as a learner would.
  2. Check visible content, controls and instructions; try the activities included in your course.
  3. Return to Edit to fix issues, then save and export again.

Expected result. A screenshot alone does not prove persistent progress or official LMS grade submission.

TRY IT YOURSELF

From an empty course to a file you can reopen

  1. CreateOpen Studio, select New course and give the course a clear structure.
  2. BuildAdd one unit and a lesson, then write meaningful text and insert a resource.
  3. AssessAdd an assessment or a game and define its expected responses.
  4. CheckOpen Learner preview and try the actual learning flow.
  5. DeliverReturn to editing if needed, save a draft and export the .p2lrn file.

Final check: reopen the exported file. Do not confuse a saved draft, a screenshot, a valid package and a completed LMS delivery.

1. Before you create: decide where to use Studio

EDITOR ALOJADO

Open Studio directly

You don't need to install anything. It is the shortest path to create, review and download a course.

INSIDE YOUR APP

Integrate Studio

First prepare Studio from the installation guide and then return to this page for authoring work.

The editor's functions are the same in both cases. What changes is where it runs and whether your platform provides saving, reader or import services.

2. Create or open a course

Open P2LRN Studio
Create course

Start a new course and prepare its structure to start adding units, lessons and content.

Open file

Load a .p2lrn saved to your computer and continue editing it.

Open URL

Open a package accessible via a web address to review or modify it.

Authorship and rights

When creating or editing the course you can keep the portable fields author, createdAt, license and copyrightHolder. No “IA author” field is added.

3. Organize units and lessons

The course tree shows the navigation structure. Use + Unit to create a unit and + Lesson to add a lesson at the selected position.

  1. Unit.It groups together a part of the course and may contain other units, lessons or resources.
  2. Lesson.It is the editable space to develop the content that the learner will see.
  3. Selection.Select an item in the tree to edit it or to indicate where the next item will be inserted.

4. Add content

The menu Add content separates options by type so you can choose the right activity.

Content

Editable lesson, file or multimedia, URL, shared resource by URL+SHA-256, document using Reader and external educational package.

Assessment

Flexible questionnaire with P2LRN compatible question types.

Games

Memory, relating, ordering, classifying, true/false with several statements, filling in the gaps, word search, crossword puzzle, word wheel and three 3D tours: ordering, relating and classifying.

Collaboration

Live voting, shared whiteboard and peer review. Studio declares collaboration.room automatically; the host provides identity and synchronization.

Estructuras avanzadas

Native components and activity groups for content that needs more complex organization.

Native components

Notice

Featured block for information, notes, warnings or success messages. The content remains semantic and portable; the Player applies the corresponding presentation.

Timeline

Visual sequence of milestones ordered for processes, chronologies and journeys. Each element retains its title and content without relying on executable code within the package.

Connected Resource Library

When the host assigns studio.resourceLibrary with list() and get(digest), Studio can select already verified shares. materializeSharedResource(activityId) adds an embedded fallback to the same Resource so that the course continues working without that library.

5. Edit on the canvas

When you select a supported element, Studio opens its editor in the central area. Modify the content on the canvas itself and use the controls available for that type of resource. Changes remain in the editing session until you download or save the course.

Images within a lesson

HTML lessons allow insert, paste or drag images directly to the canvas. Then you can select them, move them within the lesson, change their size with the controls − Size and + Size, delete them or adjust their position with the keyboard.

Images are part of portable content.

Studio supports PNG, JPG, GIF, WebP and AVIF up to 8 MB per image. Reject renamed SVG/HTML and keep the image within the lesson HTML so the package still works without relying on an external URL.

6. Check the learner view

Cambia a Learner preview to play the course status with the Player. This view is used to check navigation, content, activities and progression before exporting the package.

Preview is not a substitute for saving.

Return to editing to continue working and save or download the course when you want to keep your changes.

7. Save and export

Download .p2lrn

Generates the package and downloads it to your computer. Does not require a server save service.

Offline delivery

Generate a delivery for Windows or ZIP. You can limit attempts, record activity, set an expiration from the first opening, and keep a receipt from the teacher. The result can be reviewed in Studio or opened in Analytics. View offline deliveries.

Save to server

Send the package to the service configured by the platform that integrates Studio. This option only appears when a save destination exists.

Document reader

Importing documents requires a Reader service when the platform wants to offer that function.

Educational packages

Importing external formats requires a conversion service when that feature is enabled.

Saving on a server requires the security of your platform.

When integrating Studio into a website, the hosting website must protect endpoints from Save, Reader e Import with verified authentication and permissions on the server. P2LRN does not provide site accounts, roles, or authorization. View secure integration.

8. Reopen and edit a course

A downloaded package can be opened again from Open file. If your platform servers courses, you can also provide a seed URL to open the package directly in Studio.

9. Component technical reference

The component's public attributes, methods, and events are documented in Technical reference. The installation configuration is kept in its specific guides so as not to mix routes.

resourceLibrary

Optional library with list()/get() for the connected selector.

materializeSharedResource()

Convert a shared reference to an embedded fallback without creating another course format.

exportOfflineAssignment() / downloadOfflineAssignment()

Generate a self-contained delivery Windows .exe, ZIP portable o .cmd alternative, applying the configured attempts, tracking and expiration policy.

reviewOfflineResult(file)

Check the return .p2lrn-result, including openings, sessions, activity and available incidents. From the review you can open the result in Analytics.
