P2LRN Studio

Studio is the visual editor to create and maintain courses .p2lrn. This guide explains the work inside the editor, from an empty course to the learner view and the final export.

Learn to use Studio, step by step

01 / Start

Create a new course or reopen an existing one

The inspected English interface presents direct controls rather than the Spanish File dropdown.

  1. Choose New course to begin from an empty course, or Open file to continue an existing .p2lrn file.
  2. Use Open URL only when the course package is available at an address the editor can read.
  3. Verify the course title before making changes so you do not edit the wrong project.
  4. For large courses, use File → Split package (multipart). Choose a part size from 1 to 64 MiB (25 MiB by default), generate the multipart ZIP and keep the .p2lrn and .partNNN files together. See the actual controls and delivery steps below.

Expected result. Opening a course does not publish or save any new work.

Export a course in multipart files

Real screenshots of Studio multipart controls

Open File → Split package (multipart)…. The Part size (MiB) field accepts whole numbers from 1 to 64, starting at 25. Select Generate multipart ZIP to download the outer course and all its parts.

Extract and host the .p2lrn and all .partNNN files together over HTTP(S). Parts are not standalone unit courses. Read packaging limits and publishing instructions.

02 / Organize

Understand the course tree

The outline is the navigation structure for the course you are building.

  1. Create or select a unit to group related material.
  2. Create a lesson under the appropriate unit, then select it before editing.
  3. Confirm that the selected title matches the content displayed in the editing canvas.

Expected result. The screenshot shows a new course, not a completed or certified activity.

03 / Navigate

Edit, learner preview and course actions

These controls separate authoring actions from checking what learners will see.

  1. Use Edit while changing the structure or content.
  2. Use New unit, New lesson and Add content to build the course.
  3. Switch to Learner preview to inspect the Player experience, then return to editing for revisions.

Expected result. Switching to learner preview is not equivalent to saving or exporting.

04 / Insert

Insert tools, one control at a time

Use Insert within the selected lesson. Use Add content to create an activity or resource. These labels illustrate the editor controls; they are not clickable.

Create pages and add files

New unit groups lessons, New lesson adds a page, Image and Video insert materials, and Add content opens the activity chooser.

Arrange the lesson

Separate a topic into sections, place materials side by side, emphasize a key idea and add structured or movable elements.

Add interaction

Reveal supporting content and prepare drag targets; test the resulting interaction in learner preview.

How to prepare content and advanced options

These options use the existing Studio editor. Read each practical explanation and test the learner experience before sharing.

URL

Enter the external website or tool and explain what learners should do there. The link is not bundled into the course: check access rights, accessibility and how it opens in Learner preview.

Shared resource

Select an existing resource when several lessons need the same file. Avoid duplicate uploads and confirm all references can still open after saving and exporting.

Shared library

If your institution has connected a library, choose authorized content and check permissions. Otherwise use approved local materials. Do not embed institutional credentials in the course.

Reader and documents

Import the file and check the resulting headings, images, tables, text and questions. Conversion varies by format and available service; a successful upload alone does not prove an accurate conversion.

Educational package

Check the importer before adding SCORM, H5P or another package and keep the original. Test navigation, activities and results in Player; profiles and external resources have different limitations.

Component

Add a native block such as a Notice or Timeline within the selected lesson, enter the content and check reading order in Learner preview. A component does not replace units or lessons.

Activity group

Group related tasks and check their order in the editor and Learner preview. A group alone does not establish progress, grading or unlock rules: review those separately.

Also read format compatibility for imports and progression rules for advanced learning sequences.

Some options require the services configured by your institution. Open the course in Learner preview to check the activity before sharing it.

05 / Arrange

Move and resize objects on the lesson canvas

A lesson is editable, not a fixed image. This video shows a real shape being added, dragged to a new position and resized using Studio's object controls.

  1. Select the lesson in the course tree. In the editor shown in this Spanish-language video, open Insert and choose Shape. If your editor has a different toolbar, use its shape tool.
  2. Select the new object and drag its Move control to reposition it without dragging the text inside.
  3. Use the corner resize handle to change its width and height. The object remains editable.
  4. Apply the same approach to compatible text boxes, tables and layout blocks; some media have their own move and size controls. Check the final layout in Learner preview and save your changes.

Check: the object has changed position and size in the editor. Moving an object does not automatically change the correct answer of a game or save the course.

06 / Format

Formatting toolbar: readable content

Formatting should make the lesson clearer without requiring an image for every paragraph.

  1. Place the cursor or select text before applying a style.
  2. Use paragraph styles and font size to distinguish headings from explanations.
  3. Apply emphasis and alignment consistently, then check legibility on a narrower screen.

Expected result. Review the actual learner rendering before exporting.

07 / Save

Save a draft and export a .p2lrn file

Saving an editable draft is a separate task from producing a portable package.

  1. Use Save draft during editing to preserve your working state.
  2. Select Export .p2lrn when you need a portable file to open with the Player.
  3. Use Offline delivery and Review delivery only when following the respective delivery and review procedures.

Expected result. Confirm that the exported file exists; do not assume Preview itself saves anything.

08 / Check

Learner preview: verify the course journey

The Player is the place to inspect navigation and activities before a course is distributed.

  1. Open Learner preview and move through the lesson as a learner would.
  2. Check visible content, controls and instructions; try the activities included in your course.
  3. Return to Edit to fix issues, then save and export again.

Expected result. A screenshot alone does not prove persistent progress or official LMS grade submission.

PRACTICAL EXERCISE

Create, arrange, test and reopen a course

Follow this complete example in the actual editor, rather than only reading the menu descriptions.

  1. Create a courseOpen Studio, choose New course and give your first unit and lesson meaningful titles.
  2. Build the lessonWrite an explanation and insert a text box or shape from the Insert tab.
  3. Arrange the objectsSelect the shape, drag Move, resize it with the corner handle and check the layout.
  4. Add an activityOpen Add content, choose a quiz or game, provide the questions and define the correct answers.
  5. Try the learner viewSwitch to Learner preview, complete the activity and correct any issue in Edit mode.
  6. Save and reopenSave a draft for work in progress, download a .p2lrn package, then reopen that file to verify it.

Need a self-running delivery? That is a separate procedure: see Offline delivery setup.

Before sharing your course, use Learner preview to try every activity you added. Save, export the .p2lrn file and reopen it. If you use a learning platform, also check progress and grades inside that platform.

Practical steps to prepare, review and keep your course

These steps complement the editor screenshots and show how to continue building your course, from the first lesson through to saving and sharing it.

Where to start

Open P2LRN Studio to make a course on the web. If your institution offers Studio within its own learning platform, follow the link it provides. Available controls can vary between versions and installations.

Create a course or continue an existing one

Choose New course to start, or Open file to edit a saved .p2lrn course. These are direct controls in the English interface shown above. Check the course title, author and rights information before sharing it.

Arrange units and lessons

Select New unit to group content and New lesson to add a learning page. Select the appropriate item in the course tree before editing or inserting more material.

Choose content, assessments and games

Open Add content and choose Content for pages and resources, Assessment for quizzes or Games for activities such as ordering, matching, fill-in-the-blanks or 3D games. Fill in the available fields, then try the exercise in Learner preview. Collaboration tools and institutional resources only appear when enabled.

See the quizzes and games guide for answers, distractors and checking results.

Add and adjust images

Insert, paste or drag an image into a lesson. Select it to access the size and placement controls available for that element. Check that the text, images and alternatives display correctly in Learner preview.

Check the learner experience

Open Learner preview and move through the lessons. Answer the questions, inspect the feedback and complete each game from start to finish. A screenshot of a 3D game menu or its opening screen does not prove completion.

Save and share

Use the available save controls or Export .p2lrn to keep your course. Save the file somewhere you can find it, then reopen it to check the result. If learners need access without an internet connection, follow the offline delivery guide and test the file you produce.

Return to editing

Use Open file to reopen the saved package. Check the course structure and changes before exporting again. Learner preview does not save your work.

When a control is missing

Check which Studio version you have open and which features are available. If you use an institutional installation, ask its administrator before assuming a feature is enabled. Installation and platform integration instructions are kept separately in the developer documentation.
