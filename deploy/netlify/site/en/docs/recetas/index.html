DEVELOPERS / RECIPES

Integration recipes for developers

Technical paths for integrating Player, Host and P2LRN components into an application. To write and organize a course using the visual editor, follow the separate Studio teacher guide.

Create content

VISUAL

Create a course with Studio

New course → units and lessons → content → learner view → download or save.

CODE

Create a package programmatically

Workspace → resources → optional progression → build → validation → Player.

DOCUMENTS

Import with Reader

Read document → review extracted structure → convert only the content you want to incorporate.

NAVIGATION

Add progression

Define required activities, completion conditions, minimum scores and prerequisites.

Play

INTEGRATE

Embed Player

Choose how to install Player, add the <p2lrn-player> element, set its src and handle the ready and error events.

ACTIVITIES

Quizzes and games

Start with a questionnaire, choose a supported activity type, test it in learner preview and open the exported course in Player.

3D

Use 3D activities

Check compatible mechanics, alternative accessibility, physics and completion behavior.

TEST

Test a package

Select an example → open it in the viewer → review loading, presentation and events.

Integrate with a platform

STATUS

Save progress

Configure Host Adapter → load status → save changes → report score → log events.

PRIVATE

Serve protected resources

Check access on your server, return a verified URL and let Player load the resource without adding secrets to the course package.

EVENTS

React to playback

Listen to public events → identify activity and context → update your app or telemetry.

MIGRATION

Evaluate an external format

Check what can be preserved, read, edited, and played before designing your migration.

Connected and offline

OFFLINE

Continue offline

Wrap the Host Adapter with createOfflineHostAdapter(), choose a storage namespace, and use createOfflineSyncController() if your application supports optional reconnection.

CACHE

Reopen the course without network

Create a package cache with createCacheStoragePackageCache(), call cachePackageURL(), then assign it to player.packageCache.

RESOURCES

Share a verified library

Store by SHA-256 → createResourceLibraryResolver() → Studio or Host Adapter selector.

LMS

Connect via LTI 1.3

Deploy the self-hosted provider → register real LMS → Deep Linking/binding → launch → AGS if applicable.

Distribute large content

If a large resource should not be contained within the main file, see Multipart. The descriptor preserves hashes and the Player reconstructs the content from the verified parts.
