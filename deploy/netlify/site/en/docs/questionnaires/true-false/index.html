QUESTIONNAIRES / PRESENTATION

True-or-false questions for classroom learning

Presents a statement and two possible answers: True or False.

Prepare the activityEditor walkthrough and examples.Technical referenceIntegration information.

Decide whether each statement is true or false

Use it for quick fact checks or binary concepts, not for questions that allow for nuance or multiple valid answers.

Write statements with an unambiguous answer

This type of activity checks specific facts. One example asks whether the Earth orbits the Sun.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → True / false (Verdadero / Falso).
  2. Write the instructionsWrite a complete statement, avoiding double negatives: 'The Earth orbits the Sun'.
  3. Set the answersSelect a single statement or multiple statements, and mark the correct answer as true or false.
  4. Review the settingsAdd more questions for a longer round and check their answers and points.
  5. Try the learner activityTry both choices in Learner preview and check that the correct answer is reflected in the result.

True/False: result screen, not the answer screen

How the learner responds: Read each statement and select Verdadero (True) or Falso (False). For example, «La Tierra gira alrededor del Sol» (Earth orbits the Sun) is True. This screenshot only shows «Ronda completada: 3/3 aciertos» (3/3 correct) and «Repetir ronda» (Repeat round). The statements and answer buttons are not pictured, so this frame does not illustrate how to answer.

Accessibility, scoring and results

Interaction and accessibility

Responses are standard buttons and work with keyboard and assistive technologies.

Completion and scores

Each choice updates the answer to the question. Upon completion of the round, the total score is communicated.

To save the result on your platform, see Events and Host Adapter.
