QUESTIONNAIRES / PRESENTATION

True-or-false questions for classroom learning

Presents a statement and two possible answers: True or False.

Prepare the activityEditor walkthrough and examples.Technical referenceIntegration information.

Decide whether each statement is true or false

Use it for quick fact checks or binary concepts, not for questions that allow for nuance or multiple valid answers.

Write statements with an unambiguous answer

This type of activity checks specific facts. One example asks whether the Earth orbits the Sun.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → True / false (Verdadero / Falso).
  2. Write the instructionsWrite a complete statement, avoiding double negatives: 'The Earth orbits the Sun'.
  3. Set the answersSelect a single statement or multiple statements, and mark the correct answer as true or false.
  4. Review the settingsAdd more questions for a longer round and check their answers and points.
  5. Try the learner activityTry both choices in Learner preview and check that the correct answer is reflected in the result.

True/False: result screen, not the answer screen

How the learner responds: Read each statement and select Verdadero (True) or Falso (False). For example, «La Tierra gira alrededor del Sol» (Earth orbits the Sun) is True. Interaction and accessibility

Responses are standard buttons and work with keyboard and assistive technologies.

Completion and scores

Each choice updates the answer to the question. Upon completion of the round, the total score is communicated.

Content requirements

  • In Studio it is created with questions of type True / false.
  • At least two questions are needed.
  • Each question must have exactly two unambiguous options and one embedded solution.

Valid data example

This example shows the data used by the activity for CLI authoring. In Studio, configure the corresponding content using the visual editor.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "True or false",
  "language": "en",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "true-false",
      "prompt": "Earth orbits the Sun",
      "points": 1,
      "choices": [
        {
          "id": "t1",
          "text": "True"
        },
        {
          "id": "f1",
          "text": "False"
        }
      ],
      "solution": {
        "choiceIds": [
          "t1"
        ]
      }
    },
    {
      "id": "q2",
      "type": "true-false",
      "prompt": "Mars is a star",
      "points": 1,
      "choices": [
        {
          "id": "t2",
          "text": "True"
        },
        {
          "id": "f2",
          "text": "False"
        }
      ],
      "solution": {
        "choiceIds": [
          "f2"
        ]
      }
    }
  ]
}

How to read the example

Each question has two choices. The solution points out which of your identifiers is correct using solution.choiceIds.

Create by CLI — advanced alternative

Use these commands for code-based authoring with Toolkit installed via npm. The quiz.json file must contain a valid questionnaire like the example above.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "True / False" \
  --renderer "https://p2lrn.org/renderer/questionnaire/true-false"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer Select the preferred presentation. It does not create a second copy of the questions: the content remains the native questionnaire.
