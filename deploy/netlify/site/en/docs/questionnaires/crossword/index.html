Solve a crossword from clues

Use it when the answers are short words, the clues are clear, and the set shares enough letters to form a single board.

Build the list of clues and answers

Each crossword entry starts with a clue and an answer. The words form a crossing puzzle for learners to solve.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → Crossword (Crucigrama).
  2. Write the instructionsWrite a clue, such as 'Natural satellite of the Earth'.
  3. Set the answersEnter LUNA in Accepted answers and choose Add question to include more words.
  4. Review the settingsChoose words with compatible letters and avoid excessively long or ambiguous answers.
  5. Try the learner activityCheck the crossword grid in Learner preview, making sure every clue matches its entry.

Content requirements

  • In Studio it is edited with questions of type Text answer.
  • You need between 4 and 80 responses.
  • Each standardized response must be between 3 and 17 characters and a non-empty clue.
  • All words must form a single connected crossword puzzle. If there is no complete provision, the submission is rejected.

Valid data example

This example shows the data used by the activity for CLI authoring. In Studio, configure the corresponding content using the visual editor.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Crossword",
  "language": "en",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "text",
      "prompt": "Place where people live",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "HOME"
        ]
      }
    },
    {
      "id": "q2",
      "type": "text",
      "prompt": "Amphibian that jumps",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "TOAD"
        ]
      }
    },
    {
      "id": "q3",
      "type": "text",
      "prompt": "Water bird",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "DUCK"
        ]
      }
    },
    {
      "id": "q4",
      "type": "text",
      "prompt": "Container with a handle",
      "points": 1,
      "solution": {

          "CUP"
        ]
      }
    }
  ]
}

How to read the example

The four questions provide the clues and the words HOUSE, TOAD, DUCK and CUP. They are answers compatible with the construction of the connected board.

Create by CLI — advanced alternative

Use these commands for code-based authoring with Toolkit installed via npm. The quiz.json file must contain a valid questionnaire like the example above.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Crossword" \
  --renderer "https://p2lrn.org/renderer/questionnaire/crossword"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer Select the preferred presentation. It does not create a second copy of the questions: the content remains the native questionnaire.
