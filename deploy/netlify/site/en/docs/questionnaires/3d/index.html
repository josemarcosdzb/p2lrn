3D activity: place objects and check the solution

Use it when spatial interaction adds value and there is also an accessible alternative in HTML.

Set the order of objects in the activity

The teacher enters the correct sequence in the editor. The Player presents the task in a three-dimensional learner scene.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → 3D game: ordering (Juego 3D [ordenar]).
  2. Write the instructionsWrite an instruction such as 'Order the stages of the water cycle in 3D'.
  3. Set the answersAdd Evaporación, Condensación and Precipitación under the Ordering question type, in their correct sequence.
  4. Review the settingsUse the arrows to adjust the answer order and review the point value.
  5. Try the learner activityTest the actual 3D scene and accessible alternatives; a correct list in the editor alone is not a finished learner run.

Entry screen for the 3D ordering game

How the learner responds: Select the scene to enter. The on-screen Spanish instructions mention WASD or arrow keys for movement on a computer. Accessibility, scoring and results

Interaction and accessibility

The scene is accompanied by equivalent HTML controls. The learner can complete the activity without relying exclusively on pointing or dragging 3D objects.

Completion and scores

The scene and alternate controls update the same state. Completion and scoring use the common questionnaire contract.

To save the result on your platform, see Events and Host Adapter.

Check the exported file

Open your exported .p2lrn file in the P2LRN Viewer, complete the exercise and check its instructions, feedback and result. Test the actual file you exported rather than relying on an unrelated sample.

Create and verify your own exercises in Studio. Native test courses are no longer published.
