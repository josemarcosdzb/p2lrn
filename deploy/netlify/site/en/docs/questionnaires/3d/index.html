Set the order of objects in the activity

The teacher enters the correct sequence in the editor. The Player presents the task in a three-dimensional learner scene.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → 3D game: ordering (Juego 3D [ordenar]).
  2. Write the instructionsWrite an instruction such as 'Order the stages of the water cycle in 3D'.
  3. Set the answersAdd Evaporación, Condensación and Precipitación under the Ordering question type, in their correct sequence.
  4. Review the settingsUse the arrows to adjust the answer order and review the point value.
  5. Try the learner activityTest the actual 3D scene and accessible alternatives; a correct list in the editor alone is not a finished learner run.

Content requirements

  • The Studio preset creates a question of type Ordering with complete solution.
  • The activity requires embedded solutions and distinguishable texts.
  • The Player can also reproduce 3D activities of type Matching and Classification when they are generated by Toolkit and fulfill their full contracts.
  • If the physics cannot be initiated, the experience preserves a functional alternative.

Valid data example

This example shows the data used by the activity for CLI authoring. In Studio, configure the corresponding content using the visual editor.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Order the water cycle",
  "language": "en",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "ordering",
      "prompt": "Order the stages",
      "points": 3,
      "items": [
        {
          "id": "i1",
          "text": "Evaporation"
        },
        {
          "id": "i2",
          "text": "Condensation"
        },
        {
          "id": "i3",
          "text": "Precipitation"
        }
      ],
      "solution": {
        "order": [
          "i1",
          "i2",
          "i3"
        ]
      }
    }
  ]
}

How to read the example

The example uses sort because it is the path that Studio currently offers to create a 3D Game. The three elements and solution.order produce a complete test.

Create by CLI — advanced alternative

Use these commands for code-based authoring with Toolkit installed via npm. The quiz.json file must contain a valid questionnaire like the example above.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "3D Game" \
  --renderer "https://p2lrn.org/renderer/questionnaire/3d-order-match"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer Select the preferred presentation. It does not create a second copy of the questions: the content remains the native questionnaire.
