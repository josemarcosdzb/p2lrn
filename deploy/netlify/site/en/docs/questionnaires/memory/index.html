QUESTIONNAIRES / PRESENTATION

Memory matching game with cards and pairs

Turn unambiguous relationships into hidden cards. The learner reveals two cards at a time and looks for the correct pairs until the board is complete.

Prepare the activityEditor walkthrough and examples.Technical referenceIntegration information.

Reveal and match pairs of cards

Use it for vocabulary, concepts and definitions or one-to-one relationships that benefit from repetition and recognition.

Build the pairs learners will uncover

In this example, pupils connect planets with clues. Each pair starts as one row in the editor and becomes two cards during the game.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → Memory (Memoria).
  2. Write the instructionsWrite a clear instruction, for example 'Find the matching planets and clues'.
  3. Set the answersFill the Element and Correct pair fields with Mercurio–closest planet to the Sun, Tierra–planet with oceans and Marte–red planet. Choose Add pair for extra cards.
  4. Review the settingsMake sure each card has one clear match and set the point value.
  5. Try the learner activityOpen Learner preview, reveal the cards and finish the round to check the correct pairings.

Memory game after all pairs have been found

How the learner responds: During a round, reveal two cards and find their relationship: Mercurio matches «Planeta más cercano al Sol» (closest planet to the Sun), and Tierra matches «Planeta con océanos líquidos» (planet with liquid oceans). Try other cards if they do not match. The screenshot shows every card revealed and a final score of 4/4; it does not show the flipping action.

Test the pairs and the finished round

Complete it in Learner preview and try the exported file in Viewer.

Accessibility, scoring and results

Interaction and accessibility

Each card is a button. The activity can be completed with keyboard; The visual condition of the cards is not the only selection indicator.

Completion and scores

When all the pairs are solved, the activity ends and the Player communicates the score.

To save the result on your platform, see Events and Host Adapter.
