QUESTIONNAIRES / PRESENTATION

Standard questionnaire

Present the questionnaire as a conventional evaluation. The learner responds with controls adapted to the type of question: options, text, order, relate, classify or fill in gaps.

FOR TEACHERS AND COURSE CREATORS

Create standard questionnaire in Studio

Create this activity using the visual editor. You do not need JSON or terminal commands.

  1. Open the course.Go to Studio and select the unit or lesson that will contain this activity.
  2. Add the activity.In Add content, open Assessment and choose Questionnaire.
  3. Enter the content.Write the questions, choose the answer type and add the options.
  4. Set the correct answer.Set the accepted answers, feedback and scoring.
  5. Check Learner preview.Play the activity before downloading or saving the course.
  6. Save and reopen.Download your .p2lrn course and check the exported file in Viewer.

Accessibility, scoring and results

Interaction and accessibility

The controls are HTML forms and have associated tags. It does not depend on dragging or a graphical scene.

Completion and scores

When you submit the assessment, the quiz updates its status and reports score and completion when the correction is available.

To save the result on your platform, see Events and Host Adapter.

Practical example: create an interactive online quiz

To assess a digital safety unit, prepare three questions about passwords, suspicious links and account protection. Add them to one Quiz activity in Studio rather than creating three separate activities.

  1. Configure the questions.Choose supported question types and check choices and solutions. Keep instructions separate for each question.
  2. Review the learner journey.Enable one question at a time if appropriate. Check that Previous and Next let learners reach every question before submitting the complete assessment.
  3. Control when feedback appears.Do not show correct answers while learners are still answering unless the teacher has explicitly enabled that behavior. Check the overall result on completion.
  4. Export and test.Download the .p2lrn and check your own course in the viewer to verify behavior on mobile and desktop.

Player scores do not automatically become official LMS grades. If you need enrollment and grades, connect identity and persistence through an authorized Host Adapter autorizado.

For developers: JSON, CLI and integration

This reference is for programmatic package creation or app integration. Teachers can create the activity directly with Studio.

Open technical examples and CLI commands

Content requirements

  • Supports native quiz question types.
  • You can use embedded solution remediation or platform-managed remediation.
  • The presentation can show one question at a time or all at once.

Valid data example

This example shows the data used by the activity for CLI authoring. In Studio, configure the corresponding content using the visual editor.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Quick check",
  "language": "en",
  "grading": {
    "mode": "embedded-key"
  },
  "presentation": {
    "questionMode": "one-at-a-time",
    "shuffleQuestions": false,
    "showFeedback": "after-submit"
  },
  "questions": [
    {
      "id": "q1",
      "type": "single-choice",
      "prompt": "Capital of Portugal",
      "points": 1,
      "choices": [
        {
          "id": "a",
          "text": "Lisbon"
        },
        {
          "id": "b",
          "text": "Madrid"
        }
      ],
      "solution": {
        "choiceIds": [
          "a"
        ]
      }
    }
  ]
}

How to read the example

The example contains a single choice question. choices defines the options and solution.choiceIds Identify the correct answer.

Create by CLI — advanced alternative

Use these commands for code-based authoring with Toolkit installed via npm. The quiz.json file must contain a valid questionnaire like the example above.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Standard questionnaire" \
  --renderer "https://p2lrn.org/renderer/questionnaire/standard"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer Select the preferred presentation. It does not create a second copy of the questions: the content remains the native questionnaire.
