PLAY / ACTIVITIES

Quizzes and games

Start from Studio if you're creating visually. Different presentations reuse the same quiz model and change the learner experience only when the content is compatible.

1. Create an activity from Studio

  1. Open the course.Go to Studio and select the unit or lesson where you want to add the activity.
  2. Add content.For a conventional evaluation use Evaluation → Questionnaire. For a specific mechanic use Games and choose Memory, Match, Sort, Classify, True/False, Fill in the Gaps, Word Search, Crossword, Word Wheel or 3D Game.
  3. Edit with visual controls.Write questions, answers and solutions in the editor. You don't need to touch JSON.
  4. Try learner View.Check the activity before saving or downloading the course.

2. The same questionnaire, different experiences

Questions are saved as application/vnd.p2lrn.questionnaire+json. The chosen presentation does not create another copy of the content: it tells the Player how to display that questionnaire.

The presentation should never miss questions.

If the entire questionnaire cannot be faithfully represented mechanically, that presentation is considered incompatible. P2LRN does not eliminate questions or invent answers to make it fit.

4. What each guide explains

Each presentation now follows the same order: what the learner sees, how to create it in Studio, content requirements, a complete and valid data example, CLI alternative, technical identifier, accessibility, completion, and a test in the viewer.

5. Status and score

All submissions update the same questionnaire status. To hear punctuation and completion use Events; To persist them on a platform, configure Host Adapter.

A questionnaire, several questions and correction at the end

To evaluate multiple questions together, create them within the same activity Quiz in Studio with “Add question”. The “One question at a time” mode offers Previous and Next until the last question, where the set is delivered. Creating activities independent of a question produces independent deliverables and results.

In new courses and games, learner-visible autocorrect is initially disabled. The teacher can expressly select “Show autocorrection only upon completion.” Until delivery, sorting, matching, and classifying games should allow for provisional answers without revealing which ones are correct. For assessments where answer keys must not be distributed, use authorized Host remediation and not a package with embedded solutions.

Drag gaps are defined at the exact place in the phrase by {{id}} o marcadores ___. Long courses must remain scrollable, and 3D games maintain physical limits for moving objects.
