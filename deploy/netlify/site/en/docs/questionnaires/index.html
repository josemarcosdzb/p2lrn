Choose the right activity for your lesson

Think about the action learners should take: answer a question, connect related ideas, sort a sequence, find words or handle objects in a 3D scene. Use Studio to add the chosen activity to the course.

  1. Choose a unit or lesson.Open the course and select where the activity belongs.
  2. Open Add content.Use Assessment → Questionnaire for a multi-question quiz, or Games for a specific activity such as Memory or Crossword.
  3. Enter questions and solutions.Each activity has its own fields. The guides below show the actual authoring form and the learner result.
  4. Check Learner preview.Complete the activity yourself before sharing the course.

Activities for different learning goals

Choose activities according to what learners need to practice, not the appearance of a game. These three situations let you prepare exercises within a course without building a 3D scene:

  1. Language vocabulary.Prepare clues and answers for a word search, a crossword or a word wheel. Check that clues do not allow contradictory answers.
  2. Relaciones entre conceptos.Match definitions and images using memory or matching pairs. Test how to correct an association before submitting the activity.
  3. Processes and categories.Utiliza ordering for a sequence and classification for groups of elements. Verify that a provisional answer does not reveal the solution too early.

Before sharing the package, use Studio to review instructions and Player to test navigation, keyboard support, mobile scrolling and error messages. For objects in a spatial scene, follow the separate 3D games guide.

Fill-in-the-blanks and drag-and-drop: how they are configured

These are different editing tools. Fill in the blanks creates a question; drag and drop inserts an interactive block into the current lesson.

Fill in the blanks: create answers and distractors

Example: “La Tierra gira alrededor del Sol.” Learners choose the correct word among several options. Teachers type the sentence normally; Studio generates the blank identifiers.

  1. Write the full sentenceOpen Add content → Games → Fill in the blanks (Rellenar huecos). Under Text to complete (Texto a completar), type or paste “La Tierra gira alrededor del Sol.”; explain the task in the question prompt.
  2. Select the word to hideSelect “Sol” within that sentence and press Convert selection to blank (Convertir selección en hueco). Studio inserts the blank in place and automatically records Sol as its correct answer.
  3. Check the correct answerHueco 1 now contains Sol. You may also type or paste the accepted word into this field to edit it. You do not type technical placeholders into the sentence.
  4. Add distracting wordsSet Response mode (Modo de respuesta) to Drag words (Arrastrar palabras). Extra words / distractors (Palabras extra / distractores) appears: type Luna and Marte, one per line. The word bank includes these incorrect options and the already accepted word Sol; distractors are not entered into Hueco 1.
  5. Try it as a learnerThe sentence now contains a blank and the bank offers Sol, Luna and Marte. Check that only Sol is correct. Learners can drag a word or select it and then choose the blank.

Other fields to review

The question prompt (Enunciado) tells learners what to do; Points (Puntos) controls the question score and Time (Tiempo (s)) optionally limits the attempt. Incorrect answers subtract points (El fallo resta) enables a Penalty (Penalización). Add blank (+ Añadir hueco) inserts another gap. If a blank accepts multiple correct answers, enter them in its answer field separated by |. These are valid alternatives, not distractors.

To have learners type their answers instead, choose Type answer (Escribir respuesta). This mode does not display the draggable word bank or distractor field.

Drag cards into target zones

Inside a lesson, open Insert (Insertar) → Drag and drop (Arrastrar y soltar). The initial block contains cards and target areas. Replace the sample labels, configure the correct destinations and try the task in Learner preview.

How to mark a multi-question quiz

To evaluate multiple questions together, create them within the same activity Quiz in Studio with “Add question”. The “One question at a time” mode offers Previous and Next until the last question, where the set is delivered. Creating activities independent of a question produces independent deliverables and results.

In new courses and games, learner-visible autocorrect is initially disabled. The teacher can expressly select “Show autocorrection only upon completion.” Until delivery, sorting, matching, and classifying games should allow for provisional answers without revealing which ones are correct. For assessments where answer keys must not be distributed, use authorized Host remediation and not a package with embedded solutions.

For activities with missing words, verify that each answer appears in the intended position. Check that longer lessons stay readable on mobile and that dragging also has an accessible alternative.
