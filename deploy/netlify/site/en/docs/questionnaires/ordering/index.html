Arrange steps in the correct sequence

Use it for procedures, timelines, phases, priorities, or any content where the complete order is part of the answer.

Set the steps in their correct order

Ordering tasks help learners understand processes and timelines. The example uses evaporation, condensation and precipitation.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → Ordering (Ordenar).
  2. Write the instructionsEnter a prompt such as 'Put the stages of the water cycle in order'.
  3. Set the answersEnter one step in each Element field. Their order in the editor represents the correct answer. Use the up and down arrows to rearrange them.
  4. Review the settingsChoose Add element if you need another step; check that the intended sequence is unambiguous.
  5. Try the learner activityReorder the items in Learner preview and test the controls provided as alternatives to dragging.

Water-cycle ordering after checking the sequence

How the learner responds: Use the arrows or drag the steps into this order: Evaporación → Condensación → Precipitación → Acumulación (evaporation, condensation, precipitation, accumulation). Select Comprobar (Check) to verify the sequence. The screenshot already shows the correct order and a 4/4 result, not the initial shuffled state.

Check the sequence and alternative controls

Complete it in Learner preview and try the exported file in Viewer.

Accessibility, scoring and results

Interaction and accessibility

The learner can reorder by dragging and also has controls to raise or lower elements.

Completion and scores

The current order is compared to the solution. When the sequence is correct, the activity communicates the result.

To save the result on your platform, see Events and Host Adapter.

Check the exported file

Open your exported .p2lrn file in the P2LRN Viewer, complete the exercise and check its instructions, feedback and result. Test the actual file you exported rather than relying on an unrelated sample.

Create and verify your own exercises in Studio. Native test courses are no longer published.
