Matching concepts with correct answers

Shows two sets of elements so that the learner can build the correct relationships between them.

Match items from two sets

Use it for terms and definitions, countries and capitals, related concepts, or any matching exercise.

Enter both sides of each match

Use matching tasks to connect related information, such as countries and capitals. Each row stores an item and its correct partner.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → Matching (Relacionar).
  2. Write the instructionsWrite an instruction such as 'Match each country with its capital'.
  3. Set the answersEnter the matching pairs España–Madrid, Francia–París and Italia–Roma. Choose Add pair to expand the exercise.
  4. Review the settingsCheck that no item could reasonably match more than one answer, then set points.
  5. Try the learner activityJoin the two groups in Learner preview and confirm that the expected pairings are marked correctly.

Accessibility, scoring and results

Interaction and accessibility

The elements are buttons and the relationship can be completed by selection, without relying exclusively on dragging.

Completion and scores

Each resolved relationship updates the state of the question. When all pairs are completed, the activity can end and score is reported.

Content requirements

  • In Studio it is created as a question of type Matching.
  • The activity requires embedded solutions and at least three complete pairs.
  • The relationships must be distinguishable: duplicate texts that make the correspondence ambiguous invalidate this presentation.

Valid data example

This example shows the data used by the activity for CLI authoring. In Studio, configure the corresponding content using the visual editor.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Match countries and capitals",
  "language": "en",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "matching",
      "prompt": "Match each country with its capital",
      "points": 3,
      "left": [
        {
          "id": "l1",
          "text": "Spain"
        },
        {
          "id": "l2",
          "text": "France"
        },
        {
          "id": "l3",
          "text": "Italy"
        }
      ],
      "right": [
        {
          "id": "r1",
          "text": "Madrid"
        },
        {
          "id": "r2",
          "text": "Paris"
        },
        {
          "id": "r3",
          "text": "Rome"
        }
      ],
      "solution": {
        "pairs": [
          {
            "left": "l1",
            "right": "r1"
          },
          {
            "left": "l2",
            "right": "r2"
          },
          {
            "left": "l3",
            "right": "r3"
          }
        ]
      }
    }
  ]
}

How to read the example

left and right define the two columns. solution.pairs match the correct identifiers.

Create by CLI — advanced alternative

Use these commands for code-based authoring with Toolkit installed via npm. The quiz.json file must contain a valid questionnaire like the example above.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Matching" \
  --renderer "https://p2lrn.org/renderer/questionnaire/matching"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer Select the preferred presentation. It does not create a second copy of the questions: the content remains the native questionnaire.
