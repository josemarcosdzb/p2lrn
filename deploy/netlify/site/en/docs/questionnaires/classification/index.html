Create categories and assign each item

Classification activities group ideas by a shared property. This science example uses Sol, Rocas and Agua.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → Classification (Clasificar).
  2. Write the instructionsAsk learners to put each item into its correct category.
  3. Set the answersAdd Astros, Geología and Hidrosfera under Categories; use Add category when needed. Enter Sol, Rocas and Agua as items.
  4. Review the settingsSelect the correct category next to each item. Use Add item to extend the activity.
  5. Try the learner activityPlace the items into their destinations in Learner preview and verify each solution.

Classification with items already placed

How the learner responds: Place each item in its group. In this example, Luna and Cometa go under Astros (astronomy), Granito and Volcán under Geología (geology), and Río and Océano under Hidrosfera (hydrosphere). Accessibility, scoring and results

Interaction and accessibility

Objects and categories can be selected using buttons and keyboard; dragging is an aid, not the only method.

Completion and scores

Each assignment updates the answer. The score is calculated by comparing all assignments with the solution.

To save the result on your platform, see Events and Host Adapter.

Check the exported file

Open your exported .p2lrn file in the P2LRN Viewer, complete the exercise and check its instructions, feedback and result. Test the actual file you exported rather than relying on an unrelated sample.
