Word wheel game with questions for each letter

Assign a different letter to each textual question. The learner moves around the word wheel, answers each clue or skips a letter to return to it later.

Answer the questions for each letter of the word wheel

Use it for vocabulary and concepts with clear textual answers that can be associated with different letters.

Connect every question to its letter

The word wheel organises short questions by letter. Each one needs a clue, an accepted answer and a rule that matches the letter.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → Word wheel (Rosco).
  2. Write the instructionsEnter a clue such as 'Capital of Spain' and its answer, Madrid.
  3. Set the answersSelect M for the question's letter and choose Starts with letter. You can also choose Contains letter for other answers.
  4. Review the settingsAdd a question for each letter you want to include, making sure the answer satisfies the chosen rule.
  5. Try the learner activityTest Skip, returning to pending letters and the final results in Learner preview.

Accessibility, scoring and results

Interaction and accessibility

The letters are buttons, the answer is typed in a text field and there is an action to move to another letter.

Completion and scores

Each correct answer updates the corresponding question. When solving the set, the score is communicated.

To save the result on your platform, see Events and Host Adapter.
