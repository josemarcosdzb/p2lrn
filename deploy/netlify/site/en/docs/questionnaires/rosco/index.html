QUESTIONNAIRES / PRESENTATION

Word wheel

Assign a different letter to each textual question. The learner goes through the donut, responds or temporarily moves on to the next letter.

1. Answer the questions for each letter of the word wheel

Assign a different letter to each textual question. The learner goes through the donut, responds or temporarily moves on to the next letter.

Use it for vocabulary and concepts with clear textual answers that can be associated with different letters.

2. Create in Studio

In Studio, add the activity, set its expected answers and check Learner preview before exporting.

  1. Open Studio.Use the hosted editor or the Studio you have integrated into your project.
  2. Add the activity.In Add content, open Games and choose Word wheel.
  3. Edit the activity.Change statements, responses, and options with editor controls. The JSON remains as an advanced view, not a requirement for use.
  4. Check Learner preview.Play the activity before downloading or saving the course.

3. Content requirements

  • In Studio it is edited with questions of type Text answer.
  • Every question needs exactly one usable textual answer.
  • The response must have at least two standard characters.
  • Each challenge needs a different letter that is present in its own answer. P2LRN does not invent answers or eliminate questions.

4. Valid data example

This example shows the data used by the activity for CLI authoring. In Studio, configure the corresponding content using the visual editor.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Vocabulary Word Wheel",
  "language": "en",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "text",
      "prompt": "Home",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "HOME"
        ]
      }
    },
    {
      "id": "q2",
      "type": "text",
      "prompt": "Domestic animal that barks",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "DOG"
        ]
      }
    },
    {
      "id": "q3",
      "type": "text",
      "prompt": "Furniture used for eating or working",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "TABLE"
        ]
      }
    },
    {
      "id": "q4",
      "type": "text",
      "prompt": "Earth's natural satellite",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "MOON"
        ]
      }
    }
  ]
}

5. How to read the example

HOUSE, DOG, TABLE and MOON allow you to assign, for example, C, P, M and L. The Player calculates this association from the real answers; This block is a valid questionnaire, not a list of comments.

6. Create by CLI — advanced alternative

Use these commands for code-based authoring with Toolkit installed via npm. The quiz.json file must contain a valid questionnaire like the example above.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Word Wheel" \
  --renderer "https://p2lrn.org/renderer/questionnaire/rosco"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer Select the preferred presentation. It does not create a second copy of the questions: the content remains the native questionnaire.

8. Interaction and accessibility

The letters are buttons, the answer is typed in a text field and there is an action to move to another letter.

9. Completion and scoring

Each correct answer updates the corresponding question. When solving the set, the score is communicated.

To save the result on your platform, see Events and Host Adapter.
