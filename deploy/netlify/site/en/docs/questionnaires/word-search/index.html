Word search

FOR TEACHERS AND COURSE CREATORS

Create word search in Studio

Create this activity using the visual editor. You do not need JSON or terminal commands.

Example activity. Make a geometry word search with “triangle”, “circle” and “square” and clues that distinguish the terms.

What to check. Check the full grid and try selecting the first and last letters or answering from the clue without dragging.

  1. Open the course.Go to Studio and select the unit or lesson that will contain this activity.
  2. Add the activity.In Add content, open Games and choose Word search.
  3. Enter the content.Enter the target words and suitable clues.
  4. Set the correct answer.Check the grid and make sure every word can be selected.
  5. Check Learner preview.Play the activity before downloading or saving the course.
  6. Save and reopen.Download your .p2lrn course and check the exported file in Viewer.

For developers: JSON, CLI and integration

This reference is for programmatic package creation or app integration. Teachers can create the activity directly with Studio.

Open technical examples and CLI commands

Content requirements

  • In Studio it is edited with questions of type Text answer.
  • At least three answers are needed.
  • Each standard response must be between 3 and 16 characters.
  • All words must be placeable: P2LRN does not remove questions to force the board.

Valid data example

This example shows the data used by the activity for CLI authoring. In Studio, configure the corresponding content using the visual editor.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Planets",
  "language": "en",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "text",
      "prompt": "Closest planet to the Sun",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "MERCURY"
        ]
      }
    },
    {
      "id": "q2",
      "type": "text",
      "prompt": "Second planet in the Solar System",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "VENUS"
        ]
      }
    },
    {
      "id": "q3",
      "type": "text",
      "prompt": "Our planet",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "EARTH"
        ]
      }
    }
  ]
}

How to read the example

Each textual question provides a clue and an accepted answer. The Player normalizes the responses and constructs the grid only if it can represent the entire set.

Create by CLI — advanced alternative

Use these commands for code-based authoring with Toolkit installed via npm. The quiz.json file must contain a valid questionnaire like the example above.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Word Search" \
  --renderer "https://p2lrn.org/renderer/questionnaire/word-search"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer Select the preferred presentation. It does not create a second copy of the questions: the content remains the native questionnaire.
