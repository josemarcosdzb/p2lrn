Use it for vocabulary, names, short concepts, or review of terms.

Enter the words learners will look for

A word search helps practise vocabulary. The editor stores clues and answers; the learner then finds the words in a grid.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → Word search (Sopa de letras).
  2. Write the instructionsFor each word, add a clue as the question, such as 'Star at the centre of our solar system'.
  3. Set the answersEnter SOL in Accepted answers. Add a question for every word you want included.
  4. Review the settingsCheck spelling and make sure each clue points to the intended word.
  5. Try the learner activityOpen Learner preview, inspect the generated grid and find every word.

Word search after several words have been found

How the learner responds: Read a clue, look for its answer in the grid and select adjacent letters. For example, «Astro que produce luz por fusión» (a star producing light by fusion) is ESTRELLA (star). Content requirements

  • In Studio it is edited with questions of type Text answer.
  • At least three answers are needed.
  • Each standard response must be between 3 and 16 characters.
  • All words must be placeable: P2LRN does not remove questions to force the board.

Valid data example

This example shows the data used by the activity for CLI authoring. In Studio, configure the corresponding content using the visual editor.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Planets",
  "language": "en",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "text",
      "prompt": "Closest planet to the Sun",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "MERCURY"
        ]
      }
    },
    {
      "id": "q2",
      "type": "text",
      "prompt": "Second planet in the Solar System",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "VENUS"
        ]
      }
    },
    {
      "id": "q3",
      "type": "text",
      "prompt": "Our planet",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "EARTH"
        ]
      }
    }
  ]
}

How to read the example

Each textual question provides a clue and an accepted answer. The Player normalizes the responses and constructs the grid only if it can represent the entire set.

Create by CLI — advanced alternative

Use these commands for code-based authoring with Toolkit installed via npm. The quiz.json file must contain a valid questionnaire like the example above.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Word Search" \
  --renderer "https://p2lrn.org/renderer/questionnaire/word-search"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer Select the preferred presentation. It does not create a second copy of the questions: the content remains the native questionnaire.
