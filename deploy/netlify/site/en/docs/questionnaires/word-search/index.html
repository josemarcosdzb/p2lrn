Enter the words learners will look for

A word search helps practise vocabulary. The editor stores clues and answers; the learner then finds the words in a grid.

Activity setup in the editor

  1. Choose the activityOpen your course and its unit. In Add content, select Games (Juegos) → Word search (Sopa de letras).
  2. Write the instructionsFor each word, add a clue as the question, such as 'Star at the centre of our solar system'.
  3. Set the answersEnter SOL in Accepted answers. Add a question for every word you want included.
  4. Review the settingsCheck spelling and make sure each clue points to the intended word.
  5. Try the learner activityOpen Learner preview, inspect the generated grid and find every word.

Word search after several words have been found

How the learner responds: Read a clue, look for its answer in the grid and select adjacent letters. For example, «Astro que produce luz por fusión» (a star producing light by fusion) is ESTRELLA (star). The screenshot already contains highlighted words and filled-in clue fields, rather than an unsolved puzzle.

Interaction and accessibility

Completion and scores

When all the words are found, the answers to your questions are applied and the activity ends.
