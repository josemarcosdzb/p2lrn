From the editor to a working course, step by step

  1. Open or create: Use New course, Open file or Open URL above the editor.
  2. Organize: Use New unit and New lesson; navigate the tree on the left.
  3. Edit: Work in the lesson canvas; use the formatting ribbon and Add content dialog.
  4. Review: Open Learner preview; this does not save or grade the lesson.
  5. Save and export: Use Save draft or Export .p2lrn in the toolbar.

FREQUENTLY ASKED QUESTIONS

Questions about building and sharing courses

Do I need an LMS to create a course?

No. Open P2LRN Studio in your browser to build units, lessons and activities, then download a .p2lrn file without installing Moodle or another LMS. Server-side saving, user accounts and official grades require services provided by your own platform.

Which question types can I create?

Native quizzes support single and multiple choice, true/false, text answers, fill-in-the-blanks, ordering, matching and classification. Studio lets you combine several questions into one assessment and check the learner view before exporting.

Can I deliver courses without an internet connection?

Yes. Studio supports offline Windows deliveries as a .p2lrn-offline.exe and a portable ZIP alternative. Learners run the bundled content and return a .p2lrn-result file. Activities that depend on remote services or live collaboration cannot run fully offline.

Can one file contain both quizzes and games?

Yes. A .p2lrn file can include lessons, quizzes, memory, matching, ordering, classification, word search, crossword, word wheel and compatible 3D activities. Player chooses a suitable presentation without dropping questions to fit a game.

Where can P2LRN courses run?

On a website, embed <p2lrn-player>. For LMS use, P2LRN documents an external LTI 1.3 tool for Moodle, Canvas and Sakai, with version-dependent integration paths for Chamilo and Open edX. An administrator must register the provider and test launches on the actual LMS; this is not automatic SCORM import.

Can I set attempt limits, dates and progression rules?

Yes. Course progression can require completion and minimum scores. Offline assignments can define attempts, availability dates, deadlines and resumption; clock-based limits depend on the learner's device clock. Offline results are informative and do not automatically become official LMS grades.
