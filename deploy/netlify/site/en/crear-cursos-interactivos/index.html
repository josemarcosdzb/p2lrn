CREATE / INTERACTIVE COURSES

Create interactive courses online without coding

P2LRN Studio brings together lessons, activities and learner view in one visual editor. You can prepare a course, test it, and export it as a .p2lrn package to play with Player.

Open P2LRN StudioSee the editor's guide

FROM EDITOR TO COURSE

How it works, step by step

  1. 01

    Create the course and its structure

    In Studio, press “Create Course” and organize the units and lessons that the learner will see.

  2. 02

    Add content and activities

    Edit text and images from the interface and use “Add Content” to add tests and compatible games.

  3. 03

    Check the learner view

    Toggle between editing and learner View to review the output before distributing it.

  4. 04

    Export the package

    Download the .p2lrn file and open it with Player or integrate it into the target environment.

BEFORE YOU START

Can I create quizzes without installing Moodle?

Yes. You can prepare lessons and quizzes in Studio and play the package with Player without installing an LMS. Enrolments and official grades require a system that manages that data.

COMMON QUESTION

Do I need to install an LMS to create the course?

No. You can create and export a package from Studio. If you want enrollment, identity services, or other features from a platform, you will need to integrate it with the corresponding system.
