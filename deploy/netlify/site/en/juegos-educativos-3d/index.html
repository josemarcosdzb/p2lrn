THREE NATIVE MECHANICS

How it works, step by step

  1. 01

    Sort in 3D

    Place physical objects in a sequence and check if the order represents the solution to the exercise.

  2. 02

    Match in 3D

    Join nodes or elements from both sides to practice associations within an interactive scene.

  3. 03

    Classify in 3D

    Deposit objects in the corresponding categories and receive the result of the activity.

FROM IDEA TO GAME

How to prepare and test a 3D educational game

For example, in a science activity you could ask learners to put the stages of a process in order. This is a suggested teaching use; the viewer includes a sample package to test the real game mechanics.

1. Choose a game mechanic

Decide whether learning requires ordering a sequence, matching concepts or classifying objects. Prepare the answers and categories before building the scene.

Design the activity →

2. Test the sample

Open the 3D game package in the viewer and check how it responds to learner actions; an interactive scene is not a static image.

Open the sample game →

3. Test on the actual device

Before sharing the course, verify interaction, scrolling and performance in the browsers and devices your learners will use.

3D requirements and guide →

COMPATIBILITY

Do learners need to install an app to play?

Games run through Player in a compatible browser. 3D scenes need suitable graphics capabilities, so test each activity on the target device.

COMMON QUESTION

Are 3D games a video or a still image?

No. They are interactive activities that run in the browser. Experience depends on device graphics capabilities and browser compatibility.
