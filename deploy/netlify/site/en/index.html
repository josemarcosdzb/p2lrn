01 · FORMATS

Portable .p2lrn packages for websites and LMSs

P2LRN integrates any compatible format—SCORM, H5P, cmi5, xAPI, QTI, HTML and others—within the same package, along with its resources, structure and metadata. The same package can be used in web, LMS, applications and other environments without having to redo the integration for each format.

1

PACKAGE

The .p2lrn file preserves the course and embedded formats as part of a single portable package.

2

COMPATIBILITY

Player identifies the type of content and uses the appropriate capability to play it within the course.

3

EXPERIENCE

The learner accesses the lessons and activities from a unified experience, even if the course combines different formats.

An integrationA single Player for web, LMS and compatible applications. Technical installation details are left in the documentation so that the core experience remains clear.
