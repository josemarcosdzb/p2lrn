Términos y condiciones

Condiciones de uso del sitio público de P2LRN. Estos términos no sustituyen la licencia del software.

1. Objeto

Estos términos regulan el acceso y uso de la web informativa, documentación, visor, ejemplos y recursos públicos de P2LRN.

2. Ámbito

El sitio incluye información pública sobre P2LRN, documentación, Studio, Player, Analytics, ejemplos descargables y un formulario de contacto. Actualmente no existe en esta web un sistema de cuentas, proceso de compra, suscripción o pagos.

3. Servicios y recursos

El sitio permite consultar documentación, cargar paquetes en el visor, acceder a ejemplos y conocer las herramientas P2LRN. Si un paquete está alojado en otro dominio, el servidor de origen debe permitir que el visor acceda al archivo y a los recursos necesarios.

4. Uso de la documentación

La documentación describe las capacidades de versiones concretas de P2LRN. Para integraciones que dependan de un comportamiento específico, utiliza una versión fijada y revisa sus notas y requisitos de compatibilidad.

5. Uso del software y licencia

Los términos y la licencia son documentos distintos.

Los derechos para usar, copiar, modificar o distribuir el software se determinan exclusivamente por el archivo LICENSE aplicable y los avisos de terceros. Estos términos no conceden derechos adicionales sobre el código.

6. Obligaciones del usuario

  • Utilizar el sitio y sus herramientas de forma lícita.
  • No introducir código, URLs o contenidos destinados a comprometer el sitio, el Player o a terceros.
  • Respetar licencias, derechos de autor, marcas y avisos de terceros.
  • No presentar una versión modificada como oficial cuando la licencia aplicable lo prohíba.

7. Usos prohibidos

No está permitido abusar del formulario, intentar acceder a datos de otros usuarios, eludir controles de seguridad, utilizar el servicio para distribuir contenido ilícito o infringir deliberadamente derechos de terceros.

8. Dependencias y contenido de terceros

Algunas funciones de reproducción y algunos paquetes pueden depender de software o formatos de terceros. Cada componente conserva sus condiciones. La compatibilidad técnica no implica titularidad, patrocinio ni una sublicencia sobre dicho software.

9. Versiones y evolución

P2LRN se distribuye por versiones. La versión pública actual puede incluir cambios antes de una futura versión estable, por lo que cualquier integración que dependa de un comportamiento concreto debe fijar la versión utilizada y validar los formatos y navegadores necesarios para su caso.

10. Disponibilidad, cambios y seguridad

El sitio puede modificarse, actualizar secciones o sustituir ejemplos. Las medidas de seguridad reducen riesgos pero no permiten prometer disponibilidad continua o ausencia total de errores.

11. Contacto

Las consultas pueden enviarse desde la página de contacto. El tratamiento de los datos del formulario se explica en Privacidad.

12. Cambios y marco aplicable

Estos términos pueden actualizarse cuando cambien el sitio o sus servicios. Se respetarán en todo caso las normas imperativas que correspondan y las condiciones específicas de la licencia de software aplicable.
