PLAYER

Player web

Cómo cargar un paquete P2LRN en navegador, configurar el Web Component, usar el CDN y entender los runtimes aislados.

Integración mínima

El Player se distribuye como Web Component. Al cargar el script se registra <p2lrn-player>.

HTML
<script src="https://p2lrn.netlify.app/player/current/dist/p2lrn.js"></script>

<p2lrn-player src="/courses/course.p2lrn"></p2lrn-player>

Contrato HTML

src

URL del paquete. Requerida para la reproducción.

obligatoria
node

Selecciona un nodo concreto del grafo. Sin él se usa el entrypoint principal.

opcional
renderer

Solicita un renderer específico de forma estricta.

opcional
runtime-base-url

Sustituye el runtime estático inferido por otro origen de confianza.

opcional

Eventos

El Player publica eventos DOM bajo el namespace p2lrn:*, incluidos p2lrn:ready, p2lrn:rendered, progreso, estado, puntuación, finalización y errores.

Runtimes aislados

H5P y SCORM se ejecutan en hosts aislados. Esto separa el contenido ejecutable del documento que integra el Player y reduce el acoplamiento con la aplicación anfitriona.

El Service Worker es opcional y se utiliza cuando una instalación necesita acceso verificable a recursos con búsqueda o rangos HTTP.
