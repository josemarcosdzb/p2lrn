REPRODUCCIÓN / PLAYER

Player web

El Player abre un paquete .p2lrn, verifica su integridad, selecciona una presentación compatible y conecta la reproducción con la plataforma que lo contiene.

Instalación

La instalación se documenta fuera de esta referencia. Elige la guía que corresponda a tu aplicación y vuelve aquí para configurar el Player.

DEPENDENCIAS DEL PROYECTO

Instalación con NPM

Player integrado como paquete de la aplicación.

ARCHIVOS WEB

Instalación mediante CDN

Player cargado directamente desde HTML.

Componente web

src

URL del paquete que debe abrirse.

node

Entidad inicial opcional.

renderer

Presentación solicitada explícitamente cuando necesitas fijar una concreta.

runtime-base-url

Origen base para los entornos aislados que ejecutan contenido externo.

player.adapter

Conexión con Host Adapter versión 1.

await player.reload()

Vuelve a abrir el paquete y actualiza la reproducción.

API pública

P2LRN.mount(target, options)

Monta el Player y aplica sus opciones de carga.

P2LRN.openPackageURL(url, options)

Abre un paquete remoto y utiliza peticiones por rangos cuando el servidor lo permite.

P2LRN.openPackageBytes(buffer, limits)

Abre un paquete disponible completamente en memoria.

P2LRN.renderers()

Lista las presentaciones registradas.

P2LRN.installServiceWorker(options)

Prepara el puente de recursos cuando una integración necesita URLs navegables para contenido ya verificado.

Integridad y transporte

El Player valida el manifiesto, el grafo y los recursos que consume. Cuando un servidor admite HTTP Range, puede verificar primero la estructura del paquete y cargar recursos concretos bajo demanda.

Límites por defecto

Buffer completo: 256 MiB. Paquete remoto: hasta 64 GiB. Entradas: 5000. Son límites de protección del Player, no una recomendación de tamaño de curso.

Eventos

JavaScript
const player = document.querySelector('p2lrn-player');

for (const type of ['p2lrn:ready','p2lrn:rendered','p2lrn:score','p2lrn:statechange','p2lrn:complete','p2lrn:progressionchange','p2lrn:error']) {
  player.addEventListener(type, (event) => console.log(type, event.detail));
}

Consulta Eventos para el contrato de event.detail.

Host Adapter

Host Adapter permite cargar y guardar estado, informar de puntuación, enviar eventos y resolver recursos protegidos. Una URL entregada mediante resolveResourceUrl debe indicar verified:true para que el Player la acepte.

Ver la guía de integración →

Contenido compatible

El Player incluye presentaciones para contenido web y texto, multimedia, cuestionarios, juegos 2D y 3D, componentes, grupos compuestos y paquetes educativos compatibles con los entornos de ejecución disponibles.

Juegos 3D

Las actividades 3D utilizan Three.js para la escena y Rapier para las físicas. Las mecánicas de ordenar, relacionar y clasificar forman parte de P2LRN. Ver juegos 3D →

Service Worker

Se utiliza cuando una presentación necesita acceder mediante URL a recursos que el Player ya ha verificado. No es un requisito para todos los cursos.

Probar un paquete

El visor permite abrir un curso con el Player y revisar la información de carga y los eventos generados durante la reproducción.
