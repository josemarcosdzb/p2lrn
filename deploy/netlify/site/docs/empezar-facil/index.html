EMPEZAR / PRIMERA INTEGRACIÓN

Empezar fácil

Prueba primero la integración más sencilla: un paquete .p2lrn, el Player cargado desde CDN y una página HTML. No necesitas instalar paquetes en el proyecto para completar este recorrido.

1. Descarga un paquete de ejemplo

Guarda el ejemplo en una carpeta de trabajo. El resto de esta guía supone que el archivo se llama questionnaire-standard.p2lrn.

Descargar paquete de ejemploAbrir el ejemplo en el visor

2. Crea una página HTML

Guarda este archivo como index.html en la misma carpeta que el paquete. El primer script carga Player desde CDN y el elemento <p2lrn-player> abre el curso local de esa carpeta.

index.html
<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>P2LRN</title>
  <script src="https://p2lrn.netlify.app/player/current/dist/p2lrn.js"></script>
</head>
<body>
  <p2lrn-player src="./questionnaire-standard.p2lrn"></p2lrn-player>
</body>
</html>

3. Abre la carpeta en tu editor y sírvela por HTTP

Abre la carpeta del ejemplo en tu editor de texto o código habitual. Para que el navegador pueda cargar el paquete y sus recursos correctamente, abre la página desde un servidor HTTP local en lugar de abrir index.html directamente mediante file://.

  1. Localiza index.html y confirma que questionnaire-standard.p2lrn está en la misma carpeta.
  2. Utiliza la opción de vista previa o servidor local de tu editor, o cualquier servidor HTTP estático que prefieras.
  3. Abre en el navegador la dirección local que te proporcione ese servidor, normalmente basada en localhost o 127.0.0.1.

No necesitas un editor ni una extensión concretos; lo importante es servir la carpeta por HTTP.

4. Comprueba el resultado

La página debe mostrar el cuestionario dentro del Player. Si aparece, ya has comprobado el recorrido esencial: cargar el componente, abrir un paquete y ejecutar su contenido desde una aplicación web.

Qué has integrado.

El Player se ha cargado desde CDN; el curso sigue siendo un archivo .p2lrn independiente. A partir de aquí puedes decidir cómo quieres mantener esa integración en tu proyecto.

5. Continúa con la instalación

El siguiente paso es Instalación. La documentación presenta primero CDN —la continuación natural de este ejemplo— y después NPM para proyectos que gestionan sus dependencias mediante paquetes.
