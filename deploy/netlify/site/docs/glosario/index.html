REFERENCIA / GLOSARIO

Glosario

Consulta aquí los términos que aparecen en las demás guías. Se mantienen los nombres técnicos del formato y se explica qué responsabilidad tiene cada uno.

Paquete y estructura

Package / paquete

Archivo portable .p2lrn que entrega estructura, contenido, perfiles y datos de integridad.

Manifest / manifiesto

Documento que identifica el paquete y declara perfiles, entrypoints e integridad.

Graph / grafo

Estructura de curso, unidades, actividades, recursos y relaciones.

Entrypoint

Entidad desde la que el Player puede iniciar una reproducción.

Representation / representación

Forma concreta en la que un recurso está disponible para ser entregado.

contentRoot

Raíz de integridad derivada de la descripción normalizada del contenido.

Autoría

Workspace

Proyecto editable de autoría que conserva materiales y configuración necesarios para volver a construir un paquete.

Profile / perfil

Contrato adicional que añade semántica o capacidades al formato base.

Reader

Herramienta que extrae estructura y contenido de documentos para que una aplicación decida cómo incorporarlos al curso.

Multipart

Transporte que sustituye un recurso grande por un descriptor y varias partes verificadas.

Reproducción

Player

Componente que abre, verifica y reproduce un paquete.

Renderer / renderizador

Implementación que convierte una representación compatible en una interfaz para el alumno.

Runtime / entorno de ejecución

Entorno o lógica adicional que necesita determinado contenido para ejecutarse.

Preserve

Capacidad de conservar un artefacto dentro de un flujo sin afirmar que P2LRN pueda interpretarlo o reproducirlo.

Deliver

Capacidad de entregar o reproducir contenido mediante un entorno real compatible.

Integración

Host / plataforma

Aplicación que integra Player o Studio y posee usuarios, permisos, persistencia y secretos.

Host Adapter

Contrato de cinco operaciones para estado, puntuación, eventos y recursos protegidos.

Capability Broker

Broker deny-by-default que conecta capacidades semánticas del curso con providers configurados por el Host.

Offline Host Adapter

Wrapper de Host Adapter con estado local y outbox; no guarda historial dentro del paquete.

Package Cache

Almacén opt-in de bytes completos de cursos ya verificados; separado del estado del alumno.

Resource Library

Biblioteca content-addressed por SHA-256; los bytes permanecen tras un resolver verificado.

Learning event

Proyección ordenada/categorizada de un evento runtime con sesión/intento opcional.

Host autoritativo

Backend que decide identidad, conflictos y notas oficiales; puede deduplicar offlineDeliveryId.

Proveedor LTI

Servicio self-hosted que traduce OIDC/JWT, Deep Linking y AGS del LMS a sesiones autorizadas de P2LRN.

Recurso verificado

Objeto cuya entrega fue autorizada y cuya integridad fue comprobada según el contrato del Host.

Relaciones útiles

Workspace → paquete: el workspace se edita; el paquete se publica. Representación → renderizador: la representación describe cómo está disponible el recurso; el renderizador decide cómo mostrar una representación compatible. Player → Host Adapter: el Player reproduce; Host Adapter comunica esa reproducción con tu plataforma.
