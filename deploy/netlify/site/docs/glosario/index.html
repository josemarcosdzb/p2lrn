REFERENCIA / GLOSARIO

Glosario

Términos usados de forma consistente en la documentación.

Package

Artefacto portable .p2lrn.

Workspace

Proyecto editable de autoría, normalmente con p2lrn.project.json.

Manifest

Inventario, perfiles, entrypoints e integridad del paquete.

Graph

Estructura de curso, unidades, actividades, recursos y relaciones.

Representation

Forma concreta de entregar un recurso: contenido embebido, miembro de paquete, etc.

Entrypoint

Entidad inicial que el Player puede abrir.

Profile

Contrato adicional que declara semántica y capacidades.

contentRoot

Digest de integridad derivado de la descripción normalizada del contenido.

Renderer

Implementación que presenta una representación al usuario.

Runtime

Entorno o lógica necesaria para ejecutar una representación.

Host

Aplicación que integra el Player y posee usuarios, autorización y persistencia.

Host Adapter

Contrato entre Player y Host para estado, score, eventos y URLs verificadas.

Multipart

Transporte que sustituye un payload grande por un descriptor y partes externas verificadas.

Preserve

Poder conservar un artefacto sin afirmar que se puede interpretar o ejecutar.

Deliver

Capacidad de reproducir/entregar mediante un runtime real.
