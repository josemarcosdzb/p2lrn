INTEGRACIÓN / EVENTOS

Eventos de runtime

Todos los eventos públicos usan el namespace p2lrn:*. El detalle incluye el payload, el contexto y el evento normalizado con timestamp.

Estructura común

JavaScript
player.addEventListener('p2lrn:rendered', (event) => {
  console.log(event.detail.context);
  console.log(event.detail.event.timestamp);
  console.log(event.detail.rendererId);
});

El runtime también reenvía eventos al Host Adapter.emitEvent() cuando existe.

Eventos del Player

p2lrn:ready

Paquete cargado y render inicial completado. Incluye packageId y contentRoot.

p2lrn:rendered

Una representación ha sido renderizada. Incluye renderer, representación y entidad.

p2lrn:score

Evento de puntuación emitido por runtimes que la producen.

p2lrn:statechange

Cambio de estado emitido por runtimes compatibles.

p2lrn:complete

Finalización de una actividad.

p2lrn:progressionchange

Cambio del estado de progresión calculado por el Player.

p2lrn:error

Error estructurado con una fase como package-load, render, progression-load, progression-save o emitEvent.

Usa los nombres de eventos publicados

Importante

La documentación anterior mencionaba p2lrn:progress, p2lrn:state y p2lrn:completion como si fueran contratos generales. El Player actual usa p2lrn:statechange, p2lrn:complete y p2lrn:progressionchange. Los nombres del runtime real son la autoridad.
