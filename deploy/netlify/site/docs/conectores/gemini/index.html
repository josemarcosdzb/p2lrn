Gemini con P2LRN: sin MCP o con MCP local

Gemini no es lo mismo que Gemini CLI. Para crear cursos nuevos sin conectar tu ordenador puedes utilizar Skills o Gems donde estén disponibles. Para leer y editar cursos que ya tienes en el PC, Gemini CLI dispone de un conector MCP local stdio. Ninguna modalidad exige comprar un dominio.

Elige la opción correcta para Gemini

Gemini en la web: Skills, sin MCP

Si tu cuenta tiene acceso a Skills, crea o importa un flujo reutilizable con instrucciones y archivos. No necesitas servidor P2LRN ni instalar Node.js. Consulta la guía oficial de Skills de Gemini. Su disponibilidad depende del despliegue, país, cuenta y condiciones del servicio; no se garantiza en España.

Gemini web: Gems, si no aparecen Skills

Si la sección Skills no está disponible, puedes utilizar una Gem personalizada para repetir instrucciones y aportar archivos de referencia. Una Gem no es el servidor MCP ni ejecuta automáticamente el empaquetador de P2LRN.

Gemini CLI: Agent Skills sin MCP

En la aplicación de terminal, las Skills se almacenan en ~/.gemini/skills/ o .gemini/skills/ y se descubren mediante /skills list. Gemini CLI debe estar instalado, pero no hace falta el MCP de P2LRN si sólo quieres crear paquetes nuevos siguiendo una Skill compatible.

Gemini CLI: MCP local para cursos existentes

Para enumerar, leer, validar y, si lo autorizas, crear borradores de tus cursos del PC, utiliza el mismo servidor MCP P2LRN que Claude Desktop y Cursor. La configuración se registra en ~/.gemini/settings.json sin abrir puertos.

1. Gemini web: crear un curso sin instalar MCP

  1. Abre Gemini y comprueba si tu cuenta muestra Personalizar → Skills. Google está desplegando esa función por fases, con restricciones de región y cuenta.
  2. Cuando esté disponible, crea una Skill o carga una carpeta autorizada con SKILL.md y sus archivos compatibles. Revisa su contenido antes de activarla.
  3. Indica título, idioma, unidades, lecciones, preguntas y juegos. Exige como resultado un archivo .p2lrn real y verificable, no sólo un esquema de texto.
  4. Si Gemini no permite ejecutar el empaquetador o entregar el archivo, la tarea no está terminada. No renombres un JSON como .p2lrn.

En España: la ayuda de Google ha indicado restricciones regionales para Gemini Skills; comprueba la interfaz real de tu cuenta. Si no aparece, utiliza Gems mientras estén disponibles o un cliente compatible distinto. La disponibilidad no puede confirmarse desde P2LRN.

Skill de P2LRN y compatibilidad

Existe una Skill «P2LRN – Crear y descargar» comprobada en un entorno de ChatGPT. No está verificada como Skill de Gemini web. Copiar sus instrucciones sin ejecutar el empaquetador y validar el ZIP no demuestra compatibilidad. Consulta la guía de Skills sin MCP.

2. Gemini web: alternativa con Gems

En gemini.google.com, abre Gems → Nuevo Gem cuando esa opción exista en tu cuenta. Escribe instrucciones para estructurar un curso P2LRN, mantener soluciones correctas y evitar afirmar que un archivo está validado sin ejecutar herramientas. Puedes añadir documentación de P2LRN como archivos de conocimiento admitidos por Google.

Solicitud de ejemplo · Gemini web
Diseña un curso P2LRN de 3 unidades sobre seguridad digital,
con lecciones, 10 preguntas con respuestas verificables y
dos juegos. Si puedes ejecutar un empaquetador P2LRN autorizado,
entrega un archivo .p2lrn válido y verificado. En caso contrario,
entrega sólo el diseño e indica expresamente que falta empaquetarlo.

Una Gem puede preparar el contenido sin MCP. Para obtener un paquete real, la sesión de IA debe poder crear archivos y utilizar un empaquetador/validador compatible; si no es posible, exporta el contenido e impórtalo con Studio.

3. Gemini CLI: Agent Skills sin servidor MCP

Gemini CLI admite Skills de usuario y de proyecto mediante SKILL.md. Consulta la documentación oficial de Agent Skills. Revisa que la Skill que importes sea compatible con su entorno de ejecución y valida cualquier paquete obtenido.

Gemini CLI · detectar y enlazar una Skill local autorizada
gemini skills list
gemini skills link C:\Ruta\a\skill-p2lrn --scope user
gemini skills list

C:\Ruta\a\skill-p2lrn es un ejemplo, no un archivo incluido en el conector MCP. La instalación/enlace de una Skill no instala el servidor P2LRN. Si el flujo requiere generar un .p2lrn, confirma que la Skill contiene y ejecuta un empaquetador real y que produce un paquete válido. Para instalar Gemini CLI, sigue su documentación oficial.

4. Gemini CLI: conectar tus cursos del PC mediante MCP (opcional)

Esta opción sí utiliza MCP. El mismo servidor P2LRN funciona por stdio; no requiere dominio, HTTPS ni exponer 127.0.0.1 a Internet. Primero descarga y extrae el kit MCP P2LRN para Windows e instala Node.js 22 o posterior.

PowerShell · desde la raíz de P2LRN
.\integration\mcp\Conectar-P2LRN.cmd --root C:\MisCursos --clients gemini --install --verify

La carpeta C:\MisCursos debe existir y contener exclusivamente los cursos autorizados. El asistente prepara Toolkit y las dependencias, conserva y respalda la configuración existente de Gemini CLI, registra el MCP y comprueba una negociación real. Empieza con P2LRN_MCP_WRITE=0. No habilita edición sin permiso explícito.

Gemini web no ejecuta directamente este comando ni puede leer carpetas de tu PC mediante stdio. Para Gemini web las opciones compatibles dependen de los servicios de Google; no se anuncia aquí una integración web MCP que no esté probada.

Comprobar el resultado y límites

  • Skills o Gems: comprueba que el archivo .p2lrn exista, tenga manifiesto y pase la validación; una respuesta de texto no es una descarga.
  • Gemini CLI Skill: confirma que gemini skills list muestra la habilidad y que el entorno puede ejecutar los scripts permitidos.
  • Gemini CLI MCP: comprueba p2lrn_list_courses y p2lrn_validate_course; verifica que se rechacen rutas fuera de la carpeta autorizada.
  • No equivalentes: Skills no leen automáticamente cursos privados; MCP no garantiza que el modelo pueda generar contenidos correctos sin supervisión.
