Conectores e integración

Seis guías independientes. Para crear y descargar un curso nuevo no necesitas instalar MCP: usa Skills cuando estén disponibles. Para conectar cursos privados del PC, utiliza el MCP local. También se explican Gemini, ChatGPT, Claude, Grok, LMS y LTI 1.3 con su estado real.

Elige el tipo de conector

01 · SIN MCP

Skills: crear y descargar cursos

Skill P2LRN en ChatGPT y opciones de Claude y Gemini para crear un .p2lrn nuevo sin conectar el ordenador. No se instala MCP, Node ni un dominio.

 02 · IA WEB Y MCP

ChatGPT, Claude y Grok

Conexión a cursos del PC mediante clientes compatibles, túnel privado o HTTPS autenticado cuando sea necesario. Distingue la creación directa mediante Skills.

 03 · GEMINI

Gemini web, Gemini CLI y Skills

Skills o Gems en Gemini web cuando estén disponibles; Skills en Gemini CLI sin MCP, o conector stdio para cursos del PC.

 04 · IA LOCAL

Conectar tus cursos del PC

ZIP y asistente Windows para Claude Desktop, Cursor, Windsurf, Gemini CLI, VS Code y clientes MCP stdio; no requiere hosting.

 05 · LMS

Moodle y demás plataformas

Integración con Moodle, Canvas, Sakai, Chamilo y Open edX; reproducción, matrículas, progreso y notas.

 06 · LTI 1.3

Módulo de herramientas externas

OIDC, JWKS, Deep Linking, AGS, NRPS, seguridad, arquitectura y estado de implementación.

¿No quieres instalar MCP?

La opción más sencilla para crear un curso nuevo es una Skill P2LRN: describes el curso, el entorno de IA ejecuta un empaquetador compatible cuando esté disponible y recibes un .p2lrn descargable. No es necesario instalar Node ni acceder a carpetas privadas. Existe «P2LRN – Crear y descargar» en un entorno de ChatGPT; su disponibilidad en otras cuentas y la ejecución en Claude o Gemini deben verificarse por separado.

Si lo que quieres es editar archivos que ya están en el PC, consulta MCP local; son funciones diferentes. En Gemini encontrarás Skills/Gems web y Agent Skills CLI con sus restricciones.

Qué existe y qué sigue pendiente

MCP de IA y borradores

Existe un servidor MCP P2LRN para leer y validar cursos autorizados. La edición en borradores es opcional y exporta nuevos archivos sin sobrescribir originales.

Creación sin instalar MCP

La Skill «P2LRN – Crear y descargar» permite crear archivos nuevos desde un entorno compatible de ChatGPT, sin acceso al PC. Gemini y Claude ofrecen mecanismos de Skills propios cuya ejecución debe validarse; una Skill no es un conector.

Instalación local

Existe un asistente Windows y configuración para clientes compatibles. Cada instalación requiere verificación con la aplicación y la carpeta reales.

Configuraciones IA web

Para conectar archivos existentes existen MCP, túneles privados y endpoints HTTPS según la plataforma. No se confunden con Skills para crear paquetes nuevos. OAuth multiusuario y publicación en catálogos públicos no están finalizados.

Player y Host Adapter

El Player y las operaciones de estado, puntuación, eventos y recursos ya forman parte de P2LRN. La plataforma anfitriona aporta permisos, usuarios y persistencia.

Proveedor P2LRN LTI 1.3

Existen arquitectura y contratos iniciales. El gateway LTI completo, Deep Linking funcional, AGS real y las pruebas E2E con LMS están pendientes.

Una base técnica común

Curso .p2lrn↔Toolkit / Studio / Player↔Skill sin MCP / MCP / Host Adapter↔IA / LMS

El paquete es portable: el contenido no depende de ChatGPT, Claude, Moodle o Canvas. La identidad de usuarios, permisos, matrículas, credenciales, sesiones, progreso privado y calificaciones oficiales permanecen en el servicio anfitrión, no dentro del ZIP del curso.

No son el mismo mecanismo

Skills enseñan a la IA a crear un paquete desde un encargo y no conectan archivos privados. MCP proporciona herramientas para leer o editar cursos autorizados. LTI 1.3 permite el lanzamiento autenticado de un LMS y Host Adapter comunica el Player con su backend.

Cómo empezar

  1. Crear y descargar cursos nuevos sin instalar MCP: empieza por Skills sin MCP y, para Google, por Gemini web / CLI.
  2. Utilizar cursos del equipo: instala IA local con carpeta autorizada y prueba lectura y validación antes de editar.
  3. Enseñar desde una plataforma: consulta Plataformas LMS y la integración del Player.
  4. Lanzar mediante herramientas externas: estudia LTI 1.3 y sus requisitos de seguridad antes de configurar producción.
