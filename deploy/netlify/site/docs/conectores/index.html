Estado de las integraciones

El conector MCP dispone de lectura, validación y creación/edición controlada de borradores; la Skill P2LRN puede crear paquetes en entornos compatibles. El proveedor LTI 1.3 self-hosted ya implementa OIDC/JWT, JWKS, catálogo, Deep Linking, Player, persistencia y AGS.

Algunas capacidades dependen del entorno donde se despliegan: autenticación de conectores de IA, servicios opcionales de LTI y compatibilidad con versiones concretas de Moodle, Canvas, Sakai, Chamilo u Open edX. Cada guía indica los requisitos y límites que deben comprobarse antes de una implantación real.
