CONECTORES / SKILLS SIN MCP

Crear cursos P2LRN con Skills, sin instalar MCP

Si sólo quieres pedirle a una IA que cree un curso y te entregue un .p2lrn descargable, no necesitas instalar MCP, descargar Node.js, tener un dominio, abrir puertos ni conectar tus archivos privados. La Skill aporta las instrucciones y el empaquetador donde el entorno puede ejecutarlo.

Qué hace una Skill y qué no hace

Skill sin MCP: crear un archivo nuevo

La IA recibe un encargo, construye el contenido de un curso, ejecuta el empaquetador de la Skill si dispone de un entorno de código y verifica un nuevo .p2lrn. Devuelve el archivo en el chat. No lee carpetas de tu PC de manera automática.

MCP local: trabajar con tus archivos existentes

El conector MCP es diferente: permite listar, leer y validar paquetes que están en la carpeta autorizada de tu ordenador y, con permisos adicionales, editar borradores. Sólo es necesario si necesitas esa conexión persistente a tus archivos.

Studio: edición visual y funciones completas

Studio permite editar visualmente, preparar proyectos y exportaciones avanzadas. Una Skill autónoma no equivale al editor completo, ni garantiza colaboración, LTI, LMS, paquetes autorreproducibles o ejecución gráfica de juegos 3D.

ChatGPT: «P2LRN – Crear y descargar»

Existe una Skill P2LRN – Crear y descargar ya comprobada e instalada en un entorno de ChatGPT. Trabaja con Python y un empaquetador autónomo del subconjunto P2LRN Core 0.4.0, sin llamar al servidor MCP. Cuando esté instalada y permitida en tu cuenta, puedes solicitar un curso directamente en la conversación.

Ejemplo · pegar en ChatGPT con la Skill habilitada
Usa la Skill P2LRN – Crear y descargar.
Crea un curso .p2lrn sobre prevención de riesgos laborales,
en español, con 3 unidades, 6 lecciones, un cuestionario
de 10 preguntas, un juego de relacionar y uno de ordenar.
Verifica el paquete P2LRN Core y adjunta el archivo real
.p2lrn descargable. No uses MCP ni accedas a mi ordenador.
  1. En ChatGPT, abre Complementos → Habilidades y comprueba si «P2LRN – Crear y descargar» está disponible o compartida contigo. La instalación de Skills depende del plan y los permisos del área de trabajo.
  2. Si está instalada, pide el archivo .p2lrn con un encargo como el anterior. No instales nada en Windows para este flujo.
  3. Comprueba que el asistente ejecuta la verificación del empaquetador y entrega un archivo descargable real; rechaza respuestas sólo en JSON o texto.

Instrucciones oficiales para encontrar, compartir e instalar Skills en ChatGPT. La Skill no se instala en todas las cuentas automáticamente y esta web no ofrece todavía un ZIP público de esa Skill. No confundas el ZIP del conector MCP con un ZIP de Skill.

Claude: Skills sin instalar el servidor P2LRN

Claude admite Skills personalizadas cuando tu cuenta y entorno tienen habilitada esa función. Puedes cargar una Skill compatible en Personalizar → Skills y utilizarla en conversaciones. En Claude Code, las Skills de proyecto o usuario utilizan carpetas con SKILL.md, según la guía oficial de Anthropic.

Una Skill preparada para el entorno de ChatGPT no queda validada automáticamente en Claude. Antes de prometer descargas, hay que comprobar que sus scripts se ejecutan en el entorno de Claude, que puede entregar el archivo y que el .p2lrn pasa la verificación. El servidor MCP no es obligatorio para crear un paquete desde cero.

Gemini: Skills o Gems web y Agent Skills en CLI

Gemini web · Skills, si están habilitadas

Google ofrece Skills de Gemini con instrucciones reutilizables y archivos compatibles. La función depende de cuenta, región y despliegue; en España podría no estar todavía disponible. Para empaquetar P2LRN debe existir un entorno capaz de ejecutar la Skill y adjuntar el resultado; no está certificado.

Gemini web · Gems como alternativa

Si no aparece Skills, una Gem permite guardar instrucciones y referencias para diseñar el curso. No equivale a ejecutar el empaquetador: si Gemini sólo devuelve contenido, habrá que utilizar Studio para obtener un paquete real.

Gemini CLI · Skills de usuario/proyecto

Utiliza gemini skills list y una carpeta SKILL.md autorizada. No requiere servidor MCP P2LRN; sí necesita Gemini CLI y las herramientas que utilice esa Skill. Pasos específicos de Gemini.

¿Y Grok sin MCP?

Puedes pedirle a Grok que prepare el contenido de un curso siguiendo las instrucciones del formato y las preguntas correctas, pero P2LRN no ha certificado una integración de Skills ejecutables de Grok que genere y valide un .p2lrn. No se ofrece un botón de instalación que no exista. Para exportación verificable usa un entorno con Skill y empaquetador probados o Studio.

Validaciones y límites de la Skill P2LRN actual

  • Sí: crear y verificar cursos nuevos del subconjunto Core 0.4.0 con lecciones, cuestionarios y juegos compatibles, entregar ZIP con extensión .p2lrn y manifest de integridad.
  • No: leer automáticamente tus carpetas, modificar LMS/AulaP2P, instalar MCP, publicar en npm, garantizar edición sin pérdida de cualquier paquete antiguo o convertir el curso a un ejecutable offline.
  • Juegos 3D: el empaquetador verifica su estructura; una ejecución real del Player es necesaria para afirmar que el juego funciona visualmente.
  • Seguridad: revisa archivos y scripts antes de instalar cualquier Skill de terceros. No envíes contraseñas ni carpetas privadas para crear un curso nuevo.
