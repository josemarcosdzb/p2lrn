Conectores de IA local

Las aplicaciones de IA instaladas en tu ordenador pueden abrir herramientas P2LRN mediante MCP por stdio, sin dominio, túnel ni servidor en la nube. La carpeta de cursos autorizada y la posibilidad de editar se seleccionan durante la configuración.

Qué instala el conector local

La implementación reutiliza integration/mcp/server.mjs, el mismo servidor MCP que emplean los clientes web, pero mediante transporte stdio en vez de HTTP remoto. No instala un segundo formato ni modifica Studio, Toolkit o Player.

Lectura (predeterminada)

Listar, buscar, leer y validar paquetes dentro de una carpeta permitida.

Edición opcional

Crear proyectos de borrador, añadir contenidos y actividades y exportar paquetes nuevos. Las operaciones requieren habilitación explícita.

Acceso restringido

El proceso usa los permisos de tu usuario y sólo lee la carpeta seleccionada; no debe apuntar a todo el disco ni abrir rutas sin autorizar.

Instalación guiada en Windows

  1. Ten instalado Node.js 22 o posterior y una copia local autorizada del repositorio P2LRN.
  2. Desde el Explorador, abre integration/mcp/Conectar-P2LRN.cmd con doble clic.
  3. Selecciona la carpeta que contiene tus cursos. El valor sugerido es Documentos/P2LRN, pero puedes elegir otra.
  4. Elige los clientes detectados y si quieres solamente lectura o también edición en borradores.
  5. Revisa la lista de archivos de configuración que va a cambiar y confirma. El asistente crea copias de seguridad y no borra otros servidores MCP.
  6. Comprueba que el cliente puede listar un curso y valida el paquete antes de probar edición.
El proceso se inicia bajo demanda

No necesitas instalar un servicio en segundo plano ni exponer una URL a Internet. Si no tienes el ejecutable .cmd, usa el script avanzado después de preparar Toolkit y las dependencias.

Clientes y tipos de registro

Claude Desktop

Configura un servidor MCP local con JSON. El asistente solicita confirmación y preserva las demás entradas existentes.

Cursor

Registra las herramientas P2LRN en la configuración MCP del editor, sin modificar los paquetes del curso.

Windsurf

Configura la conexión local compatible con MCP; debe verificarse que la versión instalada expone las herramientas.

Gemini CLI

Registra el proceso stdio como servidor MCP. La conexión es local incluso si el modelo que usa Gemini CLI puede estar alojado en la nube.

VS Code

Usa un archivo .vscode/mcp.json dentro del proyecto indicado explícitamente por --workspace.

Codex CLI, Claude Code, OpenCode

Genera una configuración o instrucciones para importar y revisar según la versión del cliente; no se promete instalación automática en todos los casos.

Clientes MCP stdio genéricos

Se facilita la entrada de conexión con comando, argumentos y variables de entorno. La compatibilidad depende del cliente.

ChatGPT Desktop

Existe una guía de desarrollo local, pero la instalación directa de servidores stdio depende de las capacidades y permisos disponibles en esa aplicación.

Comandos para usuarios avanzados

Ejecuta los siguientes comandos desde la raíz del repositorio. Para el script directo debes preparar primero el Toolkit y las dependencias, cosa que hace automáticamente el lanzador de Windows.

PowerShell · asistente interactivo
node integration/mcp/connect-local.mjs
Instalar y verificar clientes elegidos
node integration/mcp/connect-local.mjs --root C:\MisCursos --clients claude,cursor,windsurf,gemini --install --verify
Editar sólo borradores y exportaciones nuevas
node integration/mcp/connect-local.mjs --root C:\MisCursos --clients auto --enable-drafts --install --verify
VS Code · sólo un proyecto explícito
node integration/mcp/connect-local.mjs --root C:\MisCursos --clients vscode --workspace C:\MiProyecto --install --verify

Trabajar con Ollama y un modelo local

El repositorio incorpora ensayos de laboratorio con Ollama en 127.0.0.1:11434 y, por defecto, el modelo qwen3:4b. El modelo debe instalarse por separado y estar disponible localmente; este conector no descarga modelos ni garantiza su capacidad autónoma para completar todas las tareas.

Uso de herramientas

integration/mcp/test/local-agent-matrix.e2e.mjs registra qué herramientas elige y ejecuta el modelo.

Generación de contenido

integration/mcp/test/local-agent-structured.e2e.mjs evalúa respuestas estructuradas que Toolkit valida para construir paquetes temporales.

Diferenciar local de remoto

El servidor MCP puede ser local aunque la IA usada por un editor sea remota. Para inferencia sin nube hay que configurar específicamente un modelo local.

Verificar que funciona y resolver errores

  • Comprueba versión de Node, ubicación del repositorio y existencia de las dependencias.
  • Confirma que el cliente muestra las herramientas p2lrn_list_courses y p2lrn_validate_course.
  • Haz una lectura real de un .p2lrn de la carpeta autorizada. Fuera de ella, el acceso debe rechazarse.
  • Si activaste edición, exporta un nuevo paquete y comprueba que el original conserva su contenido.
  • Si el cliente muestra una versión antigua, revisa su configuración MCP y reinícialo cuando proceda; no reemplaces configuraciones ajenas sin revisarlas.

La alternativa para ChatGPT web, Claude web y Grok web es el conector remoto HTTPS.
