Conectores de IA: ChatGPT, Claude y Grok

ChatGPT, Claude y Grok pueden utilizar las herramientas de P2LRN mediante un mismo servidor MCP. El acceso a cursos existentes requiere una conexión autenticada; generar un paquete nuevo directamente desde una IA es una modalidad diferente.

Dos modalidades: crear un paquete o conectar tus cursos

Crear y descargar .p2lrn

Un creador P2LRN habilitado dentro de una IA puede construir un archivo nuevo a partir de instrucciones y entregarlo como descarga. No necesita conectar tu PC ni consultar cursos privados. Sólo está disponible cuando el asistente tiene incorporada esa capacidad.

Conector MCP a cursos autorizados

El servidor de integration/mcp/ permite enumerar, leer y validar cursos existentes; la edición en borradores se habilita explícitamente. Para una IA web el servidor debe ser accesible en una URL HTTPS protegida; tener un ZIP de plugin no instala ni activa por sí solo el conector.

Estas dos modalidades pueden convivir sin cambiar el formato P2LRN ni crear una versión específica de cada curso para cada IA.

Qué herramientas ofrece el servidor MCP

Consulta

p2lrn_list_courses, p2lrn_read_course, p2lrn_read_entity, p2lrn_read_plan, p2lrn_search_metadata y p2lrn_read_text_member permiten navegar contenido expresamente autorizado.

Validación

p2lrn_validate_course comprueba el paquete. El servidor no ejecuta como código los contenidos de terceros ni interpreta formatos opacos como si fueran nativos.

Autoría controlada

Con permiso de edición se exponen operaciones p2lrn_draft_* para construir unidades, actividades nativas, archivos y componentes y exportar un .p2lrn nuevo. No se sobrescriben paquetes originales.

Preparar la conexión remota segura

  1. Descarga una copia autorizada del repositorio y prepara Node.js 22 o posterior junto con las dependencias de integration/mcp.
  2. Delimita con P2LRN_MCP_ROOT la carpeta que el servidor puede leer. Mantén P2LRN_MCP_WRITE=0 al empezar.
  3. Configura un token aleatorio seguro. El servidor HTTP escucha sólo en 127.0.0.1:37871/mcp; sitúa delante un proxy HTTPS autenticado y ajusta su origen público exacto.
  4. Registra esa URL en cada plataforma cuando su interfaz y plan admitan conectores MCP personalizados. Revisa los permisos antes de conectar.
PowerShell · desde la raíz de P2LRN
$env:P2LRN_MCP_ROOT = 'C:\CursosP2LRN'
$env:P2LRN_MCP_WRITE = '0'
$env:P2LRN_MCP_TOKEN = '<token-aleatorio-de-al-menos-32-bytes>'
$env:P2LRN_MCP_PUBLIC_ORIGIN = 'https://tu-dominio.example'
node .\integration\mcp\server.mjs --http

La dirección https://tu-dominio.example es un marcador, no un servicio desplegado. No abras el puerto 37871 directamente a Internet y no guardes secretos en el repositorio, en un ZIP o en los cursos.

Generación del kit de conectores · carpeta integration/mcp
npm install --ignore-scripts
node prepare-connectors.mjs --endpoint https://tu-dominio.example/mcp --out .generated\connectors

El generador produce chatgpt/p2lrn-plugin.zip, los metadatos de ChatGPT y los archivos de configuración para Claude y Grok. No instala ni publica un conector en una cuenta externa.

ChatGPT

Para crear cursos desde el chat, usa un creador P2LRN habilitado en esa conversación y solicita el fichero descargable. Para consultar o modificar cursos alojados en tu servidor, la cuenta debe tener acceso al registro de un conector MCP personalizado.

  1. En la opción de plugins o conectores personalizados disponible en tu cuenta, elige agregar un servidor MCP.
  2. Indica la URL HTTPS terminada en /mcp y configura el método de autenticación admitido.
  3. Autoriza sólo la carpeta y las herramientas necesarias; comienza con lectura.
  4. Prueba enumerar un curso, leerlo y validarlo antes de permitir la edición.
Estado de publicación

El ZIP preparado es de desarrollo privado. No equivale a un plugin aprobado en el directorio público de ChatGPT. Para un servicio multiusuario faltan OAuth, autorización individual, infraestructura HTTPS estable y revisión del proveedor.

Claude

En Claude web, si tu plan dispone de conectores personalizados, registra un conector MCP web e introduce la URL HTTPS protegida junto con las credenciales. Comprueba que aparece la lista de herramientas del servidor y que un curso autorizado puede abrirse.

La versión Claude Desktop también permite una conexión distinta: ejecuta P2LRN localmente por stdio, sin proxy ni dominio. La instalación está explicada en IA local. No confundas la configuración web con la de escritorio.

Grok

Cuando la cuenta ofrezca conectores personalizados, registra una conexión MCP a la misma URL HTTPS, añade el mecanismo de autenticación admitido y revisa los permisos. En cuentas de organización puede requerirse autorización de un administrador.

El generador crea un archivo grok/connection.json con los parámetros previstos para revisar; no puede activar remotamente tu cuenta ni confirmar que el conector está aprobado.

Pruebas recomendadas y solución de problemas

  • Lectura: ejecuta p2lrn_list_courses, abre un curso permitido y valida el paquete.
  • Escritura: sólo con permiso explícito, crea un borrador, edita un elemento y exporta un archivo nuevo. Verifica que el curso original no cambia.
  • Conexión rechazada: revisa URL HTTPS, token, P2LRN_MCP_PUBLIC_ORIGIN, permisos y opciones disponibles en la cuenta.
  • Aislamiento: comprueba que una carpeta no autorizada no puede leerse y que un cliente sólo lector no recibe operaciones p2lrn_draft_*.
  • No hay endpoint público: un servidor limitado a 127.0.0.1 no es accesible desde los servicios web de terceros.

Para trabajar en tu propio ordenador sin túnel ni URL pública utiliza los conectores locales.
