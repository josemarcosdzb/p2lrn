Conectores para IA

Una sola guía para ChatGPT, Claude, Gemini y Grok. Explica cómo crear cursos P2LRN con Skills sin instalar MCP, cómo conectar cursos existentes desde una aplicación instalada en el PC y cuándo es necesario configurar una conexión remota. No necesitas dominio para crear cursos ni para utilizar un cliente MCP local.

Una IA en la web accediendo a tus cursos locales

Depende de la plataforma. ChatGPT puede utilizar un túnel MCP privado cuando esté habilitado; un conector remoto público necesita HTTPS y autenticación. No confundas esa necesidad con la creación mediante Skills.

Skills sin MCP: crear y descargar cursos

Una Skill es una carpeta de instrucciones y, si hace falta, scripts y referencias. La Skill «P2LRN – Crear y descargar» ya existe en un entorno de ChatGPT; puede construir y verificar paquetes nuevos de un subconjunto P2LRN Core 0.4.0 cuando ese entorno ejecuta Python y permite adjuntar archivos. No es el ZIP del conector MCP. El paquete de Skill no se ofrece todavía como descarga pública desde esta web.

  1. Comprueba que tu plataforma permite instalar o activar Skills y ejecutar el empaquetador; no todas las cuentas o regiones lo permiten.
  2. Activa una Skill P2LRN realmente compatible. Indica título, idioma, unidades, lecciones, preguntas y juegos.
  3. Exige la ejecución del empaquetador y su verificación: el resultado debe ser un .p2lrn descargable, no sólo texto ni un JSON renombrado.
  4. Abre el archivo en Player o Studio. La verificación estructural no sustituye una prueba visual de los juegos 3D.
Ejemplo · para una IA con Skill P2LRN disponible
Usa la Skill P2LRN para crear y verificar un curso nuevo.
Tema: seguridad digital. Idioma: español. 3 unidades,
6 lecciones, 10 preguntas con soluciones y 2 juegos.
Entrega el archivo .p2lrn real y descargable.
No instales MCP ni accedas a archivos de mi ordenador.

Por plataforma: ChatGPT admite Skills según el área de trabajo; Claude permite cargar una Skill ZIP con ejecución de código habilitada; Gemini CLI admite Agent Skills, mientras que la disponibilidad de Skills en Gemini web depende de la cuenta y región. Grok no dispone aquí de una Skill P2LRN ejecutable certificada. Limitaciones y guía ampliada de Skills.

ChatGPT

Crear cursos sin MCP

  1. En ChatGPT, abre las opciones de Skills/Habilidades disponibles en tu cuenta o área de trabajo y busca «P2LRN – Crear y descargar». Si no aparece, su instalación o distribución en esa cuenta no está confirmada.
  2. Con la Skill habilitada, describe el curso y solicita el .p2lrn. No necesitas instalar Node.js en tu PC ni registrar un servidor.
  3. Comprueba que la Skill ha ejecutado su verificador y que puedes abrir el archivo descargado. No basta con que el asistente diga que lo ha creado.

Conectar cursos del PC

Para consultar los cursos guardados en Windows desde ChatGPT web, una Skill sola no da acceso al PC. Cuando tu cuenta y organización admitan servidores MCP personalizados, usa Secure MCP Tunnel o un endpoint HTTPS autenticado. ChatGPT web no puede conectar directamente con localhost. En la aplicación Desktop pueden existir plugins locales stdio sujetos a requisitos independientes; el ZIP MCP no instala automáticamente uno.

Prueba · ChatGPT con MCP autorizado
Muestra únicamente los cursos P2LRN de mi carpeta autorizada,
llama a p2lrn_list_courses y valida el que elija con
p2lrn_validate_course. No modifiques los originales.

Estado: Skill P2LRN comprobada en un entorno de ChatGPT, pero no publicada universalmente; proveedor MCP privado y generación de descriptores de desarrollo, sin certificación de un plugin público de directorio. Ayuda oficial sobre Skills.

Claude

Sin MCP: Claude Skills

  1. Activa la opción de ejecución de código y creación de archivos cuando tu plan permita Skills.
  2. En Personalizar → Habilidades/Skills, utiliza la opción de importar una Skill ZIP autorizada; revisa su SKILL.md y scripts antes de subirla.
  3. Solicita un curso P2LRN y comprueba que Claude ha ejecutado un empaquetador compatible, verificado el archivo y adjuntado el .p2lrn.

Importante: el ZIP de MCP de esta web no es una Skill. La Skill P2LRN de ChatGPT no se ha certificado como empaquetador autónomo en Claude; hace falta comprobar el entorno y el resultado. Instrucciones oficiales de Skills en Claude.

Con MCP: Claude Desktop y Claude web

Para acceder a los cursos del PC desde Claude Desktop, instala el kit MCP P2LRN, ejecuta Conectar-P2LRN.cmd y selecciona Claude. El transporte es stdio y no necesita dominio. Claude web requiere que la cuenta admita conectores remotos y que el servidor sea accesible y esté autenticado; un proceso local no se registra en la web directamente.

Prueba · Claude Desktop con MCP
Lee el índice de mi curso P2LRN autorizado.
Comprueba sus actividades y prepara un plan de mejora.
No edites el curso si el conector sólo tiene lectura.

Comprobación: exige una llamada real a p2lrn_list_courses o p2lrn_read_course, comprueba que se respetan los permisos y valida un paquete. Instalación local detallada.

Gemini

Gemini web: Skills o Gems, sin MCP

Gemini web no es Gemini CLI. Cuando tu cuenta y región tengan disponibles Skills de Gemini, puedes preparar instrucciones reutilizables para cursos P2LRN. Si no aparecen, las Gems permiten mantener instrucciones y referencias. Una Gem no ejecuta por sí sola el empaquetador; si la sesión no puede crear y verificar el archivo, prepara el contenido y termínalo en Studio.

Gemini CLI: Agent Skills sin MCP

Gemini CLI reconoce Skills en ~/.gemini/skills/ y .gemini/skills/. En la sesión de Gemini CLI puedes utilizar /skills list para comprobar cuáles están disponibles y /skills link para enlazar una carpeta local autorizada. Es necesario instalar Gemini CLI, pero no el servidor MCP P2LRN cuando sólo quieres crear un curso nuevo. Debes comprobar que la Skill ejecuta un empaquetador y verifica el .p2lrn.

Gemini CLI · dentro de una sesión
/skills list
/skills link C:\Ruta\a\skill-p2lrn --scope user
/skills list

Gemini CLI con MCP local (opcional)

Para leer, validar o editar borradores que ya tienes en el PC, utiliza el mismo ZIP MCP y el asistente para Gemini CLI. Empieza con sólo lectura; configura la carpeta autorizada y verifica las herramientas.

Windows · desde el kit P2LRN extraído
.\integration\mcp\Conectar-P2LRN.cmd --root C:\MisCursos --clients gemini --install --verify

Prueba: solicita a Gemini CLI «Lista mis cursos P2LRN autorizados y valida uno sin modificarlo». Verifica en el cliente que invoca p2lrn_list_courses y p2lrn_validate_course. La compatibilidad de la Skill P2LRN con Gemini web no está certificada, ni Gemini web ejecuta directamente este MCP stdio. Guía detallada Gemini web/CLI y Agent Skills oficiales de Gemini CLI.

Grok

Crear cursos sin un conector MCP

Grok puede ayudar a estructurar lecciones, preguntas y juegos mediante instrucciones, pero no existe aquí una Skill P2LRN de Grok certificada para empaquetar y validar archivos. Si no puede ejecutar un empaquetador real, utiliza Studio para crear el .p2lrn a partir del contenido preparado. No se anuncia una instalación de Skill inexistente.

Conector MCP personalizado

Grok admite conectores MCP personalizados en los entornos y cuentas que ofrecen esa función. En Grok → Connectors → New Connector → Custom, registra la URL de un servidor MCP accesible desde Internet y autenticado. Un proceso que escucha sólo en tu PC no es accesible desde Grok web: requiere una solución remota o túnel compatible. Documentación oficial de Grok Connectors.

El kit MCP de P2LRN contiene un generador de parámetros de conexión, pero esos descriptores no activan la cuenta ni certifican la integración en Grok.

Prueba · Grok cuando el MCP esté conectado
Enumera sólo mis cursos P2LRN autorizados.
Haz un resumen del curso que seleccione y valida
el archivo con p2lrn_validate_course, sin editarlo.

Comprobación: asegúrate de que Grok muestra las herramientas reales, ejecuta la consulta y rechaza rutas fuera de la carpeta autorizada. Si tu cuenta no muestra conectores personalizados, no se ha establecido esa conexión.

MCP local para aplicaciones de IA instaladas en tu PC

Este apartado es opcional si sólo utilizas Skills. Sirve para Claude Desktop, Gemini CLI, Cursor, Windsurf, VS Code y otros clientes MCP stdio compatibles. No requiere una web, un dominio ni abrir puertos entrantes.

Descargar MCP P2LRN para Windows (.zip)Ver SHA-256 del ZIPGuía local completa
  1. Descarga y descomprime el kit, e instala Node.js 22 o posterior. No ejecutes el asistente dentro del ZIP comprimido.
  2. Abre integration/mcp/Conectar-P2LRN.cmd desde la carpeta extraída y selecciona la aplicación compatible que tengas instalada.
  3. Elige una carpeta concreta de cursos. Mantén P2LRN_MCP_WRITE=0 y revisa cualquier cambio de configuración antes de aceptarlo.
  4. Reinicia el cliente cuando corresponda y comprueba p2lrn_list_courses y p2lrn_validate_course. Para crear borradores autoriza expresamente la escritura; los originales no deben sobrescribirse.
Windows · desde la carpeta donde extrajiste P2LRN
cd C:\P2LRN-MCP
.\integration\mcp\Conectar-P2LRN.cmd

C:\P2LRN-MCP es sólo una ruta de ejemplo. El servidor se ejecuta bajo demanda con transporte stdio. El ZIP MCP no es un plugin de ChatGPT aprobado ni el archivo de una Skill.

ChatGPT web conectado a un PC: túnel privado opcional

ChatGPT web no puede abrir directamente localhost. Cuando tu cuenta y área de trabajo tengan permisos para Secure MCP Tunnel, puedes ejecutar el MCP P2LRN en el PC y establecer una conexión saliente autorizada, sin contratar un dominio ni abrir puertos entrantes.

  1. Instala el MCP local de P2LRN con lectura y comprueba las herramientas en el ordenador.
  2. Crea o selecciona un tunnel_id en la configuración de túneles MCP de OpenAI Platform, con permisos del área de trabajo correspondiente.
  3. Descarga y configura el tunnel-client oficial con un perfil que lance node .../integration/mcp/server.mjs --stdio. No guardes claves en GitHub ni en los cursos.
  4. Ejecuta la comprobación con tunnel-client doctor --profile p2lrn-local --explain y el cliente con tunnel-client run --profile p2lrn-local; el nombre del perfil es un ejemplo.
  5. En ChatGPT registra el servidor MCP mediante Túnel si esa opción está disponible y realiza una llamada real a p2lrn_list_courses. No se considera configurado hasta comprobar la llamada.

El túnel requiere instalación y autorización aparte; no forma parte del ZIP MCP ni crea automáticamente un plugin público.

Opcional: preparar un servidor MCP remoto mediante HTTPS

No es necesario para Skills ni clientes MCP locales. Un endpoint HTTP remoto es útil cuando una IA web requiere un servidor accesible públicamente y su cuenta admite MCP personalizado. Configura un proxy HTTPS autenticado, aislamiento de carpetas y controles de acceso: no abras el puerto local directamente a Internet.

  1. Prepara Node.js 22 o posterior y las dependencias de integration/mcp en una instalación autorizada.
  2. Define P2LRN_MCP_ROOT con la carpeta que se puede leer, mantén P2LRN_MCP_WRITE=0 y crea un token seguro.
  3. El servidor escucha en 127.0.0.1:37871/mcp; configura por delante un proxy HTTPS autenticado y una URL pública real o un túnel HTTPS compatible.
  4. Registra la URL sólo en proveedores que admitan conectores personalizados. Prueba autenticación, aislamiento y permisos antes de habilitar escritura.
PowerShell · ejemplo de servidor HTTP protegido
$env:P2LRN_MCP_ROOT = 'C:\CursosP2LRN'
$env:P2LRN_MCP_WRITE = '0'
$env:P2LRN_MCP_TOKEN = '<token-aleatorio-seguro>'
$env:P2LRN_MCP_PUBLIC_ORIGIN = 'https://tu-endpoint.example'
node .\integration\mcp\server.mjs --http
Opcional · generar descriptores de conectores
cd integration\mcp
npm install --ignore-scripts
node prepare-connectors.mjs --endpoint https://tu-endpoint.example/mcp --out .generated\connectors

Los dominios .example son marcadores, no servicios desplegados. El generador produce descriptores de desarrollo para ChatGPT, Claude y Grok, pero no instala conectores en cuentas externas ni concede acceso automático. Para Gemini web no se anuncia un conector remoto no certificado.

Ejemplos prácticos de cada plataforma

ChatGPT

Sin MCP: «Crea y verifica un curso P2LRN de tres unidades y adjunta el .p2lrn». Con MCP: «Lista y valida los cursos autorizados». El resultado tiene que ser un archivo descargable o llamadas reales a las herramientas, respectivamente.

Claude

Con Skill: «Genera un curso y entrega el archivo verificado, no sólo el temario». Con MCP local: «Revisa este curso en lectura y prepara recomendaciones». No permitas edición sin autorización.

Gemini

Gemini web Skills/Gems: «Diseña el curso y empaquétalo sólo si dispones de una herramienta verificable». Gemini CLI: «Utiliza la Skill autorizada para generar el paquete» o, mediante MCP, «Lista mis cursos y valida uno».

Grok

Sin MCP: «Prepara el contenido del curso sin afirmar que has creado el ZIP». Con MCP remoto: «Lista y valida los cursos de mi carpeta autorizada». Confirma que el conector realmente ha llamado al servidor.

Pruebas recomendadas y solución de problemas

  • La Skill no aparece: comprueba habilitación y permisos del proveedor. No confundas la Skill con el ZIP MCP de la web. La Skill P2LRN actual no dispone de una descarga pública certificada aquí.
  • La IA responde con JSON, pero no hay .p2lrn: todavía no ha ejecutado ni verificado el empaquetador; no declares completada la creación.
  • Gemini web no muestra Skills: revisa región, cuenta y despliegue. Puedes utilizar Gems para diseñar, pero no garantiza empaquetado.
  • El cliente local no muestra herramientas: comprueba Node, carpeta autorizada, configuración stdio y reinicia el cliente si hace falta.
  • ChatGPT web no accede al PC: localhost no es accesible directamente. Revisa autorización y estado del túnel o endpoint remoto.
  • Claude web o Grok no conectan: confirma que la cuenta permite MCP personalizado, que el endpoint HTTPS es accesible y que la autenticación es válida.
  • Lectura o edición: comprueba que sólo se leen los cursos de la carpeta permitida, que un cliente de sólo lectura no tiene herramientas de escritura y que los borradores no sobrescriben originales.
  • Validación: ejecuta p2lrn_list_courses y p2lrn_validate_course en conexiones MCP; con Skills, verifica el archivo ZIP P2LRN y prueba la reproducción en Player.
