Conectores para IA

Utiliza P2LRN con ChatGPT, Claude, Gemini o Grok. Aquí encontrarás cómo crear un curso desde una conversación o cómo trabajar con archivos que ya tienes en tu ordenador, con instrucciones específicas para cada plataforma.

¿Qué quieres hacer?

Crear un curso nuevo

Utiliza una Skill para que la IA prepare el contenido y, si dispone de las herramientas necesarias, genere un archivo .p2lrn descargable. No necesita acceder a tus carpetas.

Consultar o modificar cursos existentes

Utiliza un conector MCP para dar acceso a una carpeta concreta y a las herramientas autorizadas. Puedes comenzar con permisos de lectura y habilitar borradores más adelante.

Son mecanismos diferentes. Una Skill proporciona instrucciones y scripts para una tarea; MCP permite que una aplicación invoque herramientas de P2LRN. Ninguno sustituye al Player o al editor visual Studio. Primero elige la plataforma; después sigue únicamente la instalación que corresponda.

Crear y descargar un curso con una Skill

La Skill «P2LRN – Crear y descargar» está disponible en un entorno de ChatGPT y puede crear y verificar paquetes nuevos del subconjunto Core 0.4.0. Su disponibilidad para otras cuentas y la ejecución equivalente en Claude o Gemini deben comprobarse; no se ofrece aquí una descarga pública independiente de esa Skill.

  1. En tu aplicación de IA, abre la función de Skills y comprueba que tienes instalada una versión compatible con P2LRN.
  2. Indica el título, idioma, estructura, preguntas y juegos. Pide que el resultado sea un archivo real y no solo un esquema de contenido.
  3. Comprueba que se ha ejecutado el empaquetador y el validador. Descarga el .p2lrn y pruébalo en Player o Studio.
Ejemplo para una IA con la Skill P2LRN instalada
Crea un curso P2LRN en español sobre seguridad digital:
3 unidades, 6 lecciones, 10 preguntas y 2 juegos.
Ejecuta el empaquetador P2LRN y valida el resultado.
Entrégame el archivo .p2lrn descargable.

Si la aplicación no puede ejecutar el empaquetador, puede ayudarte a diseñar el contenido, pero no debe afirmar que ha generado un paquete válido. La creación visual completa sigue disponible en Studio.

ChatGPT

Crear cursos

Con la Skill «P2LRN – Crear y descargar» instalada y habilitada, escribe el encargo en la conversación y solicita el archivo verificado. La disponibilidad de Skills depende de la configuración y permisos de tu cuenta o área de trabajo. Ayuda oficial de Skills.

Trabajar con los cursos del ordenador

ChatGPT en el navegador no puede abrir directamente localhost. Para usar el conector privado desde ChatGPT, revisa la opción de túnel seguro cuando esté habilitada en tu cuenta. También existen servidores MCP accesibles mediante HTTPS con autenticación. La conexión no está instalada automáticamente y no equivale a un plugin público aprobado.

Comprobación: pide «Lista mis cursos P2LRN autorizados y valida el que elija». Debes ver una invocación real de p2lrn_list_courses y p2lrn_validate_course, no una respuesta inventada.

Claude

Crear cursos

Claude admite Skills personalizadas en los entornos que tienen habilitada esa función. Revisa la Skill antes de importarla y confirma que sus scripts pueden ejecutarse y entregar archivos. La Skill P2LRN existente en ChatGPT no está certificada automáticamente para Claude. Guía oficial de Claude Skills.

Trabajar con los cursos del ordenador

En Claude Desktop, puedes utilizar el conector local: selecciona Claude en el asistente, autoriza una carpeta y comienza con lectura. En Claude web, las conexiones externas dependen del plan y de los conectores personalizados admitidos.

Comprobación: pide «Lee el índice de este curso y prepara propuestas de mejora; no modifiques los originales». Comprueba que el cliente accede al curso autorizado y respeta los permisos.

Gemini

Gemini en el navegador

Gemini web dispone de funciones de personalización como Gems y, según cuenta, región y despliegue, Skills. Estas opciones pueden preparar el contenido del curso, pero para descargar un .p2lrn la sesión debe poder ejecutar y verificar un empaquetador compatible. No se ha certificado aquí la Skill P2LRN en Gemini web.

Gemini CLI

Gemini CLI admite Agent Skills mediante archivos SKILL.md. Puedes comprobarlas desde la consola con gemini skills list y enlazar una carpeta de Skill autorizada. Para consultar cursos de tu ordenador también puedes configurar el conector P2LRN seleccionando Gemini CLI. Son opciones distintas.

PowerShell · conectar Gemini CLI a tus cursos
.\integration\mcp\Conectar-P2LRN.cmd --root C:\MisCursos --clients gemini --install --verify

C:\MisCursos es una ruta de ejemplo que debe existir. Ejecuta el comando desde la carpeta donde has extraído el kit MCP. Comprobación: pide a Gemini CLI que liste y valide un curso autorizado, y verifica que aparecen las llamadas MCP.

Grok

Crear contenido

Puedes utilizar Grok para preparar lecciones, preguntas y juegos. Actualmente no hay una Skill P2LRN de Grok certificada que permita prometer la creación y validación automática de un archivo descargable. Si no ejecuta un empaquetador, completa el curso en Studio.

Conectar cursos

Cuando tu cuenta admita conectores MCP personalizados, consulta las opciones de Grok Connectors y registra un servidor accesible de forma segura. El kit P2LRN permite generar descriptores de conexión; no instala el conector en tu cuenta ni acredita que haya sido aprobado.

Comprobación: pide «Lista mis cursos P2LRN autorizados y valida uno sin editarlo». Comprueba que Grok realmente utiliza las herramientas y respeta la carpeta permitida.

Instalar el conector en tu ordenador

El conector permite que una aplicación compatible trabaje con los cursos guardados en una carpeta de tu PC. Funciona con clientes como Claude Desktop, Gemini CLI, Cursor, Windsurf y VS Code. No necesitas disponer de una web ni comprar un dominio.

Descargar conector P2LRN (.zip)Comprobar SHA-256
  1. Instala Node.js 22 o posterior y descomprime el ZIP en una carpeta del ordenador.
  2. Ejecuta integration\mcp\Conectar-P2LRN.cmd. Elige la aplicación de IA instalada que quieras utilizar.
  3. Selecciona una carpeta de cursos y empieza con permisos de lectura (P2LRN_MCP_WRITE=0). Autoriza la escritura solo cuando la necesites.
  4. Reinicia la aplicación si lo solicita y prueba que puede listar y validar uno de tus cursos.
Windows · desde la carpeta donde has extraído P2LRN
cd C:\P2LRN-MCP
.\integration\mcp\Conectar-P2LRN.cmd

C:\P2LRN-MCP es una ruta de ejemplo. El asistente configura los clientes compatibles después de pedir autorización; el ZIP no es una Skill ni un plugin público.

Conectar desde un servicio web

Cuando utilizas la IA desde su página web, el servicio no puede leer directamente los archivos de tu PC. Necesita una conexión privada autorizada o un servidor accesible mediante HTTPS. Solo prepara esta conexión si vas a trabajar con cursos existentes desde un servicio remoto.

ChatGPT: túnel privado

Secure MCP Tunnel permite conectar un servidor MCP local a ChatGPT si tu cuenta y área de trabajo disponen de acceso. El cliente del túnel se instala y autoriza por separado; no es parte del ZIP P2LRN.

Servidor HTTPS

Para proveedores que admitan conectores MCP remotos, configura el servidor de P2LRN detrás de un proxy HTTPS autenticado. Nunca expongas directamente el puerto local ni compartas credenciales en los paquetes.

Servidor MCP HTTP · ejemplo avanzado
$env:P2LRN_MCP_ROOT = 'C:\CursosP2LRN'
$env:P2LRN_MCP_WRITE = '0'
$env:P2LRN_MCP_TOKEN = '<token-aleatorio-seguro>'
$env:P2LRN_MCP_PUBLIC_ORIGIN = 'https://tu-endpoint.example'
node .\integration\mcp\server.mjs --http

https://tu-endpoint.example es un marcador y no un servicio publicado. El servidor local escucha en 127.0.0.1:37871/mcp; para una URL pública necesitas configurar y proteger el proxy. Un túnel privado de ChatGPT requiere su propia configuración y comprobación.

Comprobaciones y problemas frecuentes

  • La IA no entrega el archivo: comprueba que la Skill ejecuta un empaquetador y devuelve un .p2lrn válido. Una respuesta de texto o JSON no basta.
  • No aparecen tus cursos: revisa la carpeta autorizada, el cliente MCP y que la aplicación haya cargado la configuración.
  • La web no conecta con tu PC: comprueba la disponibilidad del túnel o del endpoint HTTPS y los permisos de tu cuenta; localhost no es accesible desde una web externa.
  • La aplicación no puede editar: verifica los permisos. La lectura es el modo inicial; los borradores requieren autorización explícita.
  • Prueba mínima: ejecuta p2lrn_list_courses y p2lrn_validate_course, verifica el rechazo de rutas no autorizadas y confirma que el archivo original no cambia.

Si quieres crear o editar un curso manualmente, puedes utilizar Studio. Para reproducirlo y comprobar sus actividades, utiliza Player.
