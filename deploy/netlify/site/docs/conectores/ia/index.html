CONECTORES / IA WEB

Conectores de IA: ChatGPT, Claude y Grok

P2LRN utiliza un mismo servidor MCP para herramientas de IA. Si quieres trabajar con los cursos guardados en tu PC, no necesitas tener una web ni comprar un dominio. La conexión cambia según uses una aplicación instalada en el ordenador o una IA en la nube.

Si sólo quieres crear un curso, utiliza una Skill sin MCP

Para crear y descargar un archivo .p2lrn nuevo, no necesitas instalar el servidor MCP, conectar tu ordenador ni contratar un dominio. Ya existe una Skill «P2LRN – Crear y descargar» en un entorno de ChatGPT; puede producir un paquete Core 0.4.0 y verificarlo cuando está habilitada. Ver la guía de Skills sin MCP.

Esta vía no ofrece acceso automático a cursos privados del PC. Para otras plataformas, Gemini web y CLI dispone de Skills/Gems y Claude permite Skills según el entorno; hay que comprobar que realmente generan y verifican el paquete, sin asumir paridad universal.

Elige cómo conectar P2LRN a tu ordenador

1. Aplicación de IA instalada en tu PC · sin dominio

Claude Desktop, Cursor, Windsurf, Gemini CLI, VS Code y otros clientes compatibles pueden iniciar el MCP mediante stdio. Los cursos permanecen en una carpeta autorizada del ordenador; no necesitas una URL, proxy ni puerto abierto.Conectar en mi PCGuía local completa

2. ChatGPT web → cursos de tu PC · sin dominio propio

ChatGPT web no puede iniciar directamente un proceso de tu PC ni acceder a localhost. Si tienes los permisos necesarios, Secure MCP Tunnel conecta un MCP privado mediante una conexión saliente, sin exponer tu ordenador a Internet ni tener un dominio. El túnel no está incluido ni configurado automáticamente en el ZIP.Conectar ChatGPT al PC

3. Servicio MCP público en HTTPS · opcional

Un servidor accesible en Internet puede servir a clientes MCP web que lo admitan. Necesita una URL HTTPS y autenticación; no es un requisito para la conexión local ni para un Secure MCP Tunnel privado.Configuración remota avanzada

Descargar el conector MCP para tu PC o para IA web

El mismo ZIP contiene el servidor MCP, Toolkit, integration/mcp/Conectar-P2LRN.cmd para Windows y herramientas de configuración. Para uso local no tienes que registrar una URL ni preparar un dominio. No contiene claves de terceros ni instala por sí solo un conector en ninguna cuenta web.

Descargar kit MCP (.zip)Comprobar integridad SHA-256
  1. Descomprime el ZIP y consulta LEEME-PRIMERO.md. Instala Node.js 22 o posterior.
  2. Si utilizarás una aplicación de IA en tu ordenador, abre integration/mcp/Conectar-P2LRN.cmd, elige tu carpeta de cursos y el cliente instalado. Empieza en sólo lectura.
  3. Si utilizarás ChatGPT web para consultar cursos del PC, sigue el apartado de Secure MCP Tunnel. No necesitas dominio propio, pero sí una configuración de túnel autorizada.
  4. Sólo si quieres publicar un endpoint MCP accesible desde Internet, configura aparte un proxy HTTPS con autenticación y sigue la sección remota avanzada.
  5. En todos los casos, comprueba p2lrn_list_courses y p2lrn_validate_course con archivos dentro de la carpeta autorizada.
El ZIP no es un plugin publicado

El asistente instala configuraciones locales sólo en clientes compatibles y con confirmación. ChatGPT web necesita un MCP remoto o un Secure MCP Tunnel autorizado. Los ZIP de descriptores no son plugins aprobados en directorios públicos.

Dos necesidades distintas: crear un paquete o conectar tus cursos

Crear y descargar .p2lrn mediante Skill

La Skill «P2LRN – Crear y descargar» instalada en un entorno compatible de ChatGPT crea y verifica paquetes nuevos sin servidor MCP, Node en tu PC ni carpetas compartidas. Requiere que la Skill esté habilitada y que el entorno ejecute su empaquetador. Ver requisitos y límites.

Conector MCP a cursos autorizados

El servidor de integration/mcp/ permite enumerar, leer y validar cursos existentes; la edición en borradores se habilita explícitamente. Para una IA web el servidor debe ser accesible en una URL HTTPS protegida; tener un ZIP de plugin no instala ni activa por sí solo el conector.

Estas dos modalidades pueden convivir sin cambiar el formato P2LRN ni crear una versión específica de cada curso para cada IA.

Qué herramientas ofrece el servidor MCP

Consulta

p2lrn_list_courses, p2lrn_read_course, p2lrn_read_entity, p2lrn_read_plan, p2lrn_search_metadata y p2lrn_read_text_member permiten navegar contenido expresamente autorizado.

Validación

p2lrn_validate_course comprueba el paquete. El servidor no ejecuta como código los contenidos de terceros ni interpreta formatos opacos como si fueran nativos.

Autoría controlada

Con permiso de edición se exponen operaciones p2lrn_draft_* para construir unidades, actividades nativas, archivos y componentes y exportar un .p2lrn nuevo. No se sobrescriben paquetes originales.

Conectar una IA instalada en tu PC — sin dominio

Esta es la opción adecuada si quieres abrir y editar cursos almacenados en tu ordenador desde un cliente MCP compatible. Descarga el ZIP anterior, extráelo, instala Node.js 22 o posterior y abre con doble clic integration/mcp/Conectar-P2LRN.cmd. El asistente prepara Toolkit y dependencias, te pregunta qué carpeta autorizas y qué aplicaciones quieres configurar. No necesita HTTPS ni un servidor en segundo plano.

Windows · instalación local con asistente
cd C:\P2LRN-MCP
.\integration\mcp\Conectar-P2LRN.cmd

C:\P2LRN-MCP es una ruta de ejemplo: sustitúyela por la carpeta donde extrajiste el ZIP. Comienza con P2LRN_MCP_WRITE=0. El cliente inicia el servidor mediante node ...\server.mjs --stdio y sólo accede a la carpeta seleccionada. Para activar borradores posteriormente hay que conceder permiso explícito; no se sobrescriben los paquetes originales.

Instalación local paso a paso y clientes compatibles

ChatGPT web conectado a tu PC, sin dominio propio

Si lo que quieres es utilizar ChatGPT en el navegador para consultar los archivos P2LRN del PC, la conexión local stdio no basta por sí sola. ChatGPT admite Secure MCP Tunnel cuando tu cuenta, tu organización y tu área de trabajo tienen los permisos necesarios. El conector se ejecuta en tu PC y el cliente del túnel mantiene una conexión saliente HTTPS con OpenAI; no necesitas contratar un dominio ni abrir puertos entrantes.

  1. Instala el conector P2LRN local del ZIP y verifica sus herramientas con lectura y una carpeta de cursos autorizada.
  2. En OpenAI Platform, accede a la configuración de túneles MCP y crea o selecciona uno que esté asociado a tu área de trabajo de ChatGPT. Necesitas permisos de túneles y de creación de complementos MCP.
  3. Instala tunnel-client desde el enlace de descargas oficial, revisa tunnel-client help quickstart y configura el perfil con el tunnel_id y el comando stdio de P2LRN. Las credenciales se introducen localmente; nunca se copian al HTML, a GitHub o al ZIP.
  4. Comprueba el perfil con tunnel-client doctor --profile p2lrn-local --explain y mantenlo funcionando con tunnel-client run --profile p2lrn-local. El nombre p2lrn-local es sólo un ejemplo de perfil.
  5. En ChatGPT abre Complementos → Añadir servidor MCP personalizado → Túnel, selecciona el mismo tunnel_id, configura la autorización y valida una llamada real a p2lrn_list_courses. Si las opciones no aparecen, revisa los permisos de tu cuenta o área de trabajo.

Estado: P2LRN ya proporciona el servidor stdio. Secure MCP Tunnel es una integración adicional de OpenAI que requiere instalación y configuración propias; no se debe anunciar como conectado hasta completar una llamada real desde ChatGPT. Para distribuir un plugin públicamente siguen aplicándose requisitos distintos.

ChatGPT Desktop

Los plugins locales stdio para la aplicación de escritorio son una vía diferente y dependen de la disponibilidad y aprobación de la función correspondiente. El ZIP P2LRN no es, por sí mismo, un plugin ChatGPT Desktop instalado o aprobado. Consulta la documentación oficial de plugins Desktop only.

Opcional: preparar un servidor MCP remoto mediante HTTPS

Ignora esta sección si sólo conectarás una aplicación instalada en tu PC o utilizarás Secure MCP Tunnel con stdio. Estas instrucciones son exclusivamente para servir un endpoint HTTP a clientes web remotos y requieren infraestructura y autenticación adicionales.

  1. Descarga una copia autorizada del repositorio y prepara Node.js 22 o posterior junto con las dependencias de integration/mcp.
  2. Delimita con P2LRN_MCP_ROOT la carpeta que el servidor puede leer. Mantén P2LRN_MCP_WRITE=0 al empezar.
  3. Configura un token aleatorio seguro. El servidor HTTP escucha sólo en 127.0.0.1:37871/mcp; sitúa delante un proxy HTTPS autenticado y ajusta su origen público exacto.
  4. Registra esa URL en cada plataforma cuando su interfaz y plan admitan conectores MCP personalizados. Revisa los permisos antes de conectar.
PowerShell · desde la raíz de P2LRN
$env:P2LRN_MCP_ROOT = 'C:\CursosP2LRN'
$env:P2LRN_MCP_WRITE = '0'
$env:P2LRN_MCP_TOKEN = '<token-aleatorio-de-al-menos-32-bytes>'
$env:P2LRN_MCP_PUBLIC_ORIGIN = 'https://tu-dominio.example'
node .\integration\mcp\server.mjs --http

La dirección https://tu-dominio.example es un marcador, no un servicio desplegado. No abras el puerto 37871 directamente a Internet y no guardes secretos en el repositorio, en un ZIP o en los cursos.

Generación del kit de conectores · carpeta integration/mcp
npm install --ignore-scripts
node prepare-connectors.mjs --endpoint https://tu-dominio.example/mcp --out .generated\connectors

El generador produce chatgpt/p2lrn-plugin.zip, los metadatos de ChatGPT y los archivos de configuración para Claude y Grok. No instala ni publica un conector en una cuenta externa.

ChatGPT

Para crear cursos descargables desde una conversación no necesitas conectar tu PC cuando el creador P2LRN ya está habilitado. Para trabajar sobre archivos locales desde ChatGPT web puedes usar un Secure MCP Tunnel privado con permisos adecuados, sin dominio propio; la otra alternativa es un endpoint HTTPS remoto. ChatGPT web no conecta directamente con localhost.

  1. En la opción de complementos MCP personalizados disponible en tu cuenta, elige agregar un servidor MCP.
  2. Selecciona Túnel para un MCP privado en tu PC, o introduce una URL HTTPS terminada en /mcp si has desplegado un servidor remoto; configura la autenticación correspondiente.
  3. Autoriza sólo la carpeta y las herramientas necesarias; comienza con lectura.
  4. Prueba enumerar un curso, leerlo y validarlo antes de permitir la edición.
Estado de publicación

El ZIP preparado es de desarrollo privado. No equivale a un plugin aprobado en el directorio público de ChatGPT. Para un servicio multiusuario faltan OAuth, autorización individual, infraestructura HTTPS estable y revisión del proveedor.

Claude

En Claude web, si tu plan dispone de conectores personalizados, registra un conector MCP web e introduce la URL HTTPS protegida junto con las credenciales. Comprueba que aparece la lista de herramientas del servidor y que un curso autorizado puede abrirse.

La versión Claude Desktop también permite una conexión distinta: ejecuta P2LRN localmente por stdio, sin proxy ni dominio. La instalación está explicada en IA local. No confundas la configuración web con la de escritorio.

Grok

Cuando la cuenta ofrezca conectores personalizados, registra una conexión MCP a la misma URL HTTPS, añade el mecanismo de autenticación admitido y revisa los permisos. En cuentas de organización puede requerirse autorización de un administrador.

El generador crea un archivo grok/connection.json con los parámetros previstos para revisar; no puede activar remotamente tu cuenta ni confirmar que el conector está aprobado.

Ejemplo práctico en cada plataforma

ChatGPT

Tras conectar el servidor, solicita: «Lista los cursos P2LRN autorizados y valida el paquete que elija». Para crear un paquete desde cero sin conexión, usa un creador P2LRN habilitado en ChatGPT y descarga el resultado; son recorridos independientes.

Claude

Después de autorizar el MCP web, solicita: «Lee el índice de mi curso P2LRN y prepara un plan de mejoras en un borrador». Si la conexión sólo permite lectura, el cliente debe explicar que no puede editar.

Grok

Comprueba que el conector muestra las herramientas de lectura y solicita un resumen de un curso autorizado. La configuración depende de las opciones de conectores habilitadas por la cuenta.

En los tres casos, comprueba primero la respuesta real de p2lrn_list_courses y después p2lrn_validate_course. No consideres suficiente que aparezca el nombre del conector en la interfaz.

Pruebas recomendadas y solución de problemas

  • Lectura: ejecuta p2lrn_list_courses, abre un curso permitido y valida el paquete.
  • Escritura: sólo con permiso explícito, crea un borrador, edita un elemento y exporta un archivo nuevo. Verifica que el curso original no cambia.
  • Conexión rechazada: para un cliente local revisa Node, la carpeta autorizada y el proceso stdio; para un túnel revisa tunnel-client doctor, su identificador y sus permisos; para un endpoint público revisa URL HTTPS, token, P2LRN_MCP_PUBLIC_ORIGIN y proxy.
  • Aislamiento: comprueba que una carpeta no autorizada no puede leerse y que un cliente sólo lector no recibe operaciones p2lrn_draft_*.
  • No hay endpoint público: 127.0.0.1 no es accesible directamente desde una IA web, pero un túnel privado compatible puede conectar ambos extremos sin abrir un puerto público.

Para trabajar en tu propio ordenador sin túnel ni URL pública utiliza los conectores locales.
