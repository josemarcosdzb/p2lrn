Ejemplos

Paquetes del repositorio, artefactos externos preservados y fixtures de documentación generados y verificados durante el deploy.

Qué significa canónico

El deploy publica el árbol completo de examples/canonical/ y abre/verifica cada .p2lrn antes de producir el catálogo.

Canónico no significa siempre «ejecutable».

Un artefacto externo puede demostrar lectura o preservación sin afirmar autoría o deliver completo. La matriz de capacidades sigue siendo la autoridad.
