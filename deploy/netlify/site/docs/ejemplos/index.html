Ejemplos

Paquetes de referencia para abrir en el visor, revisar estructuras y probar las distintas presentaciones disponibles.

Cómo usar los ejemplos

Abre un paquete en el visor para comprobar su estructura y comportamiento. Los ejemplos de interoperabilidad muestran formatos que P2LRN puede conservar o reproducir; no todos implican autoría completa dentro del editor.
