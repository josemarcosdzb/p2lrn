REFERENCIA / EJEMPLOS

Ejemplos

Paquetes de referencia para abrir en el visor, revisar estructuras y probar las distintas presentaciones disponibles.

Cómo usar los ejemplos

Cada ejemplo puede abrirse en el visor y el archivo .p2lrn puede descargarse para probarlo en otra integración. Los ejemplos de interoperabilidad muestran formatos que P2LRN puede conservar o reproducir; no todos implican autoría completa dentro del editor.

Paquetes reales y gratuitos de distintos formatos

Ejemplos importados de proyectos externos con procedencia y licencias documentadas. Puedes filtrar el catálogo, abrir cada paquete en Player y descargar su original encapsulado en .p2lrn. Algunos perfiles se reproducen parcialmente; la compatibilidad integral de SCORM 2004, QTI 3, H5P y cmi5 no está certificada.

Cargando muestras verificadas…

Catálogo procesable

/examples/catalog.json contiene profiles, entrypoints, packageId, tamaño y renderizador cuando procede. El visor lo consume directamente, sin una segunda lista codificada manualmente.
