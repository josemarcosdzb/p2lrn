Conceptos fundamentales

Las ideas que conviene entender antes de tocar la API: paquete, grafo, entrypoints, host, integridad, autoría y runtime.

Package → Verify → Render

PACKAGE

Un contenedor portable con curso, recursos y metadatos.

VERIFY

Comprobación de manifiestos, digests, relaciones y contentRoot.

RENDER

Selección del renderer y, si procede, del runtime aislado adecuado.

Grafo y entrypoints

El curso no se interpreta como una carpeta de archivos sin estructura. Las entidades y relaciones forman un grafo. Los entrypoints indican por dónde debe comenzar la experiencia cuando no se solicita explícitamente otro nodo.

Formato frente a runtime

Que P2LRN pueda conservar un recurso no significa que pueda ejecutarlo. La ejecución depende de que exista un renderer o runtime real. Esta separación evita declarar capacidades que no existen.

Autoría frente a reproducción

El Toolkit modifica el proyecto editable y reconstruye el paquete. El Player consume el paquete final. La plataforma anfitriona no debería modificar directamente los módulos internos de Creator ni depender de detalles privados del archivo.
