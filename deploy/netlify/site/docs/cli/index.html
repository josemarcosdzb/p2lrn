REFERENCE / CLI

CLI

Sintaxis y opciones extraídas de los entrypoints actuales del Toolkit, no de una lista aproximada.

Convenciones

exit 0

Ejecución correcta o ayuda solicitada.

exit 1

Error de entrada, validación o ejecución reportado por las CLIs.

exit 2

El dispatcher p2lrn sin comando o con comando desconocido.

salida

Las operaciones estructuradas imprimen JSON salvo Reader interactivo y el árbol textual de inspect.

Dispatcher

Terminal
p2lrn <validate|reader|document-reader|inspect|create|convert|repack|multipart|extract-source|delta|trust> ...
p2lrn --help

validate

Sintaxis
p2lrn-validate <package> [--profile-payloads]
p2lrn validate <package> [--profile-payloads]
--profile-payloads

Valida payloads específicos de perfil.

--no-strict-profiles

Desactiva strictProfiles; por defecto la CLI usa validación estricta.

reader

Sintaxis
p2lrn-reader <package>
  [--summary|--tree|--read-plan|--import-plan]
  [--port N] [--no-browser]
  [--no-profile-payload-validation]

Sin flags de salida levanta ReaderServer en 127.0.0.1, imprime la URL y abre navegador salvo --no-browser.

document-reader

Sintaxis
p2lrn-document-reader <file> [--pretty]

DOCX, PPTX, ODT, EPUB y texto estructurado. PDF requiere la dependencia opcional pdfjs-dist. La CLI declara expresamente que no usa OCR ni Docling.

inspect

Sintaxis
p2lrn-inspect <package>
  [--summary] [--tree] [--plan|--read-plan]
  [--transformation] [--import-plan]
  [--capabilities FILE] [--mode MODE]
  [--validate-profile-payloads]

Sin selector imprime summary, tree y plan. El modo por defecto del plan es deliver.

create

Binario directo: p2lrn-create. También disponible como p2lrn create.

init <dir> --title T [--language es] [--description D] [--force]

Crea el proyecto.

open <package> <project_dir> [--force]

Abre un paquete como workspace.

upgrade <project>

Actualiza el workspace editable.

add-unit <project> --key K --title T [--language L] [--role module] [--parent course]

Añade unidad.

add-file <project> <file> --key K --title T [...]

--language, --parent, --media-type, --profile, --role, --activity-type, --no-copy.

add-web-content <project> <dir> --key K --title T [...]

--entrypoint, --language, --parent, --no-copy.

add-questionnaire <project> <file> --key K [...]

--title, --language, --parent, --renderer, --renderer-version, --no-copy.

add-component <project> <file> --key K [...]

--title, --language, --parent, --no-copy.

component-catalog [...]

--component, --component-version y --authoring-documents.

validate-component-authoring <file> [--allow-unknown]

Valida datos de instancia contra el catálogo.

add-composite <project> --key K --title T --children a,b [...]

--mode, --completion, --navigation, --keep-existing-parents, --language, --parent.

add-url <project> <url> --key K --title T [...]

--media-type, --profile, --role, --activity-type, --language, --parent.

build <project> <output> [--strict-profiles]

Construye el paquete final.

convert <source> <output> [--package-root DIR]

Conversión desde Creator.

ingest-aulap2p <reader_json> <output> [...]

--source-file, --asset-root, --language, --strict-profiles.

ingest-aulap2p-course <course_json> <output> [...]

--asset-root, --language, --strict-profiles.

extract-aulap2p-course <package> <output_json>

Extrae el contrato de curso compatible.

show <project>

Resumen del workspace.

convert

Binarios directos: p2lrn-convert y el alias p2lrn-wrap-external.

Sintaxis
p2lrn-convert <source> <output.p2lrn> [--package-root DIR] [--report FILE]
p2lrn wrap-external <source> <output.p2lrn> [--package-root DIR]

repack

Sintaxis
p2lrn-repack <source> <output>
  [--new-package-id]
  [--canonicalize-identifiers]

Un repack neutral comprueba que contentRoot no cambie.

multipart

Sintaxis
p2lrn-multipart <source.p2lrn> <output.p2lrn>
  [--representation <id>]
  [--part-size <bytes>]
--part-size

25 MiB por defecto; mínimo 1 MiB.

--representation

Fija una representación embebida; sin ella se elige la mayor que supera el límite.

salida

Paquete exterior y .partNNN se escriben juntos.

extract-source

Sintaxis
p2lrn-extract-source <package.p2lrn> <output.zip>

Extrae preservedPath del transformation report y verifica el SHA-256 antes de escribir.

delta

Sintaxis
p2lrn-delta create <base> <target> <output> [--force]
p2lrn-delta apply <base> <delta> <output> [--force]
p2lrn-delta inspect <delta>

trust

Sintaxis
p2lrn-trust keygen <private.pem> <public.pem> [--force]
p2lrn-trust sign <package> <private.pem> [--output FILE] [--scope content] [--force]
p2lrn-trust verify <package> <signature> [--trust-key KEY ...] [--require-trusted]
p2lrn-trust inspect <signature>

Firma Ed25519 separada. --require-trusted exige que la clave firmante esté entre las suministradas con --trust-key.

Utilidades declaradas por @p2lrn/toolkit

p2lrn-rebuild-examples [--root DIR] [--output DIR]

Reconstruye ejemplos base.

p2lrn-build-web-sdk [--root DIR] [--output DIR]

Construye distribución web y release.json.

p2lrn-build-advanced-example [--root DIR] [--output FILE.p2lrn]

Genera el ejemplo de interoperabilidad avanzada.
