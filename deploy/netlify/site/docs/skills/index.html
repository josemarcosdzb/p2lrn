Instalar y utilizar las Skills P2LRN

Descarga la Skill adecuada para ChatGPT, Codex, Claude, Gemini o Grok Build y genera cursos educativos .p2lrn desde una conversación. Esta guía explica la instalación, sus requisitos y qué comprobar antes de entregar el archivo.

Ver las cinco descargasVerificar SHA-256

Qué hace la Skill y qué no

«P2LRN – Crear y descargar» utiliza Toolkit oficial cuando está instalado y autorizado, para crear, importar, editar y validar cursos; cuando falta Node conserva un generador Python autónomo limitado para cursos nuevos dentro del contrato P2LRN Core 0.4.0. Permite estructurar unidades y lecciones, crear cuestionarios, preguntas verdadero/falso con varias afirmaciones, juegos y metadatos de autoría, y entregar un archivo .p2lrn real.

Requisitos: Node 22+ y Toolkit 0.5.0-alpha.12 para autoría oficial; Python 3.10+ solo para el empaquetador limitado. Se necesita acceso a archivos y permiso de ejecución. Si la plataforma no permite ejecutar código, podrá redactar contenido, pero no debe afirmar que ha creado el paquete.

La Skill no sustituye a Studio, la ejecución visual del Player, los juegos 3D del motor oficial ni las entregas Windows autoejecutables. Para consultar cursos reales de una carpeta autorizada se usa el MCP de P2LRN por separado.

ChatGPT: descarga e instalación

Descargar Skill para ChatGPT (.zip)
  1. Descarga el ZIP de tipo Skills only con el manifiesto plugin.json y la carpeta skills/p2lrn-creator/.
  2. Importa la Skill en un espacio de ChatGPT que lo admita. Para una distribución pública del plugin, el titular debe enviarlo a revisión por OpenAI; descargarlo no equivale a su aprobación.
  3. Pide un curso completo y exige que se ejecute el generador y su verificación antes de entregar el archivo.

Portal de publicación de OpenAI. El acceso y el proceso de revisión dependen de los permisos de la cuenta.

Codex: instalación de la Skill de proyecto

Descargar Skill para Codex (.zip)
  1. Extrae el ZIP en .agents/skills/p2lrn-creator/ dentro del repositorio y comprueba que existan SKILL.md y los scripts.
  2. Comprueba que Codex descubre la Skill y que el entorno autoriza las operaciones sobre archivos. Instalarla no concede ejecución ilimitada.
  3. Utiliza Toolkit oficial y valida el .p2lrn generado antes de reproducirlo. Redactar un documento no demuestra que el curso funcione.

Este ZIP es independiente del plugin de ChatGPT. Utiliza el paquete específico de cada plataforma.

Claude: Skill personalizada y Claude Code

Descargar Skill para Claude (.zip)
  1. El ZIP contiene la carpeta p2lrn-creator/ con SKILL.md, scripts y referencias.
  2. Impórtala en la gestión de Skills personalizadas de Claude cuando tu plan disponga de esa opción; para Claude Code, coloca la carpeta en la ubicación de Skills que admita tu instalación.
  3. Activa la ejecución de Python y verifica que el asistente puede guardar y devolver el .p2lrn.

Una Skill instalada en tu cuenta o equipo no se publica automáticamente en un directorio global.

Gemini: interfaz web y Gemini CLI

Descargar Skill para Gemini (.zip)

El ZIP incluye SKILL.md en la raíz. En Gemini web, la opción de importar Skills puede depender de la cuenta y no garantiza ejecución de Python. Para Gemini CLI, extrae esos archivos en la carpeta de tu Skill:

Ruta de proyecto de Gemini CLI
.gemini/skills/p2lrn-creator/SKILL.md
.gemini/skills/p2lrn-creator/scripts/p2lrn_package.py

Comprueba la detección con gemini skills list y ejecuta las pruebas Python de la Skill en el directorio adecuado.

Grok Build: instalar en un proyecto

Descargar Skill para Grok Build (.zip)
  1. Extrae el ZIP en la raíz del proyecto que utilizarás con Grok Build.
  2. Confirma que existe .grok/skills/p2lrn-creator/SKILL.md y que los archivos Python están en la subcarpeta scripts/.
  3. Usa las opciones de inspección de Skills del cliente para comprobar que la detecta y que permite ejecutar Python.

Grok web no es Grok Build. No se garantiza que la web importe este ZIP directamente ni que lo distribuya públicamente.

Crear presentaciones directamente dentro de P2LRN

Las cinco Skills incluyen los mismos scripts e instrucciones: references/presentations.md, un ejemplo de diapositivas y exportadores PPTX/PDF opcionales. Crea un curso real con python scripts/p2lrn_presentations.py build --input assets/presentacion-curso.json --output curso-diapositivas.p2lrn. La exportación PowerPoint necesita PptxGenJS y PDF necesita ReportLab, instalados aparte con autorización; ninguno se instala automáticamente. Edita las diapositivas en Studio desde Insertar > Presentación.

Verificar el ZIP y generar un curso de prueba

Antes de instalar, compara el SHA-256 del ZIP descargado con el manifiesto de descargas. Los cinco paquetes se reconstruyen a partir de las mismas fuentes versionadas, pero tienen estructuras de carpeta distintas.

Prueba con Python 3.10+
python -m unittest discover -s scripts -p "test_*.py"
python scripts/p2lrn_package.py build --input assets/ejemplo-curso.json --output curso-prueba.p2lrn
python scripts/p2lrn_package.py verify curso-prueba.p2lrn

Ejecuta estos comandos desde la carpeta donde esté SKILL.md. En la variante Grok, entra primero en .grok/skills/p2lrn-creator/; en la de Claude, entra en p2lrn-creator/.

La salida debe incluir un paquete presente y una validación correcta. Después abre el curso con el visor P2LRN. Las pruebas del generador verifican estructura e integridad; no certifican el funcionamiento gráfico 3D.

Seguridad, derechos y publicación

El código se distribuye bajo P2LRN-NCSL 1.0, una licencia no comercial que no debe describirse como una licencia Open Source aprobada por OSI. Revisa los archivos de la Skill antes de ejecutarlos y no concedas permisos de acceso al equipo que no necesites.

La verificación SHA-256 permite comprobar que el ZIP coincide con el publicado, pero no es una firma digital del autor ni una certificación antifraude. Los ZIP pueden descargarse desde aquí; la publicación en los catálogos oficiales de cada asistente es un proceso separado.

Para funcionalidades más completas, consulta Conectores para IA y MCP, Studio y Paquetes P2LRN.
