INICIO / COMPONENTES

Mapa de componentes

P2LRN está dividido en piezas pequeñas con responsabilidades distintas. Elegir la pieza correcta evita duplicar funciones de tu aplicación dentro del paquete.

1. El recorrido completo

Studio o Toolkit→.p2lrn→Player↕Host Adapter↕tu plataforma

Studio y Toolkit producen o modifican el paquete. Player lo reproduce. Host Adapter comunica la reproducción con los datos y servicios que pertenecen a tu plataforma.

2. Componentes principales

Studio

Editor visual para crear y modificar cursos. Úsalo cuando el autor necesita trabajar con una interfaz en lugar de construir el paquete por código.

Toolkit

API y CLI para autoría programática, Reader, validación, conversión, Multipart y automatización.

Player

Componente de reproducción. Lee el paquete, verifica integridad y muestra la presentación adecuada.

Host Adapter

Puente entre Player y tu plataforma para estado, puntuación, eventos y recursos protegidos.

Reader

Extrae estructura de documentos para que Studio o tu propia lógica decidan cómo convertirla en contenido del curso.

Multipart

Transporte para recursos grandes que deben mantenerse fuera del archivo principal sin perder verificación.

3. Qué componente usar según la tarea

Un profesor crea un curso

Studio.

Un proceso genera muchos cursos

Toolkit y CLI.

Una web reproduce el curso

Player.

La plataforma debe guardar progreso

Host Adapter.

Hay que importar un documento

Reader, normalmente desde Studio o una integración propia.

Un recurso es demasiado grande

Multipart.

4. Qué no debe guardarse dentro del paquete

El paquete contiene estructura, contenido, perfiles y metadatos portables. No debe convertirse en una base de datos de usuarios. Identidad, contraseñas, permisos, matrículas, secretos, progreso individual y datos privados permanecen en la plataforma.

5. Cómo encaja la instalación

NPM y CDN son formas de cargar componentes del navegador; no son productos distintos. Una vez elegido el recorrido de instalación, la API del Player o de Studio es la misma para esa versión.
