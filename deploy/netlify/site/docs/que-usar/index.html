INICIO / DECISIÓN

¿Qué uso?

P2LRN separa autoría, reproducción, distribución e integración. Elige primero tu objetivo para no mezclar herramientas que resuelven problemas distintos.

Elige según tu objetivo

QUIERO CREAR VISUALMENTE

Studio

Editor visual para crear y editar cursos, añadir contenido, previsualizar y exportar .p2lrn.

 QUIERO CREAR POR CÓDIGO

Toolkit / CLI

Autoría programática, validación, conversión y automatización desde Node/TypeScript.

 MI APP USA DEPENDENCIAS

Player por NPM

Instala e importa @p2lrn/player. No necesitas el script del CDN.

 QUIERO HTML DIRECTO

Player por CDN

Carga el Player con <script src="…" >. No necesitas instalar @p2lrn/player.

 QUIERO LEER DOCUMENTOS

Reader

Extrae estructura de documentos para que tu aplicación decida qué convertir en contenido.

 QUIERO GUARDAR PROGRESO

Host Adapter

Conecta estado, score, eventos y resolución de recursos con tu aplicación.

 TENGO CURSOS GRANDES

Multipart

Separa payloads grandes en partes verificadas manteniendo la integridad.

 QUIERO PROBAR

Visor

Abre paquetes canónicos con el Player real y observa los eventos.

Dos decisiones que no son lo mismo

Autoría

Studio visual o Toolkit / CLI.

Carga del Player

NPM o CDN. Son alternativas entre sí.

La frontera importante

El paquete no es tu plataforma.

Usuarios, permisos, matrícula, secretos y persistencia durable pertenecen al Host. El paquete conserva estructura, contenido y metadatos portables.
