INICIO / DECISIÓN

¿Qué componente necesito?

Elige la pieza según la tarea que quieres resolver. Las páginas de instalación se mantienen separadas para que cada recorrido tenga instrucciones completas y coherentes.

Crear y editar

EDITOR VISUAL

Studio

Para crear y editar cursos desde una interfaz gráfica.

NODE.JS / TYPESCRIPT

Toolkit

Para autoría programática, validación, lectura y procesamiento.

Reproducir

NAVEGADOR

Player

Para abrir un .p2lrn, verificar sus recursos y representar el contenido.

PRUEBA RÁPIDA

Visor

Para abrir ejemplos y comprobar un paquete antes de integrarlo.

Integrar y ampliar

Host Adapter

Conecta progreso, puntuación, eventos y recursos protegidos con tu plataforma.

Reader

Extrae estructura y contenido de documentos para incorporarlos a un curso.

Multipart

Divide recursos grandes en partes verificadas que el Player reconstruye al reproducir.

Instalar

Si ya sabes qué componente necesitas, continúa por la guía de instalación que corresponda a tu aplicación.

DEPENDENCIAS DEL PROYECTO

Instalación con NPM

Player, Studio y Toolkit como paquetes.

ARCHIVOS WEB

Instalación mediante CDN

Player y Studio cargados desde HTML.
