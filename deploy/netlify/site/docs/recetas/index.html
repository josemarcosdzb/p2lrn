REFERENCIA / RECETAS

Recetas

Usa estas rutas cuando ya sabes qué resultado necesitas y quieres llegar directamente a la guía adecuada. Cada receta enlaza la secuencia mínima de páginas sin repetir toda la referencia.

Crear contenido

VISUAL

Crear un curso con Studio

Curso nuevo → unidades y lecciones → contenido → Vista alumno → descargar o guardar.

CÓDIGO

Crear un paquete por código

Workspace → recursos → progresión opcional → build → validación → Player.

DOCUMENTOS

Importar con Reader

Leer documento → revisar estructura extraída → convertir sólo el contenido que quieras incorporar.

NAVEGACIÓN

Añadir progresión

Define obligatoriedad, finalización, puntuación mínima, bloqueos y prerrequisitos.

Reproducir

INSTALACIÓN

Incorporar el Player

Elige una forma de instalación → monta <p2lrn-player> → asigna src → escucha ready y error.

ACTIVIDADES

Cuestionarios y juegos

Parte de un cuestionario nativo → elige una presentación compatible → prueba el ejemplo → reproduce con Player.

3D

Usar actividades 3D

Comprueba mecánica compatible, accesibilidad alternativa, físicas y comportamiento de finalización.

PRUEBA

Probar un paquete

Selecciona un ejemplo → ábrelo en el visor → revisa carga, presentación y eventos.

Integrar con una plataforma

ESTADO

Guardar progreso

Configura Host Adapter → carga estado → guarda cambios → reporta puntuación → registra eventos.

PRIVADO

Servir recursos protegidos

Autoriza en tu servidor → devuelve una URL verificada → Player consume el recurso sin introducir secretos en el paquete.

EVENTOS

Reaccionar a la reproducción

Escucha eventos públicos → identifica actividad y contexto → actualiza tu aplicación o telemetría.

MIGRACIÓN

Evaluar un formato externo

Comprueba qué puede preservarse, leerse, editarse y reproducirse antes de diseñar la migración.

Conectado y offline

OFFLINE

Continuar sin conexión

Envuelve Host Adapter con createOfflineHostAdapter() → asigna namespace/store → usa createOfflineSyncController() si quieres reconexión opt-in.

CACHE

Reabrir el curso sin red

Crea createCacheStoragePackageCache() → cachePackageURL() → asigna player.packageCache.

RECURSOS

Compartir una biblioteca verificada

Store por SHA-256 → createResourceLibraryResolver() → selector de Studio o Host Adapter.

LMS

Conectar por LTI 1.3

Despliega el proveedor self-hosted → registra LMS real → Deep Linking/binding → launch → AGS si corresponde.

Distribuir contenido grande

Si un recurso grande no debe quedar dentro del archivo principal, consulta Multipart. El descriptor conserva hashes y el Player reconstruye el contenido a partir de las partes verificadas.
