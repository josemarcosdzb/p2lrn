AUTORÍA / PROGRESIÓN

Progresión

Reglas reales del perfil https://p2lrn.org/profile/progression: obligatoriedad, bloqueo secuencial, requisitos de finalización, puntuación y prerrequisitos.

Propiedades admitidas

required: boolean

Marca la entidad como obligatoria para evaluar la finalización agregada.

gateFollowing: boolean

Bloquea hermanos posteriores hasta satisfacer esta entidad. No es válido en el curso raíz.

completionRequirement

viewed, completed o passed.

minScore

Porcentaje 0–100 y sólo válido en actividades.

unlockWhen

Exactamente uno de all o any, con condiciones sobre unidades o actividades.

Ejemplo de autoría

TypeScript
workspace.setProgression(intro.activityKey, {
  required: true,
  gateFollowing: true,
  completionRequirement: 'viewed',
});

workspace.setProgression(test.activityKey, {
  required: true,
  completionRequirement: 'passed',
  minScore: 80,
  unlockWhen: {
    all: [{entityKey: intro.activityKey, status: 'viewed'}],
  },
});

Qué hace el Player

  1. Renderizado.p2lrn:rendered marca la actividad como vista.
  2. Score / complete.Los eventos del renderer actualizan estado, puntuación y aprobado.
  3. Bloqueos.El Player recalcula gateFollowing y unlockWhen.
  4. Persistencia.Si existe Host Adapter, usa loadState y saveState.
  5. Cambio.Emite p2lrn:progressionchange cuando cambia el estado.

Qué no guarda el paquete

El paquete define las reglas. El estado de un alumno no se escribe dentro del .p2lrn; debe persistirlo el Host mediante el Adapter u otra capa de aplicación.
