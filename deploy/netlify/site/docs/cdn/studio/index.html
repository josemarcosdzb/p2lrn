Studio mediante CDN

Esta guía cubre únicamente la integración de Studio mediante su cargador web. El cargador prepara el Player correspondiente antes de iniciar el editor.

1. Cargar Studio

Incluye el cargador de Studio una sola vez. Ese archivo prepara también el Player que Studio necesita para la Vista alumno.

HTML mínimo
<script src="https://p2lrn.netlify.app/studio/current/dist/p2lrn-studio.js"></script>

<p2lrn-studio></p2lrn-studio>

El archivo p2lrn-studio.js carga primero el Player del mismo canal y después inicia Studio. No añadas un segundo cargador del Player.

2. Abrir un curso inicial

Si quieres que el editor arranque con un curso ya seleccionado, indica su URL mediante src. Si lo omites, el usuario podrá crear o abrir un curso desde la interfaz.

HTML
<script src="https://p2lrn.netlify.app/studio/current/dist/p2lrn-studio.js"></script>

<p2lrn-studio src="/courses/curso.p2lrn"></p2lrn-studio>

El atributo src es opcional. Sin él, el usuario puede crear un curso nuevo desde la interfaz.

3. Fijar una versión

Para mantener una versión concreta en producción, cambia current por el número de versión publicado.

HTML
<script src="https://p2lrn.netlify.app/studio/0.5.0-alpha.11/dist/p2lrn-studio.js"></script>

El cargador versionado utiliza el Player de esa misma versión.

4. Habilitar guardado e importación

Estas opciones son necesarias sólo cuando tu plataforma ofrece guardado centralizado, Reader o conversión de paquetes externos.

HTML
<script src="https://p2lrn.netlify.app/studio/current/dist/p2lrn-studio.js"></script>

<p2lrn-studio
  src="/courses/curso.p2lrn"
  save-endpoint="/api/p2lrn/studio/save"
  reader-endpoint="/api/p2lrn/studio/read"
  import-endpoint="/api/p2lrn/studio/import"
  course-path="course">
</p2lrn-studio>
save-endpoint

Recibe el paquete cuando el usuario guarda en servidor.

reader-endpoint

Procesa documentos importados mediante Reader.

import-endpoint

Procesa paquetes educativos externos.

course-path

Identifica la ruta lógica de guardado.

5. Qué puedes hacer sin servicios de servidor

Con el cargador y el componente básico puedes crear un curso nuevo, abrir un archivo local, abrir una URL accesible, editar el contenido, cambiar a Vista alumno y descargar un nuevo .p2lrn. Los endpoints sólo son necesarios para las funciones que deben comunicarse con tu plataforma.

6. Qué debe proporcionar el servidor

Las rutas Save, Reader e Import no quedan protegidas por usar el CDN de P2LRN. Corresponde al sitio web que integra Studio implementar autenticación de sesión y autorización por rol, curso y centro en su propio servidor. También debe aplicar CSRF cuando use cookies, CORS restrictivo, límites de tamaño y peticiones y almacenamiento seguro. El atributo save-endpoint no concede permisos ni sustituye estos controles. Revisa los requisitos de seguridad de integración.

Los servicios de guardado e importación pertenecen a tu plataforma. Deben autenticar al usuario, autorizar la operación, validar la entrada y limitar las rutas y tamaños aceptados. Si no necesitas esas funciones, Studio puede crear, editar, previsualizar y descargar cursos sin esos servicios.

7. Comprobar la integración

  1. Carga.Confirma que el editor aparece sin errores en la consola.
  2. Curso.Crea un curso o abre el indicado en src.
  3. Vista alumno.Comprueba que el Player puede representar el contenido desde el propio editor.
  4. Salida.Descarga el paquete; si has configurado servicios, prueba también guardado e importación.

8. API y eventos

Los métodos y eventos de <p2lrn-studio> se documentan en Referencia técnica.
