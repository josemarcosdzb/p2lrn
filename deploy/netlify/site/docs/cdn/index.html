Instalación mediante CDN

Usa esta guía cuando quieras cargar P2LRN directamente desde HTML mediante los archivos publicados para navegador. Player y Studio tienen puntos de entrada independientes.

1. Cargar el Player

Añade el cargador una sola vez en la página. Después podrás usar el elemento <p2lrn-player> tantas veces como necesites.

HTML
<script src="__P2LRN_PINNED_PLAYER_URL__" integrity="__P2LRN_PINNED_PLAYER_SRI__" crossorigin="anonymous" referrerpolicy="no-referrer"></script>

<p2lrn-player src="./course.p2lrn"></p2lrn-player>

El primer ejemplo utiliza una versión fijada y un hash SHA-384. Reserva current para pruebas en las que aceptes actualizaciones automáticas.

2. Fijar una versión del Player

Cuando necesites una integración reproducible, sustituye el canal current por una versión concreta para mantener estable el archivo que carga tu aplicación.

HTML
<script src="https://p2lrn.org/player/0.5.0-alpha.14/dist/p2lrn.js"></script>

Una URL versionada mantiene la misma versión del archivo mientras esa publicación esté disponible.

Protección SRI de las distribuciones CDN

Para integraciones de producción, utiliza siempre la ruta inmutable /player/VERSIÓN/dist/p2lrn.js, no el canal modificable /player/current/. Cada compilación publica los hashes SHA-384 exactos en el manifiesto SRI y en /index.json (propiedad player.integrity.classic). Copia el hash correspondiente a tu HTML de integración como integrity="sha384-…" junto con crossorigin="anonymous" y referrerpolicy="no-referrer".

Fija el hash al construir o desplegar tu propia web. No descargues el hash dinámicamente desde la misma CDN al cargar la página: si CDN y manifiesto fueran modificados simultáneamente, esa comprobación dejaría de protegerte. El SRI del script inicial no equivale a verificar automáticamente todos sus módulos importados: conserva el origen aislado, CSP y controles de publicación.

3. Cargar Studio

Studio dispone de su propio cargador web. La guía específica explica el montaje, la apertura de cursos y la conexión con servicios de guardado e importación.

4. Qué ocurre al cargar el archivo

El cargador registra el componente <p2lrn-player> en el navegador. A partir de ese momento puedes utilizarlo en el HTML y asignarle un paquete mediante src. No necesitas copiar los archivos del Player a tu proyecto si vas a utilizar el recurso publicado.

5. Abrir la página desde un servidor local

Abre la carpeta del proyecto en tu editor de texto o código habitual y sírvela mediante HTTP. El navegador necesita un origen web real para resolver correctamente el paquete y sus recursos; abrir index.html directamente mediante file:// no representa el funcionamiento normal de una aplicación web.

  1. Localiza index.html y los archivos que utiliza la página.
  2. Inicia la vista previa o el servidor HTTP local que utilices normalmente en tu editor o entorno de desarrollo.
  3. Abre en el navegador la dirección local que proporcione ese servidor.

No necesitas un editor, una extensión ni una herramienta concreta para este paso.

6. Cargar un curso

El atributo src puede apuntar a un archivo del mismo sitio o a una URL permitida por el servidor que aloja el contenido. Si el curso está en otro origen, configura CORS para permitir su lectura.

7. Comprobar la integración

Abre la página desde el servidor web, confirma que el Player aparece y revisa la consola del navegador si el paquete no carga. Los fallos más habituales son una URL incorrecta, un servidor que no entrega el archivo o una política CORS que impide leerlo.

Para conocer los atributos, eventos e integración con tu plataforma, continúa con Player.

Analytics mediante CDN

La integración básica lee el archivo .p2lrn-result indicado en src. No necesitas un endpoint de métricas.

HTML
<script src="https://p2lrn.org/analytics/current/dist/p2lrn-analytics.js"></script>
<p2lrn-analytics id="panel.analytics" src="/resultados/ana.p2lrn-result"></p2lrn-analytics>

Para varios alumnos utiliza un índice estático o importa archivos locales. Guía completa: identidad, archivos e integración avanzada.
