Usar el Player desde CDN

Esta ruta carga el Player directamente desde una URL pública. No requiere instalar @p2lrn/player por NPM.

1. HTML mínimo

index.html
<!doctype html>
<html lang="es">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>Curso P2LRN</title>

<script src="https://p2lrn.netlify.app/player/current/dist/p2lrn.js"></script>

<p2lrn-player id="course" src="./course.p2lrn"></p2lrn-player>

<script>
  const player = document.querySelector('#course');
  player.addEventListener('p2lrn:ready', (event) => {
    console.log('READY', event.detail);
  });
  player.addEventListener('p2lrn:error', (event) => {
    console.error('P2LRN ERROR', event.detail);
  });
</script>
</html>
En esta ruta no ejecutes npm install @p2lrn/player.

El Player se registra mediante la etiqueta <script src="…">.

2. “current” frente a versión fija

/player/current/ apunta al build publicado como actual. Si necesitas reproducibilidad exacta, fija la versión:

CDN versionado
<script src="https://p2lrn.netlify.app/player/0.5.0-alpha.10/dist/p2lrn.js"></script>

3. El paquete .p2lrn se crea aparte

El CDN sólo resuelve cómo se carga el Player. El curso puede venir de cualquiera de estas rutas:

VISUAL

Studio

Crea y exporta el paquete con el editor visual.

 CÓDIGO

Toolkit / CLI

Genera y valida el paquete desde Node/TypeScript o comandos.

4. Sirve HTML y paquete por HTTP

No abras el ejemplo mediante file://. Publica index.html y course.p2lrn desde tu servidor web, alojamiento estático o entorno de desarrollo.

public/
public/
├─ index.html
└─ course.p2lrn

5. Cuándo usar esta ruta

  • Quieres probar el Player con una página HTML sin preparar un proyecto NPM.
  • No necesitas que tu bundler gestione el paquete @p2lrn/player.
  • Prefieres cargar un build publicado directamente desde el navegador.

Si tu aplicación ya usa dependencias y módulos, consulta la ruta NPM.
