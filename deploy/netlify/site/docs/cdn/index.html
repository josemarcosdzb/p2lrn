Instalación mediante CDN

Usa esta guía cuando quieras cargar P2LRN directamente desde HTML mediante los archivos publicados para navegador. Player y Studio tienen puntos de entrada independientes.

1. Cargar el Player

HTML
<script src="https://p2lrn.netlify.app/player/current/dist/p2lrn.js"></script>

<p2lrn-player src="./course.p2lrn"></p2lrn-player>

El canal current apunta a la versión publicada para uso habitual.

2. Fijar una versión del Player

HTML
<script src="https://p2lrn.netlify.app/player/0.5.0-alpha.10/dist/p2lrn.js"></script>

Una URL versionada mantiene la misma versión del archivo mientras esa publicación esté disponible.

3. Cargar Studio

Studio dispone de su propio cargador web. La guía específica explica el montaje, la apertura de cursos y la conexión con servicios de guardado e importación.

Guía completa de Studio mediante CDN

4. Qué ocurre al cargar el archivo

El cargador registra el componente <p2lrn-player> en el navegador. A partir de ese momento puedes utilizarlo en el HTML y asignarle un paquete mediante src. No necesitas copiar los archivos del Player a tu proyecto si vas a utilizar el recurso publicado.

5. Servir la página por HTTP o HTTPS

Abre la integración desde un servidor web. Esto permite que el navegador resuelva paquetes, recursos y servicios con reglas de origen previsibles.

Ejemplo local
python -m http.server 8080

Después abre http://localhost:8080/.

6. Cargar un curso

El atributo src puede apuntar a un archivo del mismo sitio o a una URL permitida por el servidor que aloja el contenido. Si el curso está en otro origen, configura CORS para permitir su lectura.

7. Comprobar la integración

Abre la página desde el servidor web, confirma que el Player aparece y revisa la consola del navegador si el paquete no carga. Los fallos más habituales son una URL incorrecta, un servidor que no entrega el archivo o una política CORS que impide leerlo.

Para conocer los atributos, eventos e integración con tu plataforma, continúa con Player.
