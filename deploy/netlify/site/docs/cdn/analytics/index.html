ANALYTICS / CDN

Analytics mediante CDN

Consulta los resultados del curso abierto sin necesitar un endpoint del Host.

1. Cargar Analytics desde CDN

Analytics lee directamente el archivo .p2lrn-result indicado en src. Esta ruta apunta al resultado, no al curso .p2lrn. No necesitas base de datos ni configurar un endpoint.

HTML
<script src="https://p2lrn.org/analytics/current/dist/p2lrn-analytics.js"></script>
<p2lrn-analytics id="panel.analytics" src="/resultados/ana.p2lrn-result"></p2lrn-analytics>

2. Consultar resultados de varios alumnos

Guarda los resultados como archivos normales y crea un índice estático que indique sus rutas. Analytics comprueba el SHA-256 de cada resultado antes de mostrarlo. También puedes seleccionar varios archivos o una carpeta local desde el panel.

index.p2lrn-results.json
{
  "schema": "https://p2lrn.org/schema/analytics-results-index/1",
  "results": ["ana.p2lrn-result", "luis.p2lrn-result"]
}
HTML
<p2lrn-analytics id="panel.analytics" src="/resultados/index.p2lrn-results.json"></p2lrn-analytics>

El índice es una lista de archivos, no una base de datos. Si utilizas URLs, el navegador debe poder acceder a los resultados. No publiques datos de alumnos en un CDN público: el sitio que aloja los archivos debe controlar quién puede leerlos.

3. Identificar al alumno: dos opciones

Opción A — usuario autenticado en una plataforma

En una web o LMS con inicio de sesión, la plataforma entrega el emisor y el identificador auténtico del usuario. Esos datos viajan en el .p2lrn-result y Analytics agrupa los intentos correspondientes.

JavaScript
// Datos procedentes de la sesión autenticada por tu plataforma.
const identity = {
  mode: 'platform',
  issuer: sesion.issuer,
  subjectId: sesion.userId,
  label: sesion.nombreVisible
};

Opción B — código individual asignado por el profesor

Sin plataforma ni cuentas, el profesor asigna un código distinto a cada alumno. El alumno lo introduce al comenzar la entrega offline. El resultado incorpora ese código y Analytics reúne sus intentos.

JavaScript
const identity = {
  mode: 'code',
  issuer: 'mi-centro',
  code: 'ALU-007', // Código individual asignado por el profesor
  label: 'Ana'
};

Seguridad: SHA-256 detecta modificaciones del archivo, pero no acredita quién lo realizó. Un código escrito por el alumno no equivale a autenticación. Tampoco basta con declarar una identidad de plataforma en JavaScript para verificarla: solo el sistema autorizado puede acreditar el inicio de sesión o las notas oficiales.

4. Cómo generar el resultado desde Player web

Player permite capturar resultados con cualquiera de las dos identidades. Configura la identidad antes de la actividad y descarga o guarda el resultado al terminar. No se envía automáticamente a ningún servidor.

JavaScript
import {mountP2LRN} from '@p2lrn/player';
const player = await mountP2LRN('#reproductor', {
  src: '/cursos/curso.p2lrn',
  resultIdentity: identity
});
// After the learner finishes, from a user action:
document.getElementById('descargar').addEventListener('click', () => {
  player.resultRecorder.download('resultado.p2lrn-result');
});

Con el cargador CDN puedes usar player.startResultCapture({identity}). En las entregas offline, .p2lrn-result se genera al finalizar.

5. NPM e integración avanzada

Consulta Analytics con NPM para conocer los paquetes, las APIs de TypeScript, la captura y la lectura directa. Los endpoints JSON se conservan para integraciones avanzadas autorizadas, pero no son obligatorios para trabajar con archivos.
