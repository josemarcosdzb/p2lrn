ANALYTICS / CDN

Analytics mediante CDN

Consulta los resultados del curso abierto sin necesitar un endpoint del Host.

1. Cargar el componente

Carga una sola vez el componente web de Analytics y añádelo a tu página. El atributo course-id identifica el curso actual, pero no descarga el paquete del curso.

HTML
<script src="https://p2lrn.org/analytics/current/dist/p2lrn-analytics.js"></script>
<p2lrn-analytics id="analytics-curso" course-id="curso-actual"></p2lrn-analytics>
<script>
  // Resultados validados del curso abierto, obtenidos del Player
  // o importados de archivos .p2lrn-result.
  document.querySelector('#analytics-curso').data = resultadosCurso;
</script>

2. Conectar los resultados del curso

Player o tu aplicación autorizada facilita los datos de actividad y los resultados de ese curso. También puedes incorporar evidencias offline desde .p2lrn-result. La variable resultadosCurso del ejemplo representa datos validados que debes proporcionar: no es una variable incluida automáticamente.

Para abrir el archivo .p2lrn se utiliza Player. La ruta del paquete no funciona directamente en src de Analytics: ese atributo espera un JSON de métricas.

3. Consultar Analytics

Abre el panel Analytics para revisar progreso, intentos y resultados disponibles. Desde la interfaz puedes importar archivos de resultados offline compatibles. Las calificaciones oficiales deben proceder de una fuente autorizada.

4. Integración avanzada: API autorizada

Solo cuando tu plataforma gestione alumnos, autenticación o notas oficiales centralizadas necesitas configurar un endpoint de métricas protegido. Debe devolver el dataset de Analytics en JSON, comprobar los permisos de acceso y no publicar información privada de alumnos.

HTML
<p2lrn-analytics src="/api/p2lrn/analytics/snapshot"></p2lrn-analytics>

Consulta la guía completa de Analytics para el contrato de datos, la API, permisos y reglas de calificación.
