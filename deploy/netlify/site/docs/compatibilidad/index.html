INTEGRATE / COMPATIBILITY

Compatibilidad y migración

Compatibilidad P2RLN Alpha15 y capacidades reales para H5P, SCORM, cmi5, QTI, Common Cartridge, IMS CP y Tin Can.

Regla principal

Preservar ≠ ejecutar

P2LRN distingue read, author, round-trip, preserve y deliver. Sólo se declara ejecución cuando existe un runtime real.

P2RLN Alpha15

Se aceptan nombres e identificadores antiguos como entrada legacy: .p2rln, namespace histórico, p2rln.project.json, <p2rln-player>, eventos y rutas anteriores. La escritura nueva utiliza identidad P2LRN.

Terminal
p2lrn-repack old-course.p2rln new-course.p2lrn --canonicalize-identifiers

Migración de proyecto

p2rln.project.json se trata como entrada legacy. Tras una actualización correcta, el workspace escribe p2lrn.project.json y elimina el alias antiguo sólo cuando la nueva escritura y validación han terminado correctamente.
