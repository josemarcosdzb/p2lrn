Compatibilidad y migración

La matriz usa el registro real packages/toolkit/config/authoring-capabilities.json. No convierte presencia de un renderer en una afirmación de compatibilidad total.

Cómo leer esta tabla

Preserve ≠ Read ≠ Author ≠ Deliver

Author indica autoría nativa; Open/Rebuild, que un paquete puede abrirse como proyecto y reconstruirse; Read, que el Reader declara lectura; Preserve, conservación del artefacto; Deliver, ejecución declarada por ese registro concreto.

Toolkit y Player no son la misma matriz

El Player actual registra renderers para H5P, SCORM, QTI y un runtime de paquete para cmi5, Tin Can, Common Cartridge e IMS CP. Eso demuestra que existe infraestructura de reproducción, pero el registro de capacidades de autoría sigue declarando deliver:false para esos perfiles externos. Mientras ambas fuentes no estén unificadas, la documentación no los presenta como soporte de entrega completo.
