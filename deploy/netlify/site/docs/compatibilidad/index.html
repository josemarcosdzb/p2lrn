COMPATIBILIDAD

Compatibilidad y runtimes

Qué se mantiene por compatibilidad, qué puede preservarse y qué dispone realmente de un runtime de ejecución.

P2RLN Alpha15

Los nombres históricos P2RLN, .p2rln, p2rln.project.json, <p2rln-player>, eventos y rutas antiguas continúan como entrada legacy para no romper material anterior.

La escritura nueva utiliza siempre identidad P2LRN.

H5P y SCORM

El Player incluye hosts aislados para H5P y SCORM. Las librerías H5P reutilizables se distribuyen separadamente para no obligar a todas las instalaciones a descargar el corpus completo.

cmi5, QTI, Common Cartridge, IMS CP y Tin Can

Estos formatos se manejan según las capacidades reales declaradas por el runtime y las herramientas. El hecho de conservar un paquete externo no implica que exista ejecución completa.

Preservar ≠ ejecutar

P2LRN distingue lectura, autoría, round-trip, preservación y deliver. Sólo se declara ejecución cuando hay un runtime real que la soporta.

CDN

El CDN público distribuye el Player, hosts de runtime y librerías H5P compartidas. No almacena cursos de usuarios ni datos personales.
