Authoring API

P2LRNAuthoringWorkspace.create(root, options)

Crea un workspace. Requiere title; admite language, description y force.

P2LRNAuthoringWorkspace.open(packagePath, root, options)

Abre un paquete como proyecto editable.

P2LRNAuthoringWorkspace.load(root)

Carga un workspace existente.

workspace.summary()

Devuelve versiones, projectId, rutas y contadores.

workspace.reload()

Recarga el proyecto desde disco.

workspace.upgrade()

Actualiza el workspace a la versión editable actual.

workspace.setCourseMetadata(options)

Edita título, descripción, idioma y revisión del curso.

workspace.setEntityText(key, options)

Edita texto localizado de una entidad.

workspace.setChildren(parentKey, children)

Reordena hijos y rechaza claves duplicadas.

workspace.setProgression(key, options|null)

Aplica o elimina progression sobre course, unit o activity.

workspace.addUnit(options)

Añade una unidad.

workspace.addFile(options)

Añade archivo + actividad y devuelve resourceKey/activityKey.

workspace.addUrl(options)

Añade una URL como recurso/actividad.

workspace.addWebContent(options)

Añade un directorio web con entrypoint.

workspace.addQuestionnaire(options)

Añade questionnaire nativo y permite solicitar renderer/version.

workspace.addComponent(options)

Añade un componente nativo.

workspace.addComposite(options)

Añade composite sequence/free con completion all/any.

await workspace.reader(source, options)

Extrae un documento sin mutar el proyecto.

workspace.save()

Persiste el workspace actual.

workspace.build(output, options)

Construye el .p2lrn; admite strictProfiles.

Trust / Ed25519

Terminal
p2lrn-trust keygen private.pem public.pem
p2lrn-trust sign course.p2lrn private.pem
p2lrn-trust verify course.p2lrn course.p2lrn.sig --trust-key public.pem --require-trusted
p2lrn-trust inspect course.p2lrn.sig
Integridad y confianza son distintas.

SHA-256 detecta cambios. La firma Ed25519 comprueba que el contenido fue firmado por una clave; --require-trusted además exige que esa clave esté en el conjunto suministrado.

Multipart

Terminal
p2lrn-multipart <source.p2lrn> <output.p2lrn> [--representation <id>] [--part-size <bytes>]

Parte por defecto: 25 MiB. Mínimo admitido por la implementación: 1 MiB.
