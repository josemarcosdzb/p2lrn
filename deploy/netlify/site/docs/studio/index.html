AUTORÍA / STUDIO

P2LRN Studio

Studio es el editor visual para crear y mantener cursos .p2lrn. Esta guía explica el trabajo dentro del editor, desde un curso vacío hasta la vista del alumno y la exportación final.

1. Crear o abrir un curso

Abrir P2LRN Studio
Crear curso

Inicia un curso nuevo y prepara su estructura para empezar a añadir unidades, lecciones y contenido.

Abrir archivo

Carga un .p2lrn guardado en tu equipo y continúa editándolo.

Abrir URL

Abre un paquete accesible mediante una dirección web para revisarlo o modificarlo.

2. Organizar unidades y lecciones

El árbol del curso muestra la estructura de navegación. Usa + Unit para crear una unidad y + Lesson para añadir una lección en la posición seleccionada.

  1. Unidad.Agrupa una parte del curso y puede contener otras unidades, lecciones o recursos.
  2. Lección.Es el espacio editable para desarrollar el contenido que verá el alumno.
  3. Selección.Selecciona un elemento del árbol para editarlo o para indicar dónde se insertará el siguiente elemento.

3. Añadir contenido

El menú Añadir contenido separa las opciones por tipo para que puedas elegir la actividad adecuada.

Contenido

Lección editable, archivo o multimedia, URL, documento mediante Reader y paquete educativo externo.

Evaluación

Cuestionario con los tipos de pregunta compatibles con P2LRN.

Juegos

Memoria, relacionar, ordenar, clasificar, verdadero/falso, completar huecos, sopa de letras, crucigrama, rosco y actividad 3D.

Estructuras avanzadas

Bloques reutilizables y grupos compuestos para contenido que necesita una organización más compleja.

4. Editar en el lienzo

Cuando seleccionas un elemento compatible, Studio abre su editor en el área central. Modifica el contenido en el propio lienzo y utiliza los controles disponibles para ese tipo de recurso. Los cambios permanecen en la sesión de edición hasta que descargues o guardes el curso.

5. Comprobar la vista del alumno

Cambia a Vista alumno para reproducir el estado del curso con el Player. Esta vista sirve para comprobar navegación, contenido, actividades y progresión antes de exportar el paquete.

La vista previa no sustituye al guardado.

Vuelve a edición para seguir trabajando y guarda o descarga el curso cuando quieras conservar los cambios.

6. Guardar y exportar

Descargar .p2lrn

Genera el paquete y lo descarga en el equipo. No requiere un servicio de guardado en servidor.

Guardar en servidor

Envía el paquete al servicio configurado por la plataforma que integra Studio. Esta opción sólo aparece cuando existe un destino de guardado.

Reader de documentos

La importación de documentos necesita un servicio Reader cuando la plataforma quiera ofrecer esa función.

Paquetes educativos

La importación de formatos externos necesita un servicio de conversión cuando se habilita esa función.

7. Volver a trabajar sobre un curso

Un paquete descargado puede abrirse de nuevo desde Abrir archivo. Si tu plataforma guarda cursos en servidor, también puede proporcionar una URL inicial para abrir el paquete directamente en Studio.

8. Referencia técnica del componente

Los atributos, métodos y eventos públicos del componente están documentados en Referencia técnica. La configuración de instalación se mantiene en sus guías específicas para no mezclar recorridos.
