P2LRN Studio

Studio es el editor visual de P2LRN. Puedes usar la instancia pública, incrustarlo desde NPM o cargarlo desde CDN. Las tres opciones usan el mismo componente web <p2lrn-studio>.

1. Usarlo directamente

Abrir P2LRN Studio

En la pantalla inicial puedes Crear curso, Abrir archivo o Abrir URL.

2. Flujo de autoría visual

  1. Crear o abrir.Empieza un curso nuevo o abre un paquete existente.
  2. Estructura.Crea unidades y lecciones.
  3. Contenido.Añade lecciones, archivos, URL, Reader/documentos, paquetes educativos, cuestionarios, juegos y bloques avanzados.
  4. Editar.Modifica el contenido compatible directamente en el lienzo.
  5. Vista alumno.Studio exporta temporalmente el estado y lo previsualiza con <p2lrn-player>.
  6. Salida.Descarga el paquete o guárdalo mediante el endpoint del Host.

3. Integrar Studio por NPM

Terminal
npm install @p2lrn/studio@0.5.0-alpha.10 @p2lrn/player@0.5.0-alpha.10
JavaScript / TypeScript
import '@p2lrn/studio';
HTML mínimo
<p2lrn-studio></p2lrn-studio>

La ruta NPM no necesita ningún script CDN.

4. Integrar Studio por CDN

HTML mínimo
<script src="https://p2lrn.netlify.app/studio/current/dist/p2lrn-studio.js"></script>

<p2lrn-studio></p2lrn-studio>

El cargador detecta su canal, carga el Player correspondiente y después importa p2lrn-studio.esm.js. Para fijar versión sustituye current por 0.5.0-alpha.10:

CDN versionado
<script src="https://p2lrn.netlify.app/studio/0.5.0-alpha.10/dist/p2lrn-studio.js"></script>
Usa el cargador p2lrn-studio.js en HTML puro.

No uses directamente el ESM sin resolver antes @p2lrn/player.

5. Atributos reales del componente

src

URL opcional del paquete inicial.

save-endpoint

Endpoint POST de guardado. Si falta, el botón de guardar en Host se oculta.

reader-endpoint

Endpoint necesario para importar documentos con Reader.

import-endpoint

Endpoint necesario para importar paquetes educativos externos.

course-path

Ruta lógica de guardado; valor por defecto course.

6. Ejemplo completo con servidor

HTML
<p2lrn-studio
  src="/course/curso.p2lrn"
  save-endpoint="/api/p2lrn/studio/save"
  reader-endpoint="/api/p2lrn/studio/read"
  import-endpoint="/api/p2lrn/studio/import"
  course-path="course">
</p2lrn-studio>

Para crear, editar, previsualizar y descargar puedes omitir todos los endpoints.

8. Configurar el servidor con NPM

Automático
npx p2lrn-studio setup

Actualmente Next.js es el target cuyo comando setup genera guardado + Reader + importación. Los demás targets generan el guardado; añade las otras dos rutas en el Host si las necesitas.

Next.js completo
npx p2lrn-studio setup next --course-path data/courses

9. API pública comprobada

createCourse(options)

Crea un documento nuevo.

openFile(file)

Abre un archivo local.

openUrl(url)

Abre un paquete remoto.

setMode('edit' | 'preview')

Cambia edición/vista previa.

addUnit / addLesson / addContent

Añade estructura y contenido.

download()

Exporta y descarga.

saveCourse()

Exporta y envía al save-endpoint.

10. Eventos públicos comprobados

p2lrn-studio-create

Curso nuevo creado.

p2lrn-studio-open

Paquete abierto.

p2lrn-studio-download

Paquete descargado.

p2lrn-studio-save

Guardado en servidor completado.

11. Seguridad

El helper del servidor limita tamaño, sanea nombre y ruta y, por defecto, no acepta que el navegador cambie libremente course-path. Autenticación, autorización y permisos pertenecen a la aplicación anfitriona.
