AUTHOR / VISUAL

Crear un curso con Studio

Studio es la ruta de autoría visual. Para crear un curso desde la interfaz no necesitas escribir los comandos del Toolkit. Puedes crear un curso nuevo, abrir un .p2lrn, editarlo, probar la vista del alumno y exportar un paquete nuevo.

1. Abre el editor visual

Abrir P2LRN Studio

En la pantalla inicial puedes usar Crear curso, Abrir archivo o Abrir URL.

2. Crea la estructura del curso

  1. Crear curso.Inicia un paquete nuevo para editarlo en Studio.
  2. + Nueva unidad.Crea secciones para organizar las lecciones y actividades.
  3. Añadir contenido.Abre el selector completo de tipos de contenido.
  4. + Nueva lección.Crea directamente una lección editable.

3. Qué puedes añadir visualmente

Lección

Contenido editable directamente en Studio.

Archivo / multimedia

Imagen, vídeo, audio u otro archivo incluido como recurso.

URL

Recurso web externo sin copiarlo al paquete.

Reader / documento

Importa PDF, DOCX, PPTX, EPUB, TXT, Markdown y otros documentos admitidos.

Paquete educativo

Importa contenido externo como SCORM, H5P, cmi5, QTI, Common Cartridge o IMS Content Package.

Cuestionario

Combina preguntas de elección, verdadero/falso, texto, huecos, ordenar, relacionar y clasificar.

Juegos

Memoria, relacionar, ordenar, clasificar, verdadero/falso, rellenar huecos, sopa de letras, crucigrama, rosco y juego 3D.

Bloque reutilizable / grupo compuesto

Estructuras avanzadas para componentes portables y agrupaciones.

4. Edita el contenido en el lienzo

En modo Editar, Studio muestra el árbol del curso a la izquierda y el contenido seleccionado en el lienzo. La barra de formato actual permite cambiar el tipo de bloque, aplicar negrita, cursiva y subrayado, alinear el texto y ajustar color de texto y fondo.

La estructura se modifica desde el árbol y los controles de creación; no necesitas editar manifest.json ni graph.json a mano.

5. Comprueba la vista del alumno

Pulsa Vista alumno. Studio utiliza el Player para previsualizar el curso sin convertir el editor en el runtime del alumno. Vuelve a Editar para continuar autorando.

6. Guarda o exporta

Guardar borrador

Guarda manualmente un borrador en ese navegador y dispositivo. Studio no debe considerarse autoguardado permanente.

Exportar .p2lrn

Genera el paquete portable que puedes almacenar, publicar o abrir con el Player.

save-endpoint

Cuando Studio se integra dentro de una aplicación, el host puede ofrecer un endpoint de guardado controlado por sus permisos.

No cierres la página con cambios sólo en memoria.

Antes de salir, guarda un borrador o exporta el .p2lrn.

7. Studio público frente a Studio integrado

USAR EL EDITOR

Studio público

Abres el editor y trabajas visualmente. No hace falta instalar el Player por NPM para crear el curso desde esta interfaz.

 INTEGRAR EN TU APP

Studio por NPM

Instalas @p2lrn/studio y @p2lrn/player si quieres incrustar el editor en tu propia aplicación y conectar un backend de guardado.

8. Si prefieres crear por código

La alternativa técnica es Toolkit / CLI. Esa guía sí utiliza comandos y API TypeScript porque está destinada a automatización y autoría programática.
