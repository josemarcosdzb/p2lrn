P2LRN Documentation

Recorrido completo desde entender P2LRN hasta reproducir, editar e integrar un paquete real.

Elige por objetivo

01

Ejecutar mi primer curso

Sirve un paquete, monta el Player y comprueba sus primeros eventos.

 02

Crear o editar un paquete

Construye un curso real desde un workspace y valida el resultado.

 03

Dividir un paquete grande

Separa vídeos, ZIP u otros payloads grandes en partes verificadas.

 04

Integrarlo en mi plataforma

Conecta Player, Host Adapter, progreso, CORS y runtimes externos.

 05

Probar el visor real

Abre paquetes canónicos con el Player publicado y observa el runtime.

Mapa de responsabilidades

PACKAGE

Estructura, contenido, manifiestos, perfiles y recursos portables.

PLAYER

Lectura, renderizado, eventos y runtimes aislados del navegador.

TOOLKIT

Autoría, Reader, validación, conversión, repack y herramientas CLI.

HOST

Usuarios, permisos, matrícula, progreso durable, secretos y telemetría.
