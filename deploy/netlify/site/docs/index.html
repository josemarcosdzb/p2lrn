INICIO

Documentación de P2LRN

La documentación empieza por entender P2LRN: qué piezas tiene, qué contiene un paquete, cómo funciona la progresión y qué datos produce. Después eliges instalación, creas, reproduces e integras el curso sin mezclar recorridos.

Recorrido recomendado

1 · ENTENDER

Antes de empezar

Conoce componentes, conceptos, formato, progresión y métricas antes de elegir cómo instalar o crear.

2 · PREPARAR

Instalar

Elige Studio alojado, NPM o CDN. Si trabajas dentro de un proyecto, la instalación va antes de crear el curso.

3 · CREAR

Crear el curso

Usa Studio para autoría visual o Toolkit para autoría por código.

4 · REPRODUCIR

Probar con Player

Abre el paquete, comprueba el contenido y verifica actividades y progresión.

5 · INTEGRAR

Conectar tu plataforma

Usuarios, permisos, estado, puntuación, eventos y recursos privados permanecen en tu aplicación.

Qué conviene entender antes de instalar

Mapa de componentes

Qué hacen Studio, Toolkit, Player y tu propia plataforma, y cuál necesitas para cada tarea.

Conceptos fundamentales

Proyecto de autoría, paquete, manifiesto, grafo, recursos, representaciones, perfiles y renderizadores.

Formato P2LRN

Qué contiene físicamente el paquete, cómo se organiza y qué datos pertenecen al host y no al curso.

Progresión

Cómo se declaran obligatoriedad, finalización, notas mínimas, bloqueo y prerrequisitos.

Métricas y analítica

Qué estado, notas y eventos produce el Player y cómo se separan del contenido portable.

Si sólo quieres crear un curso con el Studio alojado

Puedes abrir Studio directamente sin instalar nada. La fase de instalación sólo es necesaria cuando quieres incorporar P2LRN dentro de tu propio proyecto o utilizar Toolkit desde código.

Responsabilidad de cada pieza

STUDIO

Editor visual para construir y modificar cursos.

TOOLKIT

API y CLI para creación, validación, lectura y transformación.

PLAYER

Abre, verifica y reproduce el paquete para el alumno.

PLATAFORMA

Conserva usuarios, permisos, progreso, puntuación y secretos.

Regla de lectura

Las páginas de empezar explican el modelo del producto y del paquete. Las páginas de instalación explican cómo disponer del componente. Creación explica cómo producir contenido; reproducción, qué ocurre para el alumno; integración, cómo conectarlo con tu aplicación. Progresión y métricas aparecen al principio porque afectan a varias fases y conviene entenderlas antes de decidir la arquitectura.
