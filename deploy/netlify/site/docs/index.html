Mapa de responsabilidades

STUDIO

Autoría visual y exportación del paquete.

TOOLKIT

Autoría por código, Reader, validación, conversión, multipart, delta y trust.

PLAYER

Lectura, integridad, renderizado, progresión y eventos. Se carga por NPM o CDN.

HOST

Usuarios, autorización, matrícula, persistencia durable, secretos y telemetría.

Regla rápida

NPM y CDN son alternativas para cargar el Player.

Studio y Toolkit son alternativas de autoría. Puedes crear con Studio y reproducir por NPM o CDN; también puedes crear con Toolkit y reproducir por cualquiera de los dos canales.
