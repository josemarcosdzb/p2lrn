INICIO

Documentación de P2LRN

La documentación sigue el orden real de trabajo: primero eliges el recorrido y preparas P2LRN; después creas, reproduces e integras el curso. Las alternativas técnicas se mantienen separadas para no mezclar instrucciones.

Recorrido recomendado

1 · ORIENTARTE

Antes de empezar

Decide si vas a usar Studio, Player o Toolkit y qué resultado necesitas.

2 · PREPARAR

Instalar

Elige Studio alojado, NPM o CDN. Si trabajas dentro de un proyecto, la instalación va antes de crear el curso.

3 · CREAR

Crear el curso

Usa Studio para autoría visual o Toolkit para autoría por código.

4 · REPRODUCIR

Probar con Player

Abre el paquete, comprueba el contenido y verifica actividades y progresión.

5 · INTEGRAR

Conectar tu plataforma

Usuarios, progreso, puntuación, eventos y recursos privados permanecen en tu aplicación.

Si sólo quieres crear un curso con el Studio alojado

Puedes abrir Studio directamente sin instalar nada. La fase de instalación sólo es necesaria cuando quieres incorporar P2LRN dentro de tu propio proyecto o utilizar Toolkit desde código.

Responsabilidad de cada pieza

STUDIO

Editor visual para construir y modificar cursos.

TOOLKIT

API y CLI para creación, validación, lectura y transformación.

PLAYER

Abre, verifica y reproduce el paquete para el alumno.

PLATAFORMA

Conserva usuarios, permisos, progreso, puntuación y secretos.

Regla de lectura

Las páginas de instalación explican cómo disponer del componente. Las páginas de creación explican cómo producir contenido. Las páginas de reproducción explican qué hace el alumno. Las páginas de integración explican cómo conectar P2LRN con tu aplicación. No necesitas mezclar instrucciones entre esas fases.
