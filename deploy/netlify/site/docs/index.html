P2LRN Documentation

La documentación separa autoría (Studio o Toolkit) de carga en el navegador (NPM o CDN). Tanto Player como Studio pueden integrarse por NPM o CDN; Toolkit es una herramienta Node/TypeScript.

Mapa de responsabilidades

STUDIO

Autoría visual. Se puede cargar por NPM o CDN.

TOOLKIT

Autoría por código, Reader, validación, conversión, multipart, delta y trust.

PLAYER

Lectura, integridad, renderizado, progresión y eventos. Se puede cargar por NPM o CDN.

HOST

Usuarios, autorización, matrícula, persistencia durable, secretos y telemetría.

Regla rápida

NPM y CDN son canales alternativos de frontend.

Studio y Toolkit son formas distintas de autoría. El canal con el que cargas Player o Studio no cambia el formato .p2lrn ni las responsabilidades del Host.
