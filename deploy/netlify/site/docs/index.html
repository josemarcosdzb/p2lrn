P2LRN Documentation

Guía de desarrollador para crear un paquete real, entender su estructura, dividir payloads grandes, reproducirlo con el Player e integrarlo con una aplicación host.

Empieza por tu objetivo

01

Primer curso en 5 minutos

Crea un paquete desde cero, valida, sirve por HTTP y comprueba ready y rendered.

 02

Elegir la pieza correcta

Player, Toolkit, Reader, Host Adapter, Multipart o Visor según lo que necesitas.

 03

Crear o editar

Workspace editable, recursos, cuestionarios, componentes, build e inspección.

 04

Definir progresión

Obligatoriedad, bloqueos, requisitos, puntuación y prerrequisitos reales.

 05

Trabajar con cursos grandes

Descriptor, partes, SHA-256, publicación y reconstrucción.

 06

Integrar con tu plataforma

Host Adapter, estado, recursos verificados, CORS y runtimes.

 07

Crear juegos 3D

Three.js, Rapier y mecánicas de ordenar, relacionar y clasificar sin depender de un LMS.

 08

Escuchar eventos

Contrato actual del Player y nombres reales del runtime.

 09

Probar el visor real

Abre paquetes canónicos y observa metadata, renderer y eventos.

Mapa de responsabilidades

PACKAGE

Estructura, contenido, manifiesto, perfiles y recursos portables.

PLAYER

Lectura, integridad, renderizado, progresión y eventos.

TOOLKIT

Autoría, Reader, validación, conversión, multipart, delta y trust.

HOST

Usuarios, autorización, matrícula, persistencia durable, secretos y telemetría.

Ruta recomendada

  1. 1. Quickstart.Comprueba el flujo mínimo de principio a fin.
  2. 2. Formato.Entiende manifest, graph, perfiles y representaciones.
  3. 3. Autoría.Construye un curso desde un workspace editable.
  4. 4. Player.Reproduce el artefacto y observa los eventos.
  5. 5. Integración.Conecta estado y recursos con tu Host.
  6. 6. Referencia.Consulta firmas exactas, CLI y contratos.
