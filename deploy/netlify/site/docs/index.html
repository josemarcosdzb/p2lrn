INICIO

Documentación de P2LRN

Empieza por lo que necesitas conseguir. La documentación separa autoría, instalación, reproducción e integración para que cada recorrido tenga un principio, un resultado y un siguiente paso claros.

Empieza por tu objetivo

CREAR VISUALMENTE

Studio

Crea el curso, organiza unidades y lecciones, añade actividades, comprueba la vista del alumno y exporta el .p2lrn.

CREAR POR CÓDIGO

Toolkit y CLI

Construye, valida y transforma paquetes desde Node.js, TypeScript o la línea de comandos.

USARLO EN UNA APLICACIÓN

Instalar y reproducir

Elige una única forma de carga para tu aplicación y continúa con Player o Studio.

CONECTAR UNA PLATAFORMA

Integración

Conecta usuarios, progreso, puntuación, eventos y recursos protegidos sin introducirlos dentro del paquete.

Rutas recomendadas

Autor visual

Studio → crear contenido → Vista alumno → descargar o guardar → Player.

Autor por código

Toolkit → crear paquete → progresión → validar → Player.

Desarrollador de aplicación

elegir recorrido → instalar → Player → Host Adapter → eventos.

Evaluaciones y juegos

modelo de cuestionario → elegir presentación → probar el ejemplo → integrar con Player.

Qué responsabilidad tiene cada parte

STUDIO

Editor visual. Trabaja sobre la estructura y el contenido del curso y produce un paquete portable.

TOOLKIT

API y herramientas de autoría, lectura, validación, conversión y empaquetado.

PLAYER

Abre el paquete, verifica recursos, selecciona una presentación y ejecuta la experiencia del alumno.

PLATAFORMA

Conserva identidad, autorización, matrícula, progreso, puntuación, secretos y persistencia.

Cómo está organizada la documentación

Empezar orienta la decisión. Crear explica Studio, Toolkit y el formato. Instalar mantiene separadas las rutas disponibles. Reproducir cubre Player, cuestionarios, juegos y ejemplos. Integrar conecta P2LRN con tu aplicación. Referencia concentra recetas, términos, API y solución de problemas.
