HELP / TROUBLESHOOTING

Solución de problemas

Empieza por la fase que falla y conserva el mensaje de p2lrn:error. No desactives integridad para ocultar un síntoma.

Player no carga

  1. 1.Comprueba que /player/current/dist/p2lrn.js responde.
  2. 2.Ejecuta customElements.get('p2lrn-player').
  3. 3.Comprueba src y Network.
  4. 4.Escucha p2lrn:error.
  5. 5.Si el paquete abre pero no renderiza, revisa renderer/runtime.

CORS

Síntoma: la petición al paquete o a una parte externa falla antes de que el Player pueda verificarla. Comprueba el origen de la aplicación, la respuesta OPTIONS cuando exista preflight y Access-Control-Allow-Origin. * sólo abre lectura cross-origin; no autoriza a un usuario.

contentRoot / digest mismatch

El paquete, graph o payload cambió después de calcular integridad o llegó corrupto. Vuelve a generar o recuperar el artefacto correcto. No edites manualmente el digest para que coincida.

Renderer no disponible

Consulta P2LRN.renderers(). Si fijaste renderer, verifica que su id exista y que acepte profile/mediaType/ubicación de la representación. El Player sólo hace fallback en categorías de incompatibilidad previstas.

Multipart: falta una parte

El descriptor usa href relativos al .p2lrn. Verifica que todas las .partNNN se publiquen junto al paquete y no se renombren. Si una parte existe pero cambia, su SHA-256 debe fallar.

HTTP Range

El Player puede abrir paquetes remotos por rangos. Si el servidor no soporta el patrón esperado, revisa respuestas 206, Content-Range y límites de proxy/CDN. El transporte actual puede cambiar a lectura completa cuando no dispone de range.

Runtime origin must be isolated

Síntoma: aparece un error indicando que el origen del runtime y el de la aplicación son iguales. No desactives la comprobación: configura runtime-base-url con otro origen real (subdominio, dominio o puerto distinto). En el visor público, la aplicación usa p2lrn.netlify.app y el runtime usa el alias aislado de la rama principal.

\n

H5P library missing

Comprueba runtime-base-url, el catálogo de librerías compartidas y la versión solicitada por el contenido. No asumas que una librería existe sólo porque H5P se pueda abrir.

SCORM / runtime externo no arranca

Revisa entrypoint, host de runtime, CSP/CORS, permisos del iframe y que los recursos internos se resuelvan dentro del host aislado. Un paquete preservado no implica necesariamente ejecución completa.

No llega completion

El contrato actual del Player usa p2lrn:complete, no p2lrn:completion. Para estado usa p2lrn:statechange; para cambios de progresión usa p2lrn:progressionchange. Verifica además que el renderer concreto emita ese evento.

Fallo al guardar progreso

Si Host Adapter.saveState() falla, el Player emite p2lrn:error con fase progression-save. El estado de alumno pertenece al Host; no intentes escribirlo dentro del paquete.

Diagnóstico rápido

JavaScript
const player = document.querySelector('p2lrn-player');

player.addEventListener('p2lrn:error', (event) => {
  console.error(event.detail);
});

console.table(P2LRN.renderers());
console.log(P2LRN.version, P2LRN.toolkitVersion);
