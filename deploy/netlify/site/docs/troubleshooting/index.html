HELP / TROUBLESHOOTING

Solución de problemas

Diagnóstico rápido de los fallos más habituales al cargar paquetes, configurar CORS, resolver runtimes o escuchar eventos.

El Player no carga

Comprueba que el script del Player responde, que <p2lrn-player> está registrado y que el atributo src apunta a una URL HTTP accesible desde el navegador.

Error de CORS

El origen que sirve el paquete debe permitir solicitudes desde la aplicación. Si el recurso es privado, evita * y usa una política de origen explícita o URLs autorizadas.

Package integrity failed

Algún recurso, manifiesto o digest no coincide. No ignores el error: reconstruye el paquete con Toolkit o vuelve a obtener el artefacto original.

Renderer no disponible

Si has fijado renderer, confirma que esa implementación existe y es compatible. Si no necesitas forzar uno, elimina el atributo para permitir la selección normal.

H5P library missing

El contenido H5P puede depender de librerías no embebidas. Verifica el catálogo compartido y que el runtime configurado pueda resolver la versión solicitada.

SCORM no arranca

Confirma que el paquete SCORM conserva su entrypoint, que el host aislado puede cargar sus recursos y que no hay bloqueos CSP/CORS incompatibles.

HTTP Range / Service Worker

Para recursos que requieran búsqueda por rangos, comprueba soporte 206/Range del servidor. Instala el Service Worker sólo cuando tu despliegue realmente lo necesita.

No llega el evento esperado

Registra los listeners antes de iniciar la interacción y comprueba primero p2lrn:ready y p2lrn:error. Después valida si el renderer concreto genera el evento de progreso/score que esperas.
