Cuestionarios y juegos

Empieza desde Studio si estás creando visualmente. Las distintas presentaciones reutilizan el mismo modelo de cuestionario y cambian la experiencia del alumno sólo cuando el contenido es compatible.

1. Crear una actividad desde Studio

  1. Abre el curso.Entra en Studio y selecciona la unidad o lección donde quieres añadir la actividad.
  2. Añade contenido.Para una evaluación convencional usa Evaluación → Cuestionario. Para una mecánica específica usa Juegos y elige Memoria, Relacionar, Ordenar, Clasificar, Verdadero/Falso, Completar huecos, Sopa de letras, Crucigrama, Rosco o Juego 3D.
  3. Edita con controles visuales.Escribe preguntas, respuestas y soluciones en el editor. No necesitas tocar JSON.
  4. Prueba la Vista alumno.Comprueba la actividad antes de guardar o descargar el curso.

2. Un mismo cuestionario, distintas experiencias

Las preguntas se guardan como application/vnd.p2lrn.questionnaire+json. La presentación elegida no crea otra copia del contenido: indica al Player cómo debe mostrar ese cuestionario.

La presentación nunca debe perder preguntas.

Si todo el cuestionario no puede representarse fielmente con una mecánica, esa presentación se considera incompatible. P2LRN no elimina preguntas ni inventa respuestas para hacerla encajar.

Vocabulario y escritura

Completar huecos permite responder escribiendo o arrastrando cuando el contenido lo admite. También puedes usar Sopa de letras, Crucigrama o Rosco.

Experiencia espacial

Juego 3D.

4. Qué explica cada guía

Cada presentación sigue ahora el mismo orden: qué ve el alumno, cómo crearla en Studio, requisitos del contenido, un ejemplo de datos completo y válido, alternativa por CLI, identificador técnico, accesibilidad, finalización y una prueba en el visor.

5. Estado y puntuación

Todas las presentaciones actualizan el mismo estado del cuestionario. Para escuchar puntuación y finalización utiliza Eventos; para persistirlas en una plataforma, configura Host Adapter.

6. Probar antes de integrar

El visor permite abrir los paquetes de ejemplo y cambiar de presentación cuando el contenido sea compatible.

Un cuestionario, varias preguntas y corrección al finalizar

Para evaluar varias preguntas juntas, créalas dentro de una misma actividad Cuestionario en Studio con «Añadir pregunta». El modo «Una pregunta cada vez» ofrece Anterior y Siguiente hasta la última pregunta, donde se entrega el conjunto. Crear actividades independientes de una pregunta produce entregas y resultados independientes.

En los cursos y juegos nuevos, la autocorrección visible para el alumno queda desactivada inicialmente. El profesor puede seleccionar expresamente «Mostrar autocorrección solo al finalizar». Hasta la entrega, los juegos de ordenar, relacionar y clasificar deben permitir respuestas provisionales sin revelar cuáles son correctas. Para evaluaciones en las que no deban distribuirse las claves de respuestas, utilice corrección de Host autorizada y no un paquete con soluciones embebidas.

Los huecos de arrastre se definen en el lugar exacto de la frase mediante {{id}} o marcadores ___. Los cursos largos deben permanecer desplazables y los juegos 3D mantienen límites físicos para los objetos móviles.
