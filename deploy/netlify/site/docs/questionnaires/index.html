BUILD / QUESTIONNAIRES

Questionnaires y juegos

Un único modelo portable de preguntas puede tener varias presentaciones. Cada renderer debe representar el cuestionario completo sin inventar ni descartar contenido.

Un contenido, varias presentaciones

Los juegos parten de application/vnd.p2lrn.questionnaire+json. El renderer es una preferencia de presentación instalada por el Player, no una segunda fuente de verdad.

Conversión completa o ninguna

Los renderers de juego comprueban compatibilidad antes de ejecutar. Si una pregunta no puede representarse con fidelidad, no se elimina silenciosamente.

Modelo base

schema

https://p2lrn.org/schema/native-questionnaire/0.4.0

grading.mode

embedded-key o host.

question types

single-choice, multiple-choice, true-false, text, fill-blanks, ordering, matching y classification.

presentation

questionMode, shuffleQuestions y showFeedback.

attemptPolicy

maxAttempts y timeLimitSeconds.
