Cuestionarios y juegos

Un único modelo portable de preguntas puede tener varias presentaciones. Cada renderizador debe representar el cuestionario completo sin inventar ni descartar contenido.

Un contenido, varias presentaciones

Todas las presentaciones parten de application/vnd.p2lrn.questionnaire+json. El contenido de preguntas y respuestas sigue siendo el mismo; el renderizador sólo decide cómo presentarlo cuando todo el cuestionario es compatible con esa mecánica.

Conversión completa o ninguna

Los renderizadores de juego comprueban compatibilidad antes de ejecutar. Si una pregunta no puede representarse con fidelidad, no se elimina silenciosamente.

Modelo base

schema

https://p2lrn.org/schema/native-questionnaire/0.4.0

grading.mode

embedded-key o host.

question types

single-choice, multiple-choice, true-false, text, fill-blanks, ordering, matching y classification.

presentation

questionMode, shuffleQuestions y showFeedback.

attemptPolicy

maxAttempts y timeLimitSeconds.

Cómo elegir una presentación

Empieza por el objetivo didáctico y comprueba después si todas las preguntas cumplen los requisitos de la presentación. Si necesitas mezclar tipos de pregunta o conservar una evaluación convencional, utiliza la presentación estándar. Si quieres una mecánica de práctica, elige únicamente una que pueda representar todas las preguntas sin perder información.

Evaluación directa

Estándar. Mantiene los controles propios de cada tipo de pregunta.

Asociación

Memoria o Emparejar cuando el contenido forma parejas inequívocas.

Secuencia

Ordenar para procedimientos, cronologías o pasos.

Agrupación

Clasificar para objetos que pertenecen a categorías.

Vocabulario

Sopa de letras, Crucigrama o Rosco cuando las soluciones son textuales.

Experiencia espacial

3D para ordenar, relacionar o clasificar con una alternativa accesible en HTML.

Estado, puntuación y finalización

Las presentaciones comparten el mismo estado de cuestionario. Una mecánica de juego no crea un segundo modelo de respuestas: actualiza el cuestionario original y, al finalizar, utiliza el contrato común de puntuación y finalización. Consulta Eventos para integrar esos resultados.

Ejemplos ejecutables

Los ejemplos permiten abrir distintas presentaciones del mismo modelo de cuestionario y comprobar qué requisitos tiene cada una.
