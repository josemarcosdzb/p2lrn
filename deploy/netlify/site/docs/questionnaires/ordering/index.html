Ordenar

Pide al alumno que coloque una secuencia en el orden correcto.

1. Qué hace y qué ve el alumno

Pide al alumno que coloque una secuencia en el orden correcto.

Úsalo para procedimientos, cronologías, fases, prioridades o cualquier contenido en el que el orden completo sea parte de la respuesta.

2. Crear en Studio

Éste es el recorrido normal si estás creando el curso visualmente. No necesitas escribir JSON ni ejecutar comandos.

  1. Abre Studio.Usa el editor alojado o el Studio que hayas integrado en tu proyecto.
  2. Añade la actividad.En Añadir contenido, abre Juegos y elige Ordenar.
  3. Edita visualmente.Cambia enunciados, respuestas y opciones con los controles del editor. El JSON queda como vista avanzada, no como requisito de uso.
  4. Comprueba la Vista alumno.Reproduce la actividad antes de descargar o guardar el curso.

3. Requisitos del contenido

  • En Studio se crea como una pregunta de tipo Ordenar.
  • Cada secuencia debe tener al menos tres elementos.
  • solution.order debe contener todos los identificadores exactamente una vez.
  • La actividad requiere soluciones embebidas.

4. Ejemplo de datos válido

Este bloque muestra un cuestionario completo y válido para esta presentación. Sirve para entender el formato o para el recorrido por CLI; si utilizas Studio, el editor genera esta estructura por ti.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Ordenar el ciclo del agua",
  "language": "es",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "ordering",
      "prompt": "Ordena las fases",
      "points": 3,
      "items": [
        {
          "id": "i1",
          "text": "Evaporación"
        },
        {
          "id": "i2",
          "text": "Condensación"
        },
        {
          "id": "i3",
          "text": "Precipitación"
        }
      ],
      "solution": {
        "order": [
          "i1",
          "i2",
          "i3"
        ]
      }
    }
  ]
}

5. Cómo leer el ejemplo

items contiene los elementos visibles. solution.order declara la secuencia correcta usando sus identificadores.

6. Crear por CLI — alternativa avanzada

Utiliza este recorrido sólo si estás generando el curso por código. Requiere Toolkit instalado mediante NPM. El archivo quiz.json debe contener un cuestionario válido como el ejemplo anterior.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Ordenar" \
  --renderer "https://p2lrn.org/renderer/questionnaire/ordering"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer selecciona la presentación preferida. No crea una segunda copia de las preguntas: el contenido sigue siendo el cuestionario nativo.

7. Identificador técnico de la presentación

Normalmente Studio lo configura por ti. Sólo necesitas este identificador cuando seleccionas la presentación desde código, CLI o el visor.

8. Interacción y accesibilidad

El alumno puede reordenar mediante arrastre y también dispone de controles para subir o bajar elementos.

9. Finalización y puntuación

El orden actual se compara con la solución. Cuando la secuencia es correcta, la actividad comunica el resultado.

Para guardar el resultado en tu plataforma, consulta Eventos y Host Adapter.
