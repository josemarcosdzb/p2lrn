CUESTIONARIOS / PRESENTACIÓN

Ordenar

Transforma preguntas ordering en secuencias reordenables con controles accesibles de subir y bajar.

Renderizador

https://p2lrn.org/renderizador/questionnaire/ordering

Versión: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Todas las preguntas del cuestionario deben ser ordering.
  • Cada secuencia necesita al menos 3 elementos y una solución completa.
  • No se eliminan preguntas incompatibles para forzar el juego.
  • El orden actual se persiste en la misma respuesta del questionnaire.

Modelo mínimo

JSON
{
  "id":"orden","type":"ordering","prompt":"Ordena las fases","points":3,
  "items":[{"id":"a","text":"Inicio"},{"id":"b","text":"Proceso"},{"id":"c","text":"Final"}],
  "solution":{"order":["a","b","c"]}
}

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Ordenar" \
  --renderizador "https://p2lrn.org/renderizador/questionnaire/ordering"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderizador añade una preferencia de presentación; las preguntas siguen siendo native-questionnaire.

Ejecución y eventos

Las respuestas se mantienen en el mismo estado de questionnaire. Los renderizadores que finalizan la actividad reportan puntuación/finalización mediante el contrato común; consulta Eventos.
