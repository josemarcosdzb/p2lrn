Crucigrama

Construye un único crucigrama conectado a partir de pistas y respuestas inequívocas.

Qué ve el alumno

El alumno completa un crucigrama conectado a partir de las pistas del cuestionario, escribiendo una letra en cada casilla.

Cuándo utilizar esta presentación

Úsalo cuando las respuestas son palabras breves, las pistas son claras y el conjunto puede formar un único tablero conectado.

Renderizador

https://p2lrn.org/renderizador/questionnaire/crossword

Versión: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Requiere soluciones embebidas y pistas no vacías.
  • Cada respuesta normalizada debe tener entre 3 y 17 caracteres.
  • Mínimo 4 y máximo 80 respuestas.
  • Las palabras deben formar un único tablero conectado y todas deben poder colocarse.

Modelo mínimo

JSON / guía
// El runtime rechaza una disposición parcial.
// Pistas repetidas o respuestas ambiguas invalidan la presentación.

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Crucigrama" \
  --renderizador "https://p2lrn.org/renderizador/questionnaire/crossword"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

La preferencia de renderizador no duplica el contenido: el fuente principal sigue siendo native-questionnaire.

Interacción y accesibilidad

Cada casilla editable es un campo de texto de un carácter con una etiqueta que indica fila y columna. La actividad incluye acciones explícitas para comprobar y reiniciar.

Finalización y puntuación

Al comprobar, el runtime contrasta todas las letras con la solución. Cuando el tablero está completo y correcto aplica las respuestas y finaliza la actividad con su puntuación.

Para integrar los resultados con una plataforma, consulta Eventos y Host Adapter.
