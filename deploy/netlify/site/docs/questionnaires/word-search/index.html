Sopa de letras

Construye una cuadrícula de letras a partir de respuestas textuales. El alumno localiza cada respuesta guiándose por las pistas.

Encontrar las palabras de una sopa de letras

Úsalo para vocabulario, nombres, conceptos breves o repaso de términos.

PARA PROFESORES Y CREADORES

Crear sopa de letras en Studio

Crea la actividad con la interfaz y comprueba las soluciones. No necesitas escribir JSON ni ejecutar comandos.

  1. Abre tu curso.Entra en Studio y selecciona la unidad o lección donde vas a crear la actividad.
  2. Añade la actividad.En Añadir contenido, abre Juegos y elige Sopa de letras.
  3. Prepara el contenido.Introduce las palabras que hay que encontrar y las pistas necesarias.
  4. Define la solución.Comprueba la cuadrícula y que se puedan seleccionar todas las palabras.
  5. Comprueba la Vista alumno.Reproduce la actividad antes de descargar o guardar el curso.
  6. Guarda y vuelve a abrir.Descarga el curso .p2lrn y comprueba el archivo en el Visor.

Comprobar antes de compartir

Termina la actividad en Vista alumno y prueba el archivo exportado en el Visor.

Accesibilidad, puntuación y resultados

Interacción y accesibilidad

Las celdas tienen etiquetas accesibles y las pistas incluyen campos de texto como alternativa a seleccionar letras en la cuadrícula.

Finalización y puntuación

Cuando se encuentran todas las palabras, se aplican las respuestas a sus preguntas y finaliza la actividad.

Para guardar el resultado en tu plataforma, consulta Eventos y Host Adapter.

Prueba del archivo exportado

Abre tu archivo .p2lrn en el Visor y termina el ejercicio. Comprueba instrucciones, corrección y resultado.

Para desarrolladores: JSON, CLI e integración

Solo necesitas estos datos si vas a generar paquetes mediante código o integrar la actividad en otra plataforma.

Abrir ejemplos JSON y comandos técnicos

Requisitos del contenido

  • En Studio se edita con preguntas de tipo Respuesta de texto.
  • Se necesitan al menos tres respuestas.
  • Cada respuesta normalizada debe tener entre 3 y 16 caracteres.
  • Todas las palabras deben poder colocarse: P2LRN no elimina preguntas para forzar el tablero.

Ejemplo de datos válido

Este ejemplo recoge los datos de la actividad para quienes trabajan con la CLI. En Studio puedes configurarla desde el editor visual.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Planetas",
  "language": "es",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "text",
      "prompt": "Planeta más cercano al Sol",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "MERCURIO"
        ]
      }
    },
    {
      "id": "q2",
      "type": "text",
      "prompt": "Segundo planeta del Sistema Solar",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "VENUS"
        ]
      }
    },
    {
      "id": "q3",
      "type": "text",
      "prompt": "Nuestro planeta",
      "points": 1,
      "solution": {
        "acceptedAnswers": [
          "TIERRA"
        ]
      }
    }
  ]
}

Cómo leer el ejemplo

Cada pregunta textual aporta una pista y una respuesta aceptada. El Player normaliza las respuestas y construye la cuadrícula sólo si puede representar el conjunto completo.

Crear por CLI — alternativa avanzada

Utiliza este recorrido sólo si estás generando el curso por código. Requiere Toolkit instalado mediante NPM. El archivo quiz.json debe contener un cuestionario válido como el ejemplo anterior.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Sopa de letras" \
  --renderer "https://p2lrn.org/renderer/questionnaire/word-search"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer selecciona la presentación preferida. No crea una segunda copia de las preguntas: el contenido sigue siendo el cuestionario nativo.

Identificador técnico de la presentación

Normalmente Studio lo configura por ti. Sólo necesitas este identificador cuando seleccionas la presentación desde código, CLI o el visor.
