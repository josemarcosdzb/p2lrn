CUESTIONARIOS / PRESENTACIÓN

Sopa de letras

Genera una cuadrícula determinista a partir de respuestas textuales del cuestionario.

Qué ve el alumno

El alumno busca las respuestas dentro de una cuadrícula de letras. Puede marcar palabras directamente en la cuadrícula o utilizar los campos de respuesta asociados a las pistas.

Cuándo utilizar esta presentación

Úsalo para vocabulario, términos breves y repaso de conceptos cuando existan al menos tres respuestas textuales adecuadas para construir la cuadrícula.

Renderizador

https://p2lrn.org/renderizador/questionnaire/word-search

Versión: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Requiere soluciones embebidas.
  • Todas las respuestas convertidas deben tener entre 3 y 16 caracteres normalizados.
  • Se necesitan al menos 3 respuestas textuales.
  • La colocación debe ser completa; si no caben todas, el juego es incompatible.

Modelo mínimo

JSON / guía
{"id":"q1","type":"text","prompt":"Planeta rojo","points":1,
 "solution":{"acceptedAnswers":["MARTE"]}}

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Sopa de letras" \
  --renderizador "https://p2lrn.org/renderizador/questionnaire/word-search"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

La preferencia de renderizador no duplica el contenido: el fuente principal sigue siendo native-questionnaire.

Interacción y accesibilidad

Cada celda es un botón con fila, columna y letra en su etiqueta accesible. Además, las pistas incluyen campos de texto que ofrecen una alternativa a seleccionar letras mediante gesto.

Finalización y puntuación

Las palabras encontradas aplican la respuesta de su pregunta. Cuando se completan todas, el runtime finaliza la actividad y comunica la puntuación.

Para integrar los resultados con una plataforma, consulta Eventos y Host Adapter.
