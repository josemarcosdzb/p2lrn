BUILD / QUESTIONNAIRE RENDERER

Memoria

Convierte el cuestionario completo en parejas de pista y respuesta presentadas como cartas de memoria.

Renderer

https://p2lrn.org/renderer/questionnaire/memory

Versión instalada actualmente: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Requiere grading.mode=embedded-key y soluciones embebidas.
  • Cada pregunta debe poder expresarse como una o más parejas inequívocas; no se genera una versión parcial.
  • Se necesitan al menos 3 parejas.
  • Pistas o respuestas repetidas que hagan ambiguo el emparejamiento invalidan esta presentación.

Modelo mínimo

JSON
// Usa preguntas con respuestas textuales inequívocas.
// Ejemplo: tres single-choice con una única respuesta correcta distinta.

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Memoria" \
  --renderer "https://p2lrn.org/renderer/questionnaire/memory"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer añade una preferencia de presentación; las preguntas siguen siendo native-questionnaire.

Runtime y eventos

Las respuestas se mantienen en el mismo estado de questionnaire. Los renderers que finalizan la actividad reportan puntuación/finalización mediante el contrato común; consulta Eventos.
