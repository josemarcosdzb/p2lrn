CUESTIONARIOS / PRESENTACIÓN

Memoria

Convierte el cuestionario completo en parejas de pista y respuesta presentadas como cartas de memoria.

Qué ve el alumno

El alumno abre cartas ocultas de dos en dos y debe localizar las parejas derivadas del cuestionario. Las cartas resueltas permanecen visibles hasta completar el tablero.

Cuándo utilizar esta presentación

Úsalo cuando el contenido puede expresarse como parejas inequívocas y quieres practicar asociación y reconocimiento mediante una mecánica de memoria.

Renderizador

https://p2lrn.org/renderizador/questionnaire/memory

Versión: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Requiere grading.mode=embedded-key y soluciones embebidas.
  • Cada pregunta debe poder expresarse como una o más parejas inequívocas; no se genera una versión parcial.
  • Se necesitan al menos 3 parejas.
  • Pistas o respuestas repetidas que hagan ambiguo el emparejamiento invalidan esta presentación.

Modelo mínimo

JSON
// Usa preguntas con respuestas textuales inequívocas.
// Ejemplo: tres single-choice con una única respuesta correcta distinta.

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Memoria" \
  --renderizador "https://p2lrn.org/renderizador/questionnaire/memory"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderizador añade una preferencia de presentación; las preguntas siguen siendo native-questionnaire.

Ejecución y eventos

Las respuestas se mantienen en el mismo estado de questionnaire. Los renderizadores que finalizan la actividad reportan puntuación/finalización mediante el contrato común; consulta Eventos.

Interacción y accesibilidad

Cada carta es un botón. Antes de abrirla se anuncia como carta oculta y, al revelarla, el control expone su texto. La actividad puede completarse sin gestos de arrastre.

Finalización y puntuación

Cuando todas las parejas están resueltas, el runtime aplica las respuestas correspondientes y finaliza la actividad, comunicando la puntuación obtenida.

Para integrar los resultados con una plataforma, consulta Eventos y Host Adapter.
