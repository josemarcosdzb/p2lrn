CUESTIONARIOS / PRESENTACIÓN

Juego de memoria para emparejar cartas y conceptos

Convierte relaciones inequívocas en cartas ocultas. El alumno descubre dos cartas cada vez y busca las parejas correctas hasta completar el tablero.

Descubrir y emparejar cartas

Úsalo para vocabulario, conceptos y definiciones o relaciones uno a uno que se benefician de repetición y reconocimiento.

Define las parejas que aparecerán en las cartas

En este ejemplo los alumnos asocian planetas con pistas. Cada correspondencia se prepara en una fila y se convierte en un par de cartas durante la partida.

Configuración del ejercicio

  1. Añade la actividadAbre tu curso y selecciona la unidad donde irá. En «Añadir contenido» elige «Juegos → Memoria».
  2. Redacta la consignaEscribe un enunciado claro, como «Encuentra las parejas de planetas y pistas».
  3. Introduce las respuestasRellena las columnas «Elemento» y «Pareja correcta»: Mercurio–planeta próximo al Sol, Tierra–planeta con océanos, Marte–planeta rojo. Para incorporar más cartas, pulsa «+ Añadir pareja».
  4. Ajusta la actividadComprueba que cada carta tenga una única pareja posible y ajusta «Puntos» antes de continuar.
  5. Revisa el resultadoEn Vista alumno destapa las cartas, comprueba que las correspondencias se reconozcan y termina la ronda.

Accesibilidad, puntuación y resultados

Interacción y accesibilidad

Cada carta es un botón. La actividad se puede completar con teclado; el estado visual de las cartas no es el único indicador de selección.

Finalización y puntuación

Cuando todas las parejas quedan resueltas, la actividad finaliza y el Player comunica la puntuación.

Para guardar el resultado en tu plataforma, consulta Eventos y Host Adapter.

Prueba del archivo exportado

Abre tu archivo .p2lrn en el Visor y termina el ejercicio. Comprueba instrucciones, corrección y resultado.

Requisitos del contenido

  • En Studio, el preset de Memoria se edita como una pregunta de tipo Relacionar.
  • La actividad necesita soluciones embebidas y al menos tres parejas.
  • Las pistas y las respuestas no deben repetirse de forma que una pareja resulte ambigua.
Compatibilidad adicional del Player.

El Player también puede convertir otros tipos de pregunta en parejas cuando todas las relaciones se pueden deducir de forma inequívoca. Studio utiliza Relacionar porque es el formato visual más claro para crear este juego.

Ejemplo de datos válido

Este ejemplo recoge los datos de la actividad para quienes trabajan con la CLI. En Studio puedes configurarla desde el editor visual.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Relacionar países y capitales",
  "language": "es",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "matching",
      "prompt": "Relaciona cada país con su capital",
      "points": 3,
      "left": [
        {
          "id": "l1",
          "text": "España"
        },
        {
          "id": "l2",
          "text": "Francia"
        },
        {
          "id": "l3",
          "text": "Italia"
        }
      ],
      "right": [
        {
          "id": "r1",
          "text": "Madrid"
        },
        {
          "id": "r2",
          "text": "París"
        },
        {
          "id": "r3",
          "text": "Roma"
        }
      ],
      "solution": {
        "pairs": [
          {
            "left": "l1",
            "right": "r1"
          },
          {
            "left": "l2",
            "right": "r2"
          },
          {
            "left": "l3",
            "right": "r3"
          }
        ]
      }
    }
  ]
}

Cómo leer el ejemplo

El ejemplo usa una pregunta matching con tres elementos a cada lado. solution.pairs declara las tres relaciones y permite construir las seis cartas.

Crear por CLI — alternativa avanzada

Utiliza este recorrido sólo si estás generando el curso por código. Requiere Toolkit instalado mediante NPM. El archivo quiz.json debe contener un cuestionario válido como el ejemplo anterior.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Memoria" \
  --renderer "https://p2lrn.org/renderer/questionnaire/memory"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer selecciona la presentación preferida. No crea una segunda copia de las preguntas: el contenido sigue siendo el cuestionario nativo.

Identificador técnico de la presentación

Normalmente Studio lo configura por ti. Sólo necesitas este identificador cuando seleccionas la presentación desde código, CLI o el visor.
