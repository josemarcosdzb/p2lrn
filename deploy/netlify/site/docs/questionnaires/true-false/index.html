Preguntas de verdadero o falso para clase

Presenta una afirmación y dos respuestas posibles: Verdadero o Falso.

Evaluar afirmaciones de verdadero o falso

Úsalo para comprobaciones rápidas de hechos o conceptos binarios, no para preguntas que admitan matices o varias respuestas válidas.

Escribe afirmaciones que admitan una respuesta clara

Estas preguntas sirven para comprobar conocimientos concretos. En el ejemplo se pregunta si la Tierra gira alrededor del Sol.

Configuración del ejercicio

  1. Añade la actividadAbre tu curso y selecciona la unidad donde irá. En «Añadir contenido» elige «Juegos → Verdadero / Falso».
  2. Redacta la consignaEscribe una afirmación completa, sin dobles negaciones: «La Tierra gira alrededor del Sol».
  3. Introduce las respuestasEn el editor elige «Una afirmación» o «Varias afirmaciones» y marca la respuesta correcta, Verdadero o Falso.
  4. Ajusta la actividadAñade más preguntas si necesitas una ronda completa; revisa que todas tengan su solución y puntuación.
  5. Revisa el resultadoEn Vista alumno responde de ambas maneras para comprobar la corrección y la explicación final.

Verdadero/Falso: resultado de la ronda, no pantalla para responder

Cómo se responde: Para contestar, lee la afirmación y pulsa «Verdadero» o «Falso». Por ejemplo, «La Tierra gira alrededor del Sol» se responde «Verdadero». En esta captura solo aparecen «Ronda completada: 3/3 aciertos» y «Repetir ronda»; no aparecen las afirmaciones ni los botones para contestar. Por eso esta imagen no demuestra cómo se responde.

Comprueba las afirmaciones y sus respuestas

Termina la actividad en Vista alumno y prueba el archivo exportado en el Visor.

Accesibilidad, puntuación y resultados

Interacción y accesibilidad

Las respuestas son botones estándar y funcionan con teclado y tecnologías de asistencia.

Finalización y puntuación

Cada elección actualiza la respuesta de la pregunta. Al completar la ronda se comunica la puntuación total.

Para guardar el resultado en tu plataforma, consulta Eventos y Host Adapter.

Prueba del archivo exportado

Abre tu archivo .p2lrn en el Visor y termina el ejercicio. Comprueba instrucciones, corrección y resultado.
