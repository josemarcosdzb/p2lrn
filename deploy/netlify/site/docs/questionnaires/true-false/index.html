CUESTIONARIOS / PRESENTACIÓN

Verdadero / Falso

Presentación rápida para un cuestionario compuesto completamente por preguntas true-false.

Qué ve el alumno

El alumno recibe una afirmación cada vez y responde con uno de dos botones: Verdadero o Falso.

Cuándo utilizar esta presentación

Úsalo para comprobaciones rápidas de conceptos binarios cuando todas las preguntas tengan exactamente dos respuestas inequívocas.

Renderizador

https://p2lrn.org/renderizador/questionnaire/true-false

Versión: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Requiere grading.mode=embedded-key.
  • Cada pregunta debe tener exactamente dos opciones identificables como Verdadero/Falso o True/False.
  • Se necesitan al menos 2 preguntas.
  • Si una pregunta no cumple el contrato se rechaza la conversión completa.

Modelo mínimo

JSON
{
  "id":"vf1","type":"true-false",
  "prompt":"La Tierra orbita alrededor del Sol.","points":1,
  "choices":[{"id":"t","text":"Verdadero"},{"id":"f","text":"Falso"}],
  "solution":{"choiceIds":["t"]}
}

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Verdadero / Falso" \
  --renderizador "https://p2lrn.org/renderizador/questionnaire/true-false"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderizador añade una preferencia de presentación; las preguntas siguen siendo native-questionnaire.

Ejecución y eventos

Las respuestas se mantienen en el mismo estado de questionnaire. Los renderizadores que finalizan la actividad reportan puntuación/finalización mediante el contrato común; consulta Eventos.

Interacción y accesibilidad

La interacción se realiza con botones estándar, por lo que funciona con teclado y tecnologías de asistencia sin depender de arrastre o puntero.

Finalización y puntuación

Cada elección actualiza la respuesta de la pregunta. La actividad ofrece repetición de ronda y utiliza el mismo estado y contrato de puntuación del cuestionario.

Para integrar los resultados con una plataforma, consulta Eventos y Host Adapter.
