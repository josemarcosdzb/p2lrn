CUESTIONARIOS / PRESENTACIÓN

Verdadero / Falso

Presenta una afirmación y dos respuestas posibles: Verdadero o Falso.

1. Evaluar afirmaciones de verdadero o falso

Presenta una afirmación y dos respuestas posibles: Verdadero o Falso.

Úsalo para comprobaciones rápidas de hechos o conceptos binarios, no para preguntas que admitan matices o varias respuestas válidas.

2. Crear en Studio

En Studio, añade la actividad, configura sus respuestas y revisa la vista alumno antes de exportar.

Actividad de ejemplo. Usa afirmaciones como «La Tierra gira alrededor del Sol» y «La Luna es una estrella». El alumno marca verdadero o falso.

Qué comprobar. Evita negaciones múltiples, afirmaciones ambiguas y datos sin contexto; revisa las soluciones y explicaciones.

  1. Abre Studio.Usa el editor alojado o el Studio que hayas integrado en tu proyecto.
  2. Añade la actividad.En Añadir contenido, abre Juegos y elige Verdadero / Falso.
  3. Edita visualmente.Cambia enunciados, respuestas y opciones con los controles del editor. El JSON queda como vista avanzada, no como requisito de uso.
  4. Comprueba la Vista alumno.Reproduce la actividad antes de descargar o guardar el curso.

3. Requisitos del contenido

  • En Studio se crea con preguntas de tipo Verdadero / Falso.
  • Se necesitan al menos dos preguntas.
  • Cada pregunta debe tener exactamente dos opciones inequívocas y una solución embebida.

4. Ejemplo de datos válido

Este ejemplo recoge los datos de la actividad para quienes trabajan con la CLI. En Studio puedes configurarla desde el editor visual.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Verdadero o falso",
  "language": "es",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "true-false",
      "prompt": "La Tierra orbita alrededor del Sol",
      "points": 1,
      "choices": [
        {
          "id": "t1",
          "text": "Verdadero"
        },
        {
          "id": "f1",
          "text": "Falso"
        }
      ],
      "solution": {
        "choiceIds": [
          "t1"
        ]
      }
    },
    {
      "id": "q2",
      "type": "true-false",
      "prompt": "Marte es una estrella",
      "points": 1,
      "choices": [
        {
          "id": "t2",
          "text": "Verdadero"
        },
        {
          "id": "f2",
          "text": "Falso"
        }
      ],
      "solution": {
        "choiceIds": [
          "f2"
        ]
      }
    }
  ]
}

5. Cómo leer el ejemplo

Cada pregunta tiene dos choices. La solución señala cuál de sus identificadores es correcto mediante solution.choiceIds.

6. Crear por CLI — alternativa avanzada

Utiliza este recorrido sólo si estás generando el curso por código. Requiere Toolkit instalado mediante NPM. El archivo quiz.json debe contener un cuestionario válido como el ejemplo anterior.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Verdadero / Falso" \
  --renderer "https://p2lrn.org/renderer/questionnaire/true-false"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer selecciona la presentación preferida. No crea una segunda copia de las preguntas: el contenido sigue siendo el cuestionario nativo.

7. Identificador técnico de la presentación

Normalmente Studio lo configura por ti. Sólo necesitas este identificador cuando seleccionas la presentación desde código, CLI o el visor.

Identificador técnico

Perfil

Tipo de contenido

8. Interacción y accesibilidad

Las respuestas son botones estándar y funcionan con teclado y tecnologías de asistencia.

9. Finalización y puntuación

Cada elección actualiza la respuesta de la pregunta. Al completar la ronda se comunica la puntuación total.

Para guardar el resultado en tu plataforma, consulta Eventos y Host Adapter.

10. Probar el ejemplo

Abre el paquete de demostración en el visor real y comprueba la interacción antes de integrarlo.

Crea y comprueba tus propios ejercicios en Studio. Ya no se publican cursos nativos de prueba.
