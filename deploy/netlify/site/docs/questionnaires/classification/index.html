Clasificar elementos según sus categorías

Úsalo para taxonomías, propiedades, familias de conceptos o actividades de agrupación.

Configura las categorías y el destino de cada elemento

Clasificar permite agrupar conceptos según un criterio común. En ciencias, por ejemplo, puedes distribuir el Sol, las rocas y el agua en sus categorías.

Configuración del ejercicio

  1. Añade la actividadAbre tu curso y selecciona la unidad donde irá. En «Añadir contenido» elige «Juegos → Clasificar».
  2. Redacta la consignaEscribe el enunciado «Coloca cada elemento en su categoría».
  3. Introduce las respuestasEn «Categorías» crea Astros, Geología e Hidrosfera; utiliza «+ Añadir categoría» cuando necesites otra. En «Elementos» escribe Sol, Rocas y Agua.
  4. Ajusta la actividadSelecciona la categoría correcta en el desplegable de cada elemento. Usa «+ Añadir elemento» para completar el ejercicio.
  5. Revisa el resultadoEn Vista alumno coloca los elementos en sus destinos y verifica que las soluciones se reconozcan.

Clasificar: elementos ya colocados

Cómo se responde: Coloca cada ficha en su categoría. En este ejemplo, Luna y Cometa van a Astros; Granito y Volcán, a Geología; Río y Océano, a Hidrosfera. La captura muestra las seis fichas ya situadas: no enseña el arrastre ni el tablero antes de responder.

Revisa las categorías y la corrección

Termina la actividad en Vista alumno y prueba el archivo exportado en el Visor.

Accesibilidad, puntuación y resultados

Interacción y accesibilidad

Los objetos y categorías se pueden seleccionar mediante botones y teclado; el arrastre es una ayuda, no el único método.

Finalización y puntuación

Cada asignación actualiza la respuesta. La puntuación se calcula comparando todas las asignaciones con la solución.

Para guardar el resultado en tu plataforma, consulta Eventos y Host Adapter.

Prueba del archivo exportado

Abre tu archivo .p2lrn en el Visor y termina el ejercicio. Comprueba instrucciones, corrección y resultado.

Requisitos del contenido

  • En Studio se crea como una pregunta de tipo Clasificar.
  • Cada pregunta necesita al menos dos objetos y dos categorías.
  • La solución debe asignar todos los objetos a una categoría válida.
  • La actividad requiere soluciones embebidas.

Ejemplo de datos válido

Este ejemplo recoge los datos de la actividad para quienes trabajan con la CLI. En Studio puedes configurarla desde el editor visual.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Clasificar seres vivos",
  "language": "es",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "classification",
      "prompt": "Clasifica cada elemento",
      "points": 2,
      "items": [
        {
          "id": "perro",
          "text": "Perro"
        },
        {
          "id": "roble",
          "text": "Roble"
        }
      ],
      "categories": [
        {
          "id": "animal",
          "text": "Animal"
        },
        {
          "id": "planta",
          "text": "Planta"
        }
      ],
      "solution": {
        "assignments": [
          {
            "item": "perro",
            "category": "animal"
          },
          {
            "item": "roble",
            "category": "planta"
          }
        ]
      }
    }
  ]
}

Cómo leer el ejemplo

items son los objetos, categories son los destinos y solution.assignments contiene una asignación por objeto.

Crear por CLI — alternativa avanzada

Utiliza este recorrido sólo si estás generando el curso por código. Requiere Toolkit instalado mediante NPM. El archivo quiz.json debe contener un cuestionario válido como el ejemplo anterior.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Clasificar" \
  --renderer "https://p2lrn.org/renderer/questionnaire/classification"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer selecciona la presentación preferida. No crea una segunda copia de las preguntas: el contenido sigue siendo el cuestionario nativo.

Identificador técnico de la presentación

Normalmente Studio lo configura por ti. Sólo necesitas este identificador cuando seleccionas la presentación desde código, CLI o el visor.
