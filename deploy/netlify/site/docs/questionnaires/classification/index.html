Clasificar

Renderer 2D para preguntas classification: el alumno asigna cada objeto a una categoría usando el mismo estado native-questionnaire.

Qué ve el alumno

El alumno distribuye objetos entre categorías. Puede seleccionar una ficha y después una categoría, utilizar arrastre o elegir el destino mediante los controles disponibles.

Cuándo utilizar esta presentación

Úsalo para agrupar ejemplos por concepto, clasificar elementos por propiedades o practicar taxonomías con categorías claramente diferenciadas.

Renderizador

https://p2lrn.org/renderizador/questionnaire/classification

Versión instalada: 1.

profile

https://p2lrn.org/profile/native-questionnaire

Compatibilidad exacta

  • Requiere grading.mode=embedded-key.
  • Todas las preguntas deben ser de tipo classification.
  • Cada pregunta necesita al menos 2 objetos y al menos 2 categorías.
  • La solución debe tener una asignación por cada objeto; una conversión parcial se rechaza.

Modelo mínimo

JSON
{
  "id":"clasifica",
  "type":"classification",
  "prompt":"Clasifica los elementos",
  "points":4,
  "items":[{"id":"perro","text":"Perro"},{"id":"pino","text":"Pino"}],
  "categories":[{"id":"animal","text":"Animal"},{"id":"planta","text":"Planta"}],
  "solution":{"assignments":[
    {"item":"perro","category":"animal"},
    {"item":"pino","category":"planta"}
  ]}
}

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Clasificar" \
  --renderizador "https://p2lrn.org/renderizador/questionnaire/classification"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

Interacción y accesibilidad

Las fichas son botones y las categorías aceptan activación con Enter o Espacio además de clic y arrastre. La interacción táctil utiliza puntero y mantiene una alternativa no dependiente del gesto.

Finalización y puntuación

Cada asignación actualiza la clasificación de la pregunta. La actividad conserva el estado del cuestionario y puede reiniciarse para volver a realizar la clasificación.

Para integrar los resultados con una plataforma, consulta Eventos y Host Adapter.
