CUESTIONARIOS / PRESENTACIÓN

Rosco

Asigna una letra distinta a cada reto usando únicamente letras presentes en su propia respuesta.

Qué ve el alumno

El alumno recorre un conjunto de letras. Para cada letra lee una pista, escribe una respuesta o decide pasar temporalmente a otra.

Cuándo utilizar esta presentación

Úsalo para repasar vocabulario o conceptos mediante respuestas textuales cuando cada reto pueda asociarse de forma inequívoca a una letra disponible.

Renderizador

https://p2lrn.org/renderizador/questionnaire/rosco

Versión: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Requiere soluciones embebidas y exactamente un reto textual por pregunta.
  • Cada respuesta debe tener al menos 2 caracteres normalizados.
  • No puede haber más retos que letras disponibles en el alfabeto español usado por el runtime.
  • La asignación letra↔pregunta es 1:1; se prefiere una letra inicial cuando es posible.

Modelo mínimo

JSON / guía
// CASA, PERRO, MESA y LUNA pueden usar C, P, M y L.
// El runtime no inventa respuestas ni elimina preguntas.

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Rosco" \
  --renderizador "https://p2lrn.org/renderizador/questionnaire/rosco"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

La preferencia de renderizador no duplica el contenido: el fuente principal sigue siendo native-questionnaire.

Interacción y accesibilidad

Las letras son botones y la respuesta se introduce en un campo de texto. Enter ejecuta la comprobación y existe una acción Pasar para continuar sin bloquear la ronda.

Finalización y puntuación

Cada respuesta correcta actualiza la pregunta correspondiente. Al resolver el conjunto, el runtime finaliza la actividad y comunica la puntuación total.

Para integrar los resultados con una plataforma, consulta Eventos y Host Adapter.
