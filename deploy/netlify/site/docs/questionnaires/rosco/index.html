BUILD / QUESTIONNAIRE RENDERER

Rosco

Asigna una letra distinta a cada reto usando únicamente letras presentes en su propia respuesta.

Renderer

https://p2lrn.org/renderer/questionnaire/rosco

Versión instalada actualmente: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Requiere soluciones embebidas y exactamente un reto textual por pregunta.
  • Cada respuesta debe tener al menos 2 caracteres normalizados.
  • No puede haber más retos que letras disponibles en el alfabeto español usado por el runtime.
  • La asignación letra↔pregunta es 1:1; se prefiere una letra inicial cuando es posible.

Modelo mínimo

JSON / guía
// CASA, PERRO, MESA y LUNA pueden usar C, P, M y L.
// El runtime no inventa respuestas ni elimina preguntas.

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Rosco" \
  --renderer "https://p2lrn.org/renderer/questionnaire/rosco"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

La preferencia de renderer no duplica el contenido: el source of truth sigue siendo native-questionnaire.
