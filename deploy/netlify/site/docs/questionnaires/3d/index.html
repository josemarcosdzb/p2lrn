CUESTIONARIOS / PRESENTACIÓN

Juego 3D

Presentación 3D independiente del LMS para ordenar, relacionar y clasificar. El runtime actual usa Three.js y Rapier con una superficie HTML accesible.

Qué ve el alumno

El alumno interactúa con una escena 3D para ordenar, relacionar o clasificar elementos. La actividad mantiene la misma información del cuestionario y cambia únicamente su presentación.

Cuándo utilizar esta presentación

Úsalo cuando una de esas tres mecánicas se beneficia de una experiencia espacial y todo el contenido puede representarse sin perder información.

Renderizador

https://p2lrn.org/renderizador/questionnaire/3d-order-match

Versión: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Requiere grading.mode=embedded-key.
  • Sólo acepta ordering, matching y classification y exige que todas las preguntas sean representables.
  • Ordering necesita solución completa; matching relaciones válidas; classification asignación completa.
  • Los textos deben ser distinguibles. La física dispone de fallback sin física si Rapier no puede iniciarse.

Modelo mínimo

JSON / guía
// Ejemplo de actividad 3D con ordenar, relacionar y clasificar.

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Juego 3D" \
  --renderizador "https://p2lrn.org/renderizador/questionnaire/3d-order-match"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

La preferencia de renderizador no duplica el contenido: el fuente principal sigue siendo native-questionnaire.

Interacción y accesibilidad

La escena gráfica se acompaña de controles HTML accesibles. Ordenar y clasificar ofrecen selectores alternativos; relacionar conserva botones para elegir los elementos. La actividad puede seguir funcionando con una alternativa sin físicas si Rapier no está disponible.

Finalización y puntuación

Las acciones de la escena y de los controles accesibles actualizan el mismo estado del cuestionario. La finalización y puntuación se comunican mediante el contrato común.

Para integrar los resultados con una plataforma, consulta Eventos y Host Adapter.
