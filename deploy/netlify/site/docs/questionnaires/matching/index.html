Relacionar elementos de dos conjuntos

Úsalo para términos y definiciones, países y capitales, conceptos relacionados o cualquier ejercicio de correspondencia.

Escribe las dos partes de cada correspondencia

Relacionar sirve para unir dos conjuntos de información, como países y capitales. La actividad se prepara mediante filas de «Elemento» y «Pareja correcta».

Configuración del ejercicio

  1. Añade la actividadAbre tu curso y selecciona la unidad donde irá. En «Añadir contenido» elige «Juegos → Relacionar».
  2. Redacta la consignaEscribe qué debe relacionar el alumno: «Une cada país con su capital».
  3. Introduce las respuestasIntroduce las correspondencias España–Madrid, Francia–París e Italia–Roma. Usa «+ Añadir pareja» para ampliar el ejercicio.
  4. Ajusta la actividadRepasa las parejas por si alguna respuesta aparece duplicada o puede emparejarse con más de un elemento. Ajusta los puntos.
  5. Revisa el resultadoAbre Vista alumno, une ambos conjuntos y verifica que el resultado corresponda con las parejas guardadas.

Relacionar: parejas ya completadas

Cómo se responde: Selecciona un país y después su capital: España–Madrid, Francia–París, Portugal–Lisboa e Italia–Roma. La captura muestra los pares ya asociados por color, con resultado 4/4. No enseña el instante de seleccionar las respuestas.

Comprueba las correspondencias

Termina la actividad en Vista alumno y prueba el archivo exportado en el Visor.

Accesibilidad, puntuación y resultados

Interacción y accesibilidad

Los elementos son botones y la relación puede completarse mediante selección, sin depender exclusivamente del arrastre.

Finalización y puntuación

Cada relación resuelta actualiza el estado de la pregunta. Al completar todas las parejas, la actividad puede finalizar y reportar puntuación.

Para guardar el resultado en tu plataforma, consulta Eventos y Host Adapter.

Prueba del archivo exportado

Abre tu archivo .p2lrn en el Visor y termina el ejercicio. Comprueba instrucciones, corrección y resultado.

Requisitos del contenido

  • En Studio se crea como una pregunta de tipo Relacionar.
  • La actividad necesita soluciones embebidas y al menos tres parejas completas.
  • Las relaciones deben ser distinguibles: textos duplicados que vuelvan ambigua la correspondencia invalidan esta presentación.

Ejemplo de datos válido

Este ejemplo recoge los datos de la actividad para quienes trabajan con la CLI. En Studio puedes configurarla desde el editor visual.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Relacionar países y capitales",
  "language": "es",
  "grading": {
    "mode": "embedded-key"
  },
  "questions": [
    {
      "id": "q1",
      "type": "matching",
      "prompt": "Relaciona cada país con su capital",
      "points": 3,
      "left": [
        {
          "id": "l1",
          "text": "España"
        },
        {
          "id": "l2",
          "text": "Francia"
        },
        {
          "id": "l3",
          "text": "Italia"
        }
      ],
      "right": [
        {
          "id": "r1",
          "text": "Madrid"
        },
        {
          "id": "r2",
          "text": "París"
        },
        {
          "id": "r3",
          "text": "Roma"
        }
      ],
      "solution": {
        "pairs": [
          {
            "left": "l1",
            "right": "r1"
          },
          {
            "left": "l2",
            "right": "r2"
          },
          {
            "left": "l3",
            "right": "r3"
          }
        ]
      }
    }
  ]
}

Cómo leer el ejemplo

left y right definen las dos columnas. solution.pairs une los identificadores correctos.

Crear por CLI — alternativa avanzada

Utiliza este recorrido sólo si estás generando el curso por código. Requiere Toolkit instalado mediante NPM. El archivo quiz.json debe contener un cuestionario válido como el ejemplo anterior.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Relacionar" \
  --renderer "https://p2lrn.org/renderer/questionnaire/matching"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer selecciona la presentación preferida. No crea una segunda copia de las preguntas: el contenido sigue siendo el cuestionario nativo.

Identificador técnico de la presentación

Normalmente Studio lo configura por ti. Sólo necesitas este identificador cuando seleccionas la presentación desde código, CLI o el visor.
