CUESTIONARIOS / PRESENTACIÓN

Emparejar

Presenta las parejas derivadas del cuestionario en dos columnas que el alumno debe relacionar.

Qué ve el alumno

El alumno ve dos columnas. Selecciona un elemento de la izquierda y después el elemento correspondiente de la derecha hasta completar las relaciones.

Cuándo utilizar esta presentación

Úsalo para términos y definiciones, conceptos relacionados, traducciones o cualquier actividad basada en parejas que puedan distinguirse de forma inequívoca.

Renderizador

https://p2lrn.org/renderizador/questionnaire/matching

Versión: 1.

profile

https://p2lrn.org/profile/native-questionnaire

media type

application/vnd.p2lrn.questionnaire+json

Cuándo es compatible

  • Requiere grading.mode=embedded-key.
  • Se necesitan al menos 3 parejas completas.
  • No admite pistas o respuestas duplicadas que hagan imposible distinguir una relación.
  • Las respuestas se aplican al mismo estado native-questionnaire.

Modelo mínimo

JSON
// Puede derivarse de single-choice, multiple-choice,
// text, fill-blanks o matching cuando la solución es inequívoca.

Autoría

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Emparejar" \
  --renderizador "https://p2lrn.org/renderizador/questionnaire/matching"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderizador añade una preferencia de presentación; las preguntas siguen siendo native-questionnaire.

Ejecución y eventos

Las respuestas se mantienen en el mismo estado de questionnaire. Los renderizadores que finalizan la actividad reportan puntuación/finalización mediante el contrato común; consulta Eventos.

Interacción y accesibilidad

Las opciones de ambas columnas son botones. La relación se puede completar mediante clic o teclado; no es necesario arrastrar. Las conexiones visuales acompañan al estado, pero no son el único mecanismo de interacción.

Finalización y puntuación

Cada pareja correcta actualiza la respuesta de su pregunta. Cuando se resuelven todas las relaciones, la actividad finaliza y comunica la puntuación.

Para integrar los resultados con una plataforma, consulta Eventos y Host Adapter.
