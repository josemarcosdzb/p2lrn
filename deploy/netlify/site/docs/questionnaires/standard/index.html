Cuestionario estándar

Presenta el cuestionario como una evaluación convencional. El alumno responde con controles adaptados al tipo de pregunta: opciones, texto, ordenar, relacionar, clasificar o completar huecos.

PARA PROFESORES Y CREADORES

Crear cuestionario estándar en Studio

Crea la actividad con la interfaz y comprueba las soluciones. No necesitas escribir JSON ni ejecutar comandos.

Actividad de ejemplo. Combina una pregunta de opción única sobre el sistema solar con una pregunta de respuesta breve. Define qué respuestas se aceptan y cuándo se muestra la corrección.

Qué comprobar. Prueba la vista alumno y confirma que las opciones, instrucciones y envío de la actividad sean claros.

  1. Abre tu curso.Entra en Studio y selecciona la unidad o lección donde vas a crear la actividad.
  2. Añade la actividad.En Añadir contenido, abre Evaluación y elige Cuestionario.
  3. Prepara el contenido.Escribe las preguntas, elige el tipo de respuesta y prepara las opciones.
  4. Define la solución.Define las respuestas válidas, el criterio de corrección y la puntuación.
  5. Comprueba la Vista alumno.Reproduce la actividad antes de descargar o guardar el curso.
  6. Guarda y vuelve a abrir.Descarga el curso .p2lrn y comprueba el archivo en el Visor.

Comprobar antes de compartir

Termina la actividad en Vista alumno y prueba el archivo exportado en el Visor.

Accesibilidad, puntuación y resultados

Interacción y accesibilidad

Los controles son formularios HTML y mantienen etiquetas asociadas. No depende de arrastre ni de una escena gráfica.

Finalización y puntuación

Al enviar la evaluación, el cuestionario actualiza su estado y comunica puntuación y finalización cuando la corrección está disponible.

Para guardar el resultado en tu plataforma, consulta Eventos y Host Adapter.

Prueba del archivo exportado

Abre tu archivo .p2lrn en el Visor y termina el ejercicio. Comprueba instrucciones, corrección y resultado.

Ejemplo práctico: crear un cuestionario interactivo online

Para evaluar una unidad de seguridad digital, prepara tres preguntas sobre contraseñas, enlaces sospechosos y protección de cuentas. Añádelas a una única actividad Cuestionario desde Studio, en lugar de crear tres actividades independientes.

  1. Configura las preguntas.Elige los tipos compatibles y comprueba las opciones y soluciones. Mantén separadas las instrucciones de cada pregunta.
  2. Revisa el recorrido del alumno.Activa, si procede, una pregunta cada vez. Comprueba que Anterior y Siguiente permiten llegar a todas las preguntas antes de entregar el conjunto.
  3. Controla cuándo se corrige.No muestres respuestas correctas mientras el alumno todavía está respondiendo, salvo que el docente lo haya configurado expresamente. Comprueba el resultado global al finalizar.
  4. Exporta y prueba.Descarga el archivo .p2lrn y comprueba tu propio curso en el visor para verificar el comportamiento en móvil y escritorio.

La puntuación de Player no se convierte automáticamente en nota oficial del LMS. Si necesitas matriculación y calificaciones, conecta identidad y persistencia mediante un Host Adapter autorizado.

Para desarrolladores: JSON, CLI e integración

Solo necesitas estos datos si vas a generar paquetes mediante código o integrar la actividad en otra plataforma.

Abrir ejemplos JSON y comandos técnicos

Requisitos del contenido

  • Admite los tipos de pregunta del cuestionario nativo.
  • Puede utilizar corrección con solución embebida o corrección gestionada por la plataforma.
  • La presentación puede mostrar una pregunta cada vez o todas a la vez.

Ejemplo de datos válido

Este ejemplo recoge los datos de la actividad para quienes trabajan con la CLI. En Studio puedes configurarla desde el editor visual.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Comprobación rápida",
  "language": "es",
  "grading": {
    "mode": "embedded-key"
  },
  "presentation": {
    "questionMode": "one-at-a-time",
    "shuffleQuestions": false,
    "showFeedback": "after-submit"
  },
  "questions": [
    {
      "id": "q1",
      "type": "single-choice",
      "prompt": "Capital de Portugal",
      "points": 1,
      "choices": [
        {
          "id": "a",
          "text": "Lisboa"
        },
        {
          "id": "b",
          "text": "Madrid"
        }
      ],
      "solution": {
        "choiceIds": [
          "a"
        ]
      }
    }
  ]
}

Cómo leer el ejemplo

El ejemplo contiene una pregunta de elección única. choices define las opciones y solution.choiceIds identifica la respuesta correcta.

Crear por CLI — alternativa avanzada

Utiliza este recorrido sólo si estás generando el curso por código. Requiere Toolkit instalado mediante NPM. El archivo quiz.json debe contener un cuestionario válido como el ejemplo anterior.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Cuestionario estándar" \
  --renderer "https://p2lrn.org/renderer/questionnaire/standard"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer selecciona la presentación preferida. No crea una segunda copia de las preguntas: el contenido sigue siendo el cuestionario nativo.

Identificador técnico de la presentación

Normalmente Studio lo configura por ti. Sólo necesitas este identificador cuando seleccionas la presentación desde código, CLI o el visor.
