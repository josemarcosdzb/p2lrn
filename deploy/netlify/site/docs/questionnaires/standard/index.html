CUESTIONARIOS / PRESENTACIÓN

Cuestionario estándar

Presenta el cuestionario como una evaluación convencional. El alumno responde con controles adaptados al tipo de pregunta: opciones, texto, ordenar, relacionar, clasificar o completar huecos.

1. Qué hace y qué ve el alumno

Presenta el cuestionario como una evaluación convencional. El alumno responde con controles adaptados al tipo de pregunta: opciones, texto, ordenar, relacionar, clasificar o completar huecos.

Úsalo cuando quieres mezclar tipos de pregunta o cuando la evaluación directa es más importante que una mecánica de juego.

2. Crear en Studio

Éste es el recorrido normal si estás creando el curso visualmente. No necesitas escribir JSON ni ejecutar comandos.

  1. Abre Studio.Usa el editor alojado o el Studio que hayas integrado en tu proyecto.
  2. Añade la actividad.En Añadir contenido, abre Evaluación y elige Cuestionario.
  3. Edita visualmente.Cambia enunciados, respuestas y opciones con los controles del editor. El JSON queda como vista avanzada, no como requisito de uso.
  4. Comprueba la Vista alumno.Reproduce la actividad antes de descargar o guardar el curso.

3. Requisitos del contenido

  • Admite los tipos de pregunta del cuestionario nativo.
  • Puede utilizar corrección con solución embebida o corrección gestionada por la plataforma.
  • La presentación puede mostrar una pregunta cada vez o todas a la vez.

4. Ejemplo de datos válido

Este bloque muestra un cuestionario completo y válido para esta presentación. Sirve para entender el formato o para el recorrido por CLI; si utilizas Studio, el editor genera esta estructura por ti.

quiz.json
{
  "schema": "https://p2lrn.org/schema/native-questionnaire/0.4.0",
  "version": "0.4.0",
  "title": "Comprobación rápida",
  "language": "es",
  "grading": {
    "mode": "embedded-key"
  },
  "presentation": {
    "questionMode": "one-at-a-time",
    "shuffleQuestions": false,
    "showFeedback": "after-submit"
  },
  "questions": [
    {
      "id": "q1",
      "type": "single-choice",
      "prompt": "Capital de Portugal",
      "points": 1,
      "choices": [
        {
          "id": "a",
          "text": "Lisboa"
        },
        {
          "id": "b",
          "text": "Madrid"
        }
      ],
      "solution": {
        "choiceIds": [
          "a"
        ]
      }
    }
  ]
}

5. Cómo leer el ejemplo

El ejemplo contiene una pregunta de elección única. choices define las opciones y solution.choiceIds identifica la respuesta correcta.

6. Crear por CLI — alternativa avanzada

Utiliza este recorrido sólo si estás generando el curso por código. Requiere Toolkit instalado mediante NPM. El archivo quiz.json debe contener un cuestionario válido como el ejemplo anterior.

Terminal
p2lrn-create add-questionnaire ./workspace ./quiz.json \
  --key quiz \
  --title "Cuestionario estándar" \
  --renderer "https://p2lrn.org/renderer/questionnaire/standard"

p2lrn-create build ./workspace ./course.p2lrn --strict-profiles

--renderer selecciona la presentación preferida. No crea una segunda copia de las preguntas: el contenido sigue siendo el cuestionario nativo.

7. Identificador técnico de la presentación

Normalmente Studio lo configura por ti. Sólo necesitas este identificador cuando seleccionas la presentación desde código, CLI o el visor.

Identificador técnico

https://p2lrn.org/renderer/questionnaire/standard

Perfil

https://p2lrn.org/profile/native-questionnaire

Tipo de contenido

application/vnd.p2lrn.questionnaire+json

8. Interacción y accesibilidad

Los controles son formularios HTML y mantienen etiquetas asociadas. No depende de arrastre ni de una escena gráfica.

9. Finalización y puntuación

Al enviar la evaluación, el cuestionario actualiza su estado y comunica puntuación y finalización cuando la corrección está disponible.

Para guardar el resultado en tu plataforma, consulta Eventos y Host Adapter.
