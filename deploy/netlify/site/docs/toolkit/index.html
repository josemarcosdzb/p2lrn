BUILD / TOOLKIT

Toolkit

API Node/TypeScript y CLI para validar, inspeccionar, abrir, leer documentos, editar, convertir y reconstruir paquetes P2LRN.

Instalación

$npm install @p2lrn/toolkit @p2lrn/player

Flujo completo de autoría

TypeScript
import {P2LRNAuthoringWorkspace} from '@p2lrn/toolkit/authoring';

const workspace = P2LRNAuthoringWorkspace.open(
  'course.p2lrn',
  './workspace'
);

const document = await workspace.reader('./material/tema-1.docx');

console.log(document.metadata);
console.log(document.blocks);
console.log(document.tables);

workspace.setCourseMetadata({
  title: 'Curso actualizado',
  incrementRevision: true,
});

workspace.addUnit({
  key: 'unidad-1',
  title: 'Unidad 1',
});

workspace.build('course-updated.p2lrn', {
  strictProfiles: true,
});

workspace.reader(path)

Lee un documento utilizando el Reader documental ya existente. No crea un segundo lector y no modifica el proyecto. Las rutas relativas se resuelven desde la raíz del workspace; las absolutas se aceptan directamente.

DOCX / PPTX

Extracción estructurada desde XML interno.

PDF

Texto embebido mediante pdfjs-dist opcional.

ODT / EPUB

Extracción estructurada del contenedor.

TXT / Markdown / HTML / RTF / TEX / XML / YAML

Lectura estructurada ligera.

Importante

reader() analiza y devuelve metadata, blocks, tables y warnings. No altera silenciosamente el curso.

Crear o abrir

P2LRNAuthoringWorkspace.create(root, options)

Crea un proyecto nuevo.

P2LRNAuthoringWorkspace.open(packagePath, root)

Abre un paquete como workspace editable.

P2LRNAuthoringWorkspace.load(root)

Carga un workspace ya existente.

Edición tipada

La API incluye métodos como setCourseMetadata, setEntityText, setChildren, setProgression, addUnit, addFile, addUrl, addWebContent, addQuestionnaire, addComponent y addComposite.

Validar e inspeccionar

Terminal
p2lrn-validate course.p2lrn
p2lrn-inspect course.p2lrn
p2lrn-reader course.p2lrn

Conversión y empaquetado avanzado

El Toolkit también incluye conversión, repack, multipart, delta y trust. La explicación de cómo crear un curso está en Crear paquetes; la división de contenidos pesados se documenta sólo en Multipart / paquetes grandes para evitar duplicar la misma explicación aquí.
