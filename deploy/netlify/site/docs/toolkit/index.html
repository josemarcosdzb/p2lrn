TOOLKIT

Toolkit

Herramientas Node/TypeScript para leer, validar, crear, convertir, migrar y reconstruir paquetes P2LRN.

Instalación

$npm install @p2lrn/toolkit @p2lrn/player

Autoría

La frontera pública para editores y Studio es @p2lrn/toolkit/authoring. La intención es que las aplicaciones trabajen contra operaciones tipadas y no contra módulos internos de Creator.

JavaScript
import {P2LRNAuthoringWorkspace} from '@p2lrn/toolkit/authoring';

const workspace = P2LRNAuthoringWorkspace.open('course.p2lrn', './workspace');
workspace.setCourseMetadata({ title: 'Curso actualizado', incrementRevision: true });
workspace.addUnit({ key: 'unidad-1', title: 'Unidad 1' });
workspace.build('course-updated.p2lrn', { strictProfiles: true });

Reader documental

El Reader documental ligero está incluido en el Toolkit. Lee DOCX, PPTX, ODT, EPUB y texto estructurado. PDF queda limitado a texto embebido mediante pdfjs-dist opcional.

Límite deliberado

No incorpora OCR, Docling, Docker, LibreOffice, Pandoc ni dependencias de una plataforma LMS concreta.
