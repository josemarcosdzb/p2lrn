P2LRN para desarrolladores e integradores

Esta sección reúne las instrucciones para incorporar P2LRN a una aplicación o plataforma educativa. Incluye ejemplos de código, instalación, autenticación y pruebas. Si tu objetivo es redactar un curso, utiliza la guía de Studio para profesores.

Empezar una integración

Elige una guía según lo que vas a conectar. Cada recorrido contiene los pasos y los requisitos técnicos correspondientes; las instrucciones de creación de cursos están en la sección para profesores.

01 · EMPEZAR

Integrar Player en una página HTML

Un archivo de ejemplo, el cargador CDN y una comprobación desde un servidor local. Para integrar P2LRN en una web, no para redactar un curso.

02 · INSTALAR

Elegir CDN o NPM

CDN para páginas que cargan el componente directamente; NPM para aplicaciones que gestionan dependencias y versiones.

03 · CONECTAR

Identidad, estado y permisos

Vincula Player con la sesión de tu plataforma, el guardado de progreso y el acceso autorizado a recursos y resultados.

Qué debes comprobar antes de ponerlo en producción

  1. Que el mismo paquete se abre en Player y que las actividades se completan en un navegador real.
  2. Que el Host autoriza por usuario, centro y curso; no confíes en identificadores que lleguen del navegador.
  3. Que los resultados del alumno no se confunden con calificaciones oficiales hasta recibir confirmación del LMS.
  4. Que las versiones CDN/NPM utilizadas coinciden con las realmente publicadas y probadas.
