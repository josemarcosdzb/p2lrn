Instalación

Incorpora P2LRN al proyecto con el método que corresponda a tu aplicación. La documentación presenta primero CDN y después NPM; Studio alojado sigue disponible sin instalación local.

CDN

Carga Player o Studio directamente desde los archivos web publicados. Es la continuación del recorrido Empezar fácil y no requiere añadir paquetes al proyecto.

Continuar con CDNStudio mediante CDN

NPM

Utiliza los paquetes publicados cuando tu proyecto gestiona dependencias y versiones mediante NPM. Player, Studio, Toolkit y Analytics se instalan según la función que necesites; @p2lrn/h5p-libraries añade el catálogo reutilizable de librerías H5P cuando el contenido no las incorpora por sí mismo.

Continuar con NPMStudio con NPM

Studio alojado

Si sólo quieres crear o editar un curso desde el editor web, abre P2LRN Studio. No necesitas preparar una instalación local para ese uso.

Qué componente necesitas

Player

Para reproducir paquetes .p2lrn en el navegador. Disponible mediante CDN o NPM.

Studio

Para integrar el editor visual dentro de una aplicación. Utiliza Player para la vista alumno.

Toolkit

Para autoría, Host de referencia, validación, Reader y procesamiento por código. Se instala mediante NPM.

Analytics

Panel embebible para alumnos, cursos, progreso, actividad, intentos y notas del Host. Disponible mediante CDN o NPM.

H5P Libraries

@p2lrn/h5p-libraries es opcional: proporciona librerías H5P compartidas cuando el paquete H5P no las transporta.
