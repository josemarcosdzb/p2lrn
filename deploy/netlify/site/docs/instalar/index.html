EMPEZAR / INSTALACIÓN

Instalar P2LRN

Antes de crear contenido dentro de un proyecto o reproducir un curso en una aplicación, prepara el entorno. Aquí eliges una sola ruta de instalación; después continúas con creación o reproducción.

1. Decide dónde vas a utilizar P2LRN

EDITOR ALOJADO

Usar Studio directamente

Si sólo quieres crear un curso desde el editor web, no tienes que instalar nada. Abre Studio y empieza a trabajar.

PROYECTO CON DEPENDENCIAS

Instalar con NPM

Para aplicaciones que gestionan Player, Studio o Toolkit como dependencias del proyecto.

HTML / NAVEGADOR

Cargar mediante CDN

Para páginas que cargan Player o Studio desde los archivos web publicados, sin añadirlos como dependencias.

2. NPM y CDN son alternativas

No instales NPM y después añadas también el cargador CDN para el mismo componente. Elige una de las dos formas de carga y mantén ese recorrido.

Resultado de esta fase.

Player, Studio o Toolkit disponibles en tu entorno y listos para utilizarse. Todavía no necesitas crear ningún curso para comprobar la instalación.

3. Qué preparar según lo que vas a hacer

Crear cursos visualmente dentro de tu aplicación

Studio y Player. Sigue Studio con NPM o Studio mediante CDN.

Reproducir cursos

Player. Después continúa con Player.

Crear o procesar cursos por código

Toolkit mediante NPM. Después continúa con Toolkit.

Crear desde el Studio alojado

No requiere instalación local. Continúa con la guía de Studio.

4. Después de instalar

Una vez preparado el entorno, continúa con el mapa de componentes y después con la guía de creación o reproducción que corresponda.
