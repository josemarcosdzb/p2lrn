Studio con NPM

Esta guía cubre únicamente la integración de Studio como dependencia de un proyecto. Incluye la parte del navegador y, cuando la necesites, los servicios de servidor para guardar e importar.

1. Instalar las dependencias

Terminal
npm install @p2lrn/studio@0.5.0-alpha.10 @p2lrn/player@0.5.0-alpha.10

Las versiones de Studio y Player deben estar alineadas.

2. Registrar Studio en la aplicación

JavaScript / TypeScript
import '@p2lrn/studio';
HTML mínimo
<p2lrn-studio></p2lrn-studio>

Con este montaje mínimo puedes crear un curso, abrir un archivo o una URL, editar, previsualizar y descargar un nuevo .p2lrn.

3. Abrir un curso inicial

HTML
<p2lrn-studio src="/courses/curso.p2lrn"></p2lrn-studio>

El atributo src es opcional. Si no lo defines, el usuario puede crear un curso nuevo desde la interfaz.

4. Habilitar guardado e importación

HTML
<p2lrn-studio
  src="/courses/curso.p2lrn"
  save-endpoint="/api/p2lrn/studio/save"
  reader-endpoint="/api/p2lrn/studio/read"
  import-endpoint="/api/p2lrn/studio/import"
  course-path="course">
</p2lrn-studio>
save-endpoint

Recibe el paquete exportado cuando el usuario guarda en servidor.

reader-endpoint

Procesa documentos que se importan mediante Reader.

import-endpoint

Procesa paquetes educativos externos que deben convertirse a P2LRN.

course-path

Identifica la ruta lógica de guardado. El valor por defecto es course.

5. Generar la integración de servidor

El comando setup detecta la tecnología del proyecto cuando puede hacerlo automáticamente.

Detección automática
npx p2lrn-studio setup
Ejemplo con Next.js
npx p2lrn-studio setup next --course-path data/courses
Rutas generadas.

La plantilla de Next.js crea guardado, Reader e importación externa. Las demás plantillas disponibles crean la ruta de guardado; Reader e importación pueden añadirse con servicios equivalentes cuando la aplicación los necesite.

6. Tecnologías reconocidas por setup

El comando admite detección o selección explícita para Next.js, Express, Nest, Fastify, Hono, SvelteKit, Nuxt, Astro, Remix, React Router, PHP, Laravel, Symfony, Django, FastAPI, Flask, Rails, ASP.NET, Spring, Go, Rust y una integración genérica.

7. Funciones auxiliares del servidor

JavaScript / TypeScript
import {
  handleP2LRNStudioSave,
  handleP2LRNStudioReader,
  handleP2LRNStudioExternalImport,
} from '@p2lrn/studio/server';

Protege estas rutas con la autenticación y autorización de tu aplicación. El navegador no debe poder decidir libremente rutas de escritura del servidor.

8. API del componente

createCourse(options)

Crea un curso nuevo.

openFile(file)

Abre un archivo local.

openUrl(url)

Abre un paquete mediante URL.

setMode('edit' | 'preview')

Cambia entre edición y vista previa.

addUnit(), addLesson(), addContent()

Añaden estructura y contenido.

download()

Genera y descarga el paquete.

saveCourse()

Genera el paquete y lo envía al servicio de guardado.

9. Eventos

p2lrn-studio-create

Se ha creado un curso.

p2lrn-studio-open

Se ha abierto un paquete.

p2lrn-studio-download

Se ha descargado un paquete.

p2lrn-studio-save

Ha finalizado un guardado en servidor.
