INSTALL / NPM

P2LRN por NPM

Usa esta ruta cuando tu aplicación gestiona dependencias con NPM. Player, Studio y Toolkit son paquetes distintos: instala únicamente los que necesites.

1. Qué paquete corresponde a cada función

@p2lrn/player

Reproduce paquetes .p2lrn en el navegador.

@p2lrn/studio

Integra el editor visual <p2lrn-studio>. Declara @p2lrn/player como peer dependency y lo usa para abrir y previsualizar paquetes.

@p2lrn/toolkit

Autoría y procesamiento en Node/TypeScript: crear, validar, Reader, conversiones y multipart.

2. Player por NPM

Terminal
npm install @p2lrn/player@0.5.0-alpha.10
JavaScript / TypeScript
import '@p2lrn/player';
HTML
<p2lrn-player src="/courses/course.p2lrn"></p2lrn-player>
No añadas además el loader CDN del Player.

En esta ruta el Web Component queda registrado por el import del paquete NPM.

3. Studio visual por NPM

Para incrustar Studio en tu aplicación instala Studio y Player juntos:

Terminal
npm install @p2lrn/studio@0.5.0-alpha.10 @p2lrn/player@0.5.0-alpha.10
JavaScript / TypeScript
import '@p2lrn/studio';
HTML mínimo
<p2lrn-studio></p2lrn-studio>

Sin endpoints de servidor, Studio puede crear cursos, abrir archivos o URLs, editar, previsualizar y descargar un .p2lrn. El guardado en Host permanece oculto mientras no exista save-endpoint.

4. Studio con guardado, Reader e importación externa

HTML
<p2lrn-studio
  src="/course/curso.p2lrn"
  save-endpoint="/api/p2lrn/studio/save"
  reader-endpoint="/api/p2lrn/studio/read"
  import-endpoint="/api/p2lrn/studio/import"
  course-path="course">
</p2lrn-studio>
save-endpoint

POST del paquete exportado. Sólo es necesario para guardar en servidor.

reader-endpoint

POST de documentos. Sólo es necesario al importar documentos con Reader.

import-endpoint

POST de paquetes educativos externos para convertirlos a P2LRN.

course-path

Ruta lógica de guardado; por defecto course. El helper ignora la ruta enviada por el navegador salvo que actives allowClientPath:true.

src

Paquete inicial opcional. Si lo omites puedes crear un curso nuevo.

5. Configurar backend con el CLI

Detección automática
npx p2lrn-studio setup
Next.js y ruta de cursos
npx p2lrn-studio setup next --course-path data/courses
Estado real del generador.

Actualmente el target next genera save + Reader + import. Los demás targets soportados generan la integración de save; Reader e importación externa requieren endpoints equivalentes del Host si se necesitan.

6. Helpers de servidor disponibles

Servidor JavaScript / Web Request
import {
  handleP2LRNStudioSave,
  handleP2LRNStudioReader,
  handleP2LRNStudioExternalImport,
} from '@p2lrn/studio/server';

Autenticación y autorización pertenecen a tu aplicación. No expongas estas rutas de escritura o importación como endpoints anónimos.

7. Toolkit por NPM

El Toolkit no es necesario para reproducir un curso ya creado. Instálalo para autoría o procesamiento por código.

Terminal
npm install @p2lrn/toolkit@0.5.0-alpha.10

Continúa en Crear paquetes o Toolkit.

8. Si no quieres NPM en el navegador

Usa CDN. Player y Studio tienen loaders publicados. El backend sigue siendo responsabilidad del Host y no depende del canal usado en el navegador.
