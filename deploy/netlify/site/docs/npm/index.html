INSTALACIÓN / NPM

Instalación con NPM

Usa esta guía cuando P2LRN forma parte de un proyecto que gestiona sus dependencias con NPM. Cada paquete tiene una función distinta y puedes instalar sólo los que necesites.

1. Paquetes disponibles

@p2lrn/player

Reproduce cursos .p2lrn en el navegador.

@p2lrn/studio

Integra el editor visual dentro de tu aplicación. Usa @p2lrn/player para la vista previa.

@p2lrn/toolkit

Ofrece autoría, lectura, validación y herramientas de procesamiento en Node.js y TypeScript.

2. Instalar el Player

Instala el paquete y después impórtalo una vez desde el código de tu aplicación.

Terminal
npm install @p2lrn/player@0.5.0-alpha.11
JavaScript / TypeScript
import '@p2lrn/player';
HTML
<p2lrn-player src="/courses/course.p2lrn"></p2lrn-player>

Después del import, el elemento <p2lrn-player> queda disponible en la página.

3. Instalar Studio

Studio utiliza Player como dependencia del entorno de navegador, por lo que ambos deben estar disponibles en la misma aplicación.

Terminal
npm install @p2lrn/studio@0.5.0-alpha.11 @p2lrn/player@0.5.0-alpha.11
JavaScript / TypeScript
import '@p2lrn/studio';
Guía completa de Studio con NPM

4. Instalar el Toolkit

Instala Toolkit cuando necesites crear o procesar paquetes desde Node.js o TypeScript.

Terminal
npm install @p2lrn/toolkit@0.5.0-alpha.11

Toolkit requiere Node.js 22 o posterior. Player y Studio declaran Node.js 18 o posterior para sus herramientas de paquete.

5. Comprobar que la integración está lista

Después de instalar e importar un componente, abre la página donde lo has montado y verifica dos cosas: que el elemento se registra sin errores de JavaScript y que puede acceder al archivo .p2lrn indicado en src. Si el paquete está en otro origen, el servidor que lo aloja debe permitir su lectura desde el navegador.

6. Elegir qué instalar

Sólo reproducir

Instala @p2lrn/player.

Editar visualmente dentro de tu aplicación

Instala @p2lrn/studio y @p2lrn/player.

Crear o procesar cursos en servidor

Instala @p2lrn/toolkit.

7. Siguiente paso

Si sólo necesitas reproducir, continúa con Player. Si vas a integrar el editor, sigue la guía de Studio con NPM. Para autoría por código, continúa con Toolkit.
