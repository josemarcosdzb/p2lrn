INSTALL / NPM

Usar P2LRN por NPM

Esta ruta es para proyectos JavaScript/TypeScript que gestionan dependencias con NPM y un bundler o framework. No carga el Player desde CDN.

1. Instala sólo lo que necesitas

@p2lrn/player

Reproducir paquetes .p2lrn dentro de tu aplicación.

@p2lrn/toolkit

Crear, validar, leer, convertir o empaquetar cursos desde Node/TypeScript. Requiere Node.js 22 o superior.

@p2lrn/studio

Integrar el editor visual dentro de tu propia aplicación. Usa @p2lrn/player como peer dependency.

2. Player por NPM

Terminal
npm install @p2lrn/player@0.5.0-alpha.10
JavaScript / TypeScript
import '@p2lrn/player';

const player = document.querySelector('p2lrn-player');
player.addEventListener('p2lrn:ready', (event) => {
  console.log('READY', event.detail);
});
HTML de tu aplicación
<p2lrn-player src="/courses/course.p2lrn"></p2lrn-player>
En esta ruta no añadas el script del CDN.

El registro del Web Component llega desde import '@p2lrn/player'.

3. Autoría por código: Toolkit

El Toolkit es opcional. No necesitas instalarlo para reproducir un paquete ya creado.

Terminal
npm install @p2lrn/toolkit@0.5.0-alpha.10
TypeScript
import {P2LRNAuthoringWorkspace} from '@p2lrn/toolkit/authoring';

const workspace = P2LRNAuthoringWorkspace.create('./workspace', {
  title: 'Mi curso',
  language: 'es',
});

Continúa en Crear paquetes con Toolkit / CLI.

4. Integrar Studio visual por NPM

Si quieres que el editor visual forme parte de tu propia aplicación, instala Studio y Player juntos. Esto es distinto de abrir el Studio público.

Terminal
npm install @p2lrn/studio@0.5.0-alpha.10 @p2lrn/player@0.5.0-alpha.10
npx p2lrn-studio setup

Para aprender a usar el editor como autor, consulta Studio visual.

5. Cuándo usar esta ruta

  • Tu aplicación ya usa NPM, Vite, Next.js, React, Vue, Svelte u otro sistema de módulos.
  • Quieres fijar la versión de P2LRN en package.json.
  • Quieres importar el Player, Toolkit o Studio como dependencias del proyecto.

Si sólo quieres añadir el Player a una página HTML sin dependencias, usa la ruta CDN.
