NPM / ANALYTICS

Analytics con NPM

Lee directamente archivos .p2lrn-result sin base de datos ni API obligatoria. Genera los resultados con Player y relaciónalos con una cuenta autenticada o un código individual del profesor.

1. Instalar los paquetes NPM

Instala Player y Analytics con versiones compatibles. Ambos utilizan el mismo contrato de resultados .p2lrn-result.

Terminal
npm install @p2lrn/player@0.5.0-alpha.12 @p2lrn/analytics@0.5.0-alpha.12

2. Leer resultados mediante src

El atributo src de Analytics apunta directamente a un archivo .p2lrn-result, no al paquete del curso. Analytics verifica el SHA-256 y obtiene las métricas automáticamente, sin conversores propios ni servidor.

JavaScript / TypeScript
import '@p2lrn/analytics';
// HTML: <p2lrn-analytics id="panel.analytics"></p2lrn-analytics>
const panel = document.getElementById('panel.analytics');
panel.src = '/resultados/ana.p2lrn-result';

3. Leer varios alumnos sin base de datos

Guarda los archivos en una carpeta estática protegida y crea un pequeño índice JSON. El navegador puede leer la lista de archivos, pero no descubrir por sí solo todos los ficheros de una carpeta remota. También puedes importar varios archivos locales desde Analytics.

index.p2lrn-results.json
{
  "schema": "https://p2lrn.org/schema/analytics-results-index/1",
  "results": ["ana.p2lrn-result", "luis.p2lrn-result"]
}
JavaScript / TypeScript
import '@p2lrn/analytics';
import {loadAnalyticsResultSource} from '@p2lrn/analytics/results';
// Reads a SHA-256-verified result or index, without manual conversion.
const dataset = await loadAnalyticsResultSource('/resultados/index.p2lrn-results.json');
document.getElementById('panel.analytics').data = dataset;

Privacidad: permite acceder a esos archivos únicamente a usuarios autorizados. No publiques resultados identificables en un alojamiento estático abierto.

4. Generar el resultado con código individual

Sin cuentas, asigna un código distinto a cada alumno, preferiblemente vinculado a tu centro. Configura la captura antes de las actividades y, al terminar, llama a download desde una acción del usuario para guardar el archivo.

JavaScript / TypeScript
import {mountP2LRN} from '@p2lrn/player';
const player = await mountP2LRN('#player', {
  src: '/cursos/curso.p2lrn',
  resultIdentity: {
    mode: 'code',
    issuer: 'centro-educativo',
    code: codigoIndividualAsignado,
    label: nombreAlumno
  }
});
document.getElementById('download-result').addEventListener('click', () =>
  player.resultRecorder.download('alumno.p2lrn-result')
);

El código permite agrupar intentos, pero no demuestra quién los realizó. Descargar el archivo no significa que llegue automáticamente al profesor.

5. Generar el resultado con una plataforma autenticada

Si el LMS o la web ya autenticó al alumno, proporciona el emisor y su identificador verificado desde la sesión de confianza. No los obtengas de un campo modificable por el usuario.

JavaScript / TypeScript
const player = await mountP2LRN('#player', {
  src: '/cursos/curso.p2lrn',
  resultIdentity: {
    mode: 'platform',
    issuer: sesionAutenticada.issuer,
    subjectId: sesionAutenticada.userId,
    label: sesionAutenticada.nombre
  }
});

El hash SHA-256 protege la integridad, no demuestra la identidad. Las notas oficiales requieren validación por una plataforma autorizada.

6. Integración avanzada (opcional)

Si una institución ya dispone de un origen JSON de métricas autenticado, src puede seguir apuntando a ese documento autorizado, o puede utilizar panel.data/panel.dataSource. Es una integración avanzada opcional, no un requisito para los archivos de resultados.
