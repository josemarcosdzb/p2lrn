1. Qué hay dentro de un .p2lrn

El paquete final contiene el manifiesto, el grafo del curso y los recursos necesarios. El workspace de autoría es otra cosa: conserva p2lrn.project.json y los archivos fuente que necesitas para volver a editar y reconstruir.

course.p2lrn
course.p2lrn
├─ META-INF/manifest.json   # identidad, perfiles, inventario e integridad
├─ content/graph.json       # curso, unidades, actividades y relaciones
├─ assets/...               # recursos embebidos
├─ packages/...             # subpaquetes preservados, cuando existen
└─ multipart/...            # descriptor sólo si hay payloads divididos

2. Crear el workspace

TypeScript
import {P2LRNAuthoringWorkspace} from '@p2lrn/toolkit/authoring';

const workspace = P2LRNAuthoringWorkspace.create('./workspace', {
  title: 'Curso de seguridad básica',
  language: 'es',
  description: 'Curso P2LRN creado desde cero.',
});

3. Añadir estructura y recursos

addFile() crea el recurso y su actividad asociada. El resultado devuelve las claves reales para que puedas usarlas después en progresión u otras reglas.

TypeScript
workspace.addUnit({
  key: 'unidad-1',
  title: 'Unidad 1 · Fundamentos',
});

const intro = workspace.addFile({
  source: './material/intro.html',
  key: 'intro',
  title: 'Introducción',
  parent: 'unidad-1',
  mediaType: 'text/html',
});

const practica = workspace.addFile({
  source: './material/practica.html',
  key: 'practica',
  title: 'Práctica',
  parent: 'unidad-1',
  mediaType: 'text/html',
});

workspace.setProgression(intro.activityKey, {
  required: true,
  gateFollowing: true,
  completionRequirement: 'viewed',
});

workspace.setProgression(practica.activityKey, {
  required: true,
  completionRequirement: 'completed',
});

4. Leer un documento sin modificar todavía el curso

workspace.reader() utiliza el Reader documental del Toolkit. Devuelve la estructura extraída y deja que tu aplicación decida qué parte se convierte en contenido del curso.

TypeScript
const document = await workspace.reader('./material/tema-1.docx');

console.log(document.metadata);
console.log(document.blocks);
console.log(document.tables);
console.log(document.warnings);

5. Construir y validar

TypeScript + CLI
workspace.build('./curso.p2lrn', {
  strictProfiles: true,
});

# después del build
p2lrn-validate curso.p2lrn
p2lrn-inspect curso.p2lrn
p2lrn-reader curso.p2lrn

6. ¿El curso pesa demasiado?

No metas un vídeo de varios cientos de MB o GB dentro de un único ZIP si tu almacenamiento, despliegue o CDN no lo necesita. P2LRN dispone de transporte multipart para separar el payload grande manteniendo el paquete exterior y su integridad.
