AUTORÍA / PAQUETES

Crear un paquete: editor visual o código

P2LRN admite dos rutas de autoría. Studio permite crear el curso visualmente. Toolkit / CLI permite construirlo por código y automatizar procesos. Ambas terminan en un paquete .p2lrn.

1. Elige la forma de crear

EDITOR VISUAL

Studio

Crear curso, unidades, lecciones, archivos, documentos, cuestionarios y juegos desde una interfaz gráfica.

 AUTOMATIZACIÓN

Toolkit / CLI

Crear workspaces y paquetes desde TypeScript o comandos reproducibles.

2. Crear con Studio visual

  1. Abre Studio.Entra en /studio/ y pulsa Crear curso, o abre un archivo/URL existente.
  2. Organiza el curso.Usa + Nueva unidad, + Nueva lección y Añadir contenido.
  3. Añade actividades.Lecciones, multimedia, URL, Reader/documento, paquetes educativos, cuestionarios, juegos y bloques avanzados.
  4. Edita visualmente.Selecciona el contenido en el lienzo y utiliza la barra de formato.
  5. Prueba el resultado.Cambia a Vista alumno para reproducir el curso con el Player.
  6. Exporta.Usa Exportar .p2lrn cuando quieras obtener el paquete portable.
Guía completa de StudioAbrir editor visual

3. Qué hay dentro de un .p2lrn

El paquete final contiene el manifiesto, el grafo del curso y los recursos necesarios. El workspace de autoría del Toolkit es otra cosa: conserva p2lrn.project.json y los archivos fuente para reconstruir el paquete.

course.p2lrn
course.p2lrn
├─ META-INF/manifest.json
├─ content/graph.json
├─ assets/...
├─ packages/...
└─ multipart/...

4. Crear por código: instala el Toolkit

Esta parte pertenece a la ruta técnica de autoría. Si estás usando Studio visual, no necesitas ejecutar estos comandos para crear el curso.

Terminal
npm install @p2lrn/toolkit@0.5.0-alpha.10

5. Crear el workspace por TypeScript

TypeScript
import {P2LRNAuthoringWorkspace} from '@p2lrn/toolkit/authoring';

const workspace = P2LRNAuthoringWorkspace.create('./workspace', {
  title: 'Curso de seguridad básica',
  language: 'es',
  description: 'Curso P2LRN creado desde cero.',
});

6. Añadir estructura y recursos

addFile() crea el recurso y su actividad asociada. El resultado devuelve las claves reales para usarlas después en progresión u otras reglas.

TypeScript
workspace.addUnit({
  key: 'unidad-1',
  title: 'Unidad 1 · Fundamentos',
});

const intro = workspace.addFile({
  source: './material/intro.html',
  key: 'intro',
  title: 'Introducción',
  parent: 'unidad-1',
  mediaType: 'text/html',
});

workspace.setProgression(intro.activityKey, {
  required: true,
  gateFollowing: true,
  completionRequirement: 'viewed',
});

7. Leer un documento antes de añadirlo

workspace.reader() utiliza el Reader documental del Toolkit. Devuelve la estructura extraída y deja que tu aplicación decida qué parte se convierte en contenido del curso.

TypeScript
const document = await workspace.reader('./material/tema-1.docx');

console.log(document.metadata);
console.log(document.blocks);
console.log(document.tables);
console.log(document.warnings);

8. Construir y validar

TypeScript + CLI
workspace.build('./curso.p2lrn', {
  strictProfiles: true,
});

# después del build
p2lrn-validate curso.p2lrn
p2lrn-inspect curso.p2lrn
p2lrn-reader curso.p2lrn
