START / 5 MIN

Quickstart desde cero

Este recorrido no presupone que ya tengas un paquete. Usa el Toolkit real para crear un curso mínimo, lo valida, lo sirve por HTTP y lo abre con el Player publicado.

0. Requisitos

  • Node.js 22 o superior para @p2lrn/toolkit.
  • Un directorio vacío para el ejemplo.
  • Un navegador moderno.
Versiones

El repositorio alinea Toolkit, Player y H5P libraries en 0.5.0-alpha.10. P2LRN sigue siendo alpha.

1. Instala el Toolkit

Terminal
mkdir p2lrn-quickstart
cd p2lrn-quickstart
npm init -y
npm install @p2lrn/toolkit@0.5.0-alpha.10

2. Crea un proyecto real

Terminal
npx p2lrn-create init ./workspace --title "Curso mínimo" --language es
npx p2lrn-create add-unit ./workspace --key unidad-1 --title "Unidad 1"

Crea ahora contenido.html junto al proyecto:

contenido.html
<!doctype html>
<html lang="es">
<meta charset="utf-8">
<title>Hola P2LRN</title>
<body>
  <h1>Hola P2LRN</h1>
  <p>Este contenido forma parte del paquete del Quickstart.</p>
</body>
</html>
Terminal
npx p2lrn-create add-file ./workspace ./contenido.html --key introduccion --title "Introducción" --parent unidad-1 --media-type text/html
npx p2lrn-create build ./workspace ./course.p2lrn --strict-profiles
npx p2lrn-validate ./course.p2lrn
npx p2lrn-inspect ./course.p2lrn

3. Monta el Player

Crea index.html en el mismo directorio que course.p2lrn.

index.html
<!doctype html>
<html lang="es">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>P2LRN Quickstart</title>

<script src="https://p2lrn.netlify.app/player/current/dist/p2lrn.js"></script>

<p2lrn-player id="course" src="./course.p2lrn"></p2lrn-player>

<script>
  const player = document.querySelector('#course');

  player.addEventListener('p2lrn:ready', (event) => {
    console.log('READY', event.detail);
  });

  player.addEventListener('p2lrn:rendered', (event) => {
    console.log('RENDERED', event.detail);
  });

  player.addEventListener('p2lrn:error', (event) => {
    console.error('P2LRN ERROR', event.detail);
  });
</script>
</html>

4. Sírvelo por HTTP

Terminal
npx --yes serve .

Abre la URL local que muestre serve. No abras index.html mediante file://.

5. Criterio de éxito

  • BUILDp2lrn-create build genera course.p2lrn.
  • VALIDATEp2lrn-validate termina sin error.
  • READYSe recibe p2lrn:ready.
  • RENDERSe recibe p2lrn:rendered.
  • ERRORNo aparece p2lrn:error.

6. Qué has construido

p2lrn-quickstart/
p2lrn-quickstart/
├─ workspace/
│  ├─ p2lrn.project.json
│  └─ ...
├─ contenido.html
├─ course.p2lrn
├─ index.html
├─ package.json
└─ node_modules/

El workspace es editable; course.p2lrn es el artefacto portable. Continúa con Crear paquetes para autoría más completa.
