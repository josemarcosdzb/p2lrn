Antes de crear tu primer curso

Empieza desde Studio con una lección y una actividad. La instalación web y la configuración del LMS se explican aparte, en la documentación para desarrolladores.

Crea y comprueba un curso breve

Empieza con un concepto y una pregunta. Añade más contenido cuando hayas comprobado la primera actividad como alumno.

  1. Escribe un título que identifique el tema del curso.
  2. Añade una lección y redacta la explicación.
  3. Inserta una pregunta, escribe las opciones y marca la respuesta correcta.
  4. Resuelve la pregunta en la vista del alumno y revisa la corrección.
  5. Guarda el trabajo y exporta el paquete para comprobarlo en Player.
