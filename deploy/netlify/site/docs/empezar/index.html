INICIO / ORIENTACIÓN

Elige tu recorrido

No necesitas leer toda la documentación en orden. Empieza por la tarea que quieres resolver y sigue ese recorrido hasta completarla.

1. Quiero crear un curso

SIN PROGRAMAR EL PAQUETE

Crear con Studio

Usa el editor visual para construir la estructura, añadir contenido, previsualizar y exportar.

AUTOMATIZACIÓN O CÓDIGO

Crear con Toolkit

Usa la API y el CLI para generar, transformar o validar cursos dentro de un proceso técnico.

2. Quiero reproducir un curso en mi aplicación

Primero elige cómo incorporas el Player al proyecto. Son recorridos alternativos: escoge uno y continúa dentro de él.

PROYECTO CON DEPENDENCIAS

Instalación con NPM

La aplicación instala el paquete y lo importa desde su código.

HTML Y NAVEGADOR

Instalación mediante CDN

La página carga el archivo web publicado y utiliza el componente directamente.

No combines las dos instrucciones.

La guía NPM contiene únicamente pasos de NPM. La guía CDN contiene únicamente pasos de CDN. Ambas terminan en el mismo componente Player.

3. Quiero integrar el editor Studio en mi aplicación

El uso del editor y su instalación son cosas distintas. Aprende primero cómo funciona Studio y utiliza después una sola guía de integración.

DEPENDENCIA DEL PROYECTO

Studio con NPM

Instalación, servicios de guardado, Reader, importación, API y eventos.

CARGADOR WEB

Studio mediante CDN

Carga en HTML, curso inicial y conexión con los servicios de tu plataforma.

4. Quiero conectar progreso, usuarios o recursos privados

Instala primero el Player, comprueba que el paquete se reproduce y después continúa con Integración. Host Adapter enlaza el Player con el estado y los servicios que pertenecen a tu plataforma.

5. Si todavía no sabes qué pieza necesitas

El mapa de componentes explica la frontera entre Studio, Toolkit, Player, Reader, Multipart y Host Adapter. Después, Conceptos explica cómo encajan paquete, grafo, perfiles, presentaciones y entornos de ejecución.
