INICIO / ELEGIR RUTA

Elige tu recorrido

P2LRN separa la creación del curso de la forma en que Player o Studio se incorporan a una aplicación. Elige primero el objetivo y después sigue una sola guía de instalación.

1. Crear un curso

EDITOR VISUAL

Studio

Crea, organiza, edita, previsualiza y exporta cursos desde una interfaz visual.

AUTORÍA POR CÓDIGO

Toolkit / CLI

Crea y procesa cursos desde Node.js, TypeScript o la línea de comandos.

2. Incorporar P2LRN a una aplicación

PROYECTO CON DEPENDENCIAS

NPM

Instala Player, Studio o Toolkit como paquetes del proyecto.

HTML Y NAVEGADOR

CDN

Carga Player o Studio desde sus archivos web publicados.

3. Integrar Studio

La integración de Studio tiene una guía independiente para cada recorrido. Elige la que corresponda a tu aplicación y permanece en esa guía hasta completar el montaje.

DEPENDENCIA DEL PROYECTO

Studio con NPM

Instalación, importación, servicios de servidor, API y eventos.

CARGADOR WEB

Studio mediante CDN

Carga directa en HTML, curso inicial y servicios de guardado e importación.

4. Funciones que pueden necesitar servidor

La edición básica y la descarga de un curso pueden realizarse en el navegador. El guardado centralizado, Reader y la conversión de paquetes externos necesitan servicios proporcionados por la plataforma que integra P2LRN.
