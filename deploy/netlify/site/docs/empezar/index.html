Quickstart

Del repositorio a un paquete reproducido en navegador, con una comprobación mínima de que el Player está funcionando.

Qué vas a conseguir

Al terminar tendrás un .p2lrn servido por HTTP, un <p2lrn-player> montado y dos listeners para saber si el runtime está listo o ha fallado.

Prerrequisitos

  • Node.js 22 o superior si vas a usar npm/Toolkit.
  • Un paquete .p2lrn accesible mediante HTTP.
  • Un servidor web local o una aplicación que pueda servir HTML y el paquete.

1. Carga el Player

HTML
<script src="https://p2lrn.netlify.app/player/current/dist/p2lrn.js"></script>

<p2lrn-player id="course" src="/courses/course.p2lrn"></p2lrn-player>

2. Comprueba eventos

JavaScript
const player = document.querySelector('#course');

player.addEventListener('p2lrn:ready', () => {
  console.log('P2LRN ready');
});

player.addEventListener('p2lrn:error', (event) => {
  console.error(event.detail);
});

3. Si el paquete está en otro dominio

El servidor que entrega el .p2lrn debe permitir CORS para el origen de tu aplicación. Si usas media seekable o lecturas por rangos, el servidor también debe responder correctamente a las peticiones HTTP necesarias.

Cómo comprobar que funciona

  • READYSe dispara p2lrn:ready.
  • NETWORKEl paquete responde 200/206 según el recurso solicitado.
  • NO ERRORNo aparece p2lrn:error en la integración mínima.
