EMPEZAR / ORIENTACIÓN

Antes de empezar

Empieza definiendo qué quieres hacer y dónde vas a utilizar P2LRN. Después pasarás por instalación —cuando corresponda— y sólo entonces por creación o reproducción.

1. Qué quieres hacer

Crear un curso visualmente

Puedes usar el Studio alojado directamente o instalar Studio dentro de tu aplicación.

Crear cursos por código

Necesitas Toolkit mediante NPM.

Reproducir un curso

Necesitas Player mediante NPM o CDN.

Conectar progreso y usuarios

Primero prepara Player y después configura Host Adapter.

2. Si vas a trabajar dentro de un proyecto, instala primero

La siguiente página te permite elegir una única ruta de instalación. No se crea ningún curso todavía: primero dejamos disponible el componente que vas a utilizar.

Ir a instalación

3. Si usarás el Studio alojado

No hay instalación local. Puedes abrir P2LRN Studio y seguir directamente la guía de creación visual.

4. No mezcles recorridos

NPM y CDN son alternativas para cargar los componentes del navegador. Studio visual y Toolkit son alternativas de autoría. Elige el recorrido que corresponda a tu caso y sigue sus pasos hasta obtener el resultado esperado.
