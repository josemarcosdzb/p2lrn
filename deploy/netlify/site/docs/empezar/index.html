INICIO / ELEGIR RUTA

Primero decide qué quieres hacer

P2LRN tiene dos decisiones independientes: cómo creas el curso y cómo cargas las herramientas en tu aplicación. Separarlas evita mezclar NPM y CDN en un mismo ejemplo.

1. Crear un curso

EDITOR VISUAL

Studio

Crea, edita, previsualiza y exporta cursos sin escribir manifest o graph a mano.

 POR CÓDIGO

Toolkit / CLI

Autoría programática y automatización desde Node/TypeScript.

2. Integrar en una aplicación

PROYECTO CON DEPENDENCIAS

NPM

Instala Player o Studio como paquetes de tu proyecto y usa importaciones JavaScript.

 HTML DIRECTO

CDN

Carga Player o Studio mediante sus cargadores publicados, sin instalar esos paquetes en el navegador.

3. Combinaciones válidas

Studio + NPM

Editor visual integrado como dependencia de tu aplicación.

Studio + CDN

Editor visual cargado desde el cargador publicado.

Toolkit + Player NPM

Generación por código y reproducción dentro de una aplicación con dependencias.

Toolkit + Player CDN

Generación por código y reproducción desde HTML directo.

4. Regla que evita la contradicción anterior

NPM y CDN son alternativas para cargar una misma pieza en el navegador.

No instales el Player por NPM y después cambies a su cargador CDN dentro del mismo recorrido. Si Studio llega por CDN, utiliza su cargador; ese cargador carga automáticamente el Player de su mismo canal.

5. Persistencia e importadores

Crear, editar, previsualizar y descargar con Studio puede hacerse sin servidor. Guardar en servidor, usar Reader o importar paquetes educativos sí requiere endpoints del Host. Consulta Studio para la matriz exacta.
