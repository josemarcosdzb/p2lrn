EMPEZAR / ORIENTACIÓN

Antes de empezar

Conoce primero las piezas de P2LRN y la estructura del paquete. Después puedes hacer una primera integración sencilla con CDN y, a continuación, preparar la instalación que vayas a mantener en tu proyecto.

1. Qué quieres hacer

Crear un curso visualmente

Puedes usar el Studio alojado directamente o integrar Studio dentro de tu aplicación.

Crear cursos por código

Toolkit ofrece la API y CLI de autoría y procesamiento.

Reproducir un curso

Player abre y ejecuta paquetes .p2lrn en el navegador.

Conectar progreso y usuarios

Player se conecta a tu plataforma mediante Host Adapter cuando llegues a la fase de integración.

Enviar un curso sin LMS

Studio puede preparar una entrega offline que el alumno abre con doble clic y devuelve como .p2lrn-result.

2. Entiende el modelo antes de probarlo

No necesitas memorizar la especificación. Antes de crear o integrar basta con conocer qué componentes existen, qué significan los conceptos principales y qué contiene realmente un paquete.

Mapa de componentes

Qué responsabilidad tiene Studio, Toolkit, Player y la plataforma anfitriona.

Conceptos fundamentales

Paquete, manifiesto, grafo, recurso, representación, perfil y renderer.

Formato P2LRN

Qué hay dentro del archivo .p2lrn, cómo se relacionan sus partes y qué datos permanecen fuera.

3. Haz una primera integración sencilla

La ruta más directa para comprobar cómo se integra el Player es cargarlo desde CDN. La guía Empezar fácil utiliza un paquete de ejemplo y un HTML pequeño para que puedas ver el resultado antes de configurar una instalación completa.

Empezar fácil con CDN

4. Después prepara tu proyecto

Cuando ya has visto la integración básica, continúa con Instalación. Ahí tienes primero la integración mediante CDN y después la instalación con NPM, además de las guías específicas de Studio.

5. Si usarás el Studio alojado

No necesitas una instalación local para crear contenido. Puedes abrir P2LRN Studio y seguir directamente la guía de creación visual.

6. Si quieres entregarlo sin LMS

Después de crear y comprobar el curso puedes generar una entrega autorreproducible para Windows o un ZIP portable. La guía Entrega offline explica el recorrido completo profesor → alumno → .p2lrn-result → profesor, además de métricas y límites de seguridad.

Ver entrega offline

7. Cuándo leer Progresión y Métricas

Cuando el curso ya se puede crear, reproducir e integrar, el bloque Seguimiento reúne Progresión y Métricas y analítica. Ese bloque pertenece a una fase posterior, cuando necesitas definir finalización, aprobación, estado, notas e informes.
