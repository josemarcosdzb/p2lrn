SEGUIMIENTO / ANALYTICS

P2LRN Analytics

Un panel embebible para convertir los datos del Host y los eventos de P2LRN en una vista clara de alumnos, cursos, progreso, actividad, intentos y notas.

Abrir demoUsar CDNUsar NPM

1. Qué muestra

Resumen

Alumnos, cursos, matrículas, finalización, nota oficial media, tiempo activo y señales que requieren revisión.

Alumnos

Progreso, cursos, intentos, tiempo activo, última actividad y detalle por curso.

Cursos

Alumnos iniciados y completados, progreso medio, nota media, aprobados, actividad e intentos.

Notas

Distribución y libro de calificaciones, diferenciando expresamente notas autoritativas de puntuaciones informativas.

Actividad

Learning events normalizados, categorías, evolución reciente e interacciones recibidas desde Player y Host.

Señales

Reglas transparentes para inactividad, progreso bajo, nota baja e intentos fallidos repetidos.

2. Frontera de datos

Analytics no guarda alumnos, notas ni historial dentro de un archivo .p2lrn. El Host conserva identidad, permisos y persistencia, y entrega al panel un dataset ya autorizado para el usuario que lo está consultando.

Una puntuación del navegador no es una nota oficial.

Analytics sólo incluye una calificación en los promedios oficiales cuando el Host la entrega con authoritative: true. Progreso, actividad, intentos y puntuaciones informativas permanecen visibles como evidencia separada.

3. CDN

Carga el bundle clásico una vez y añade el Web Component. src debe apuntar a un endpoint del Host que devuelva el dataset autorizado.

HTML
<script src="https://p2lrn.netlify.app/analytics/current/dist/p2lrn-analytics.js"></script>
<p2lrn-analytics src="/api/p2lrn/analytics/snapshot"></p2lrn-analytics>

Para fijar una prerelease concreta, sustituye current por 0.5.0-alpha.11.

4. NPM

En proyectos con dependencias gestionadas, instala Analytics y registra el componente desde tu aplicación.

Terminal
npm install @p2lrn/analytics@0.5.0-alpha.11
JavaScript / TypeScript
import '@p2lrn/analytics';

const panel = document.querySelector('p2lrn-analytics');
panel.src = '/api/p2lrn/analytics/snapshot';
await panel.refresh();

5. Dataset del Host

El contrato utiliza seis colecciones. Los identificadores son opacos para Analytics y su significado pertenece a tu plataforma.

learners

Identidad visible autorizada: id, nombre, correo opcional, grupo, cohorte y etiquetas.

courses

Curso, código y metadatos de presentación.

enrollments

Relación alumno–curso y progreso global cuando el Host ya lo calcula.

attempts

Intentos, estado, progreso, timestamps y tiempo activo.

grades

Calificaciones con valor, máximo, aprobado y la bandera authoritative. Para medias globales de curso, omite entityId o usa el mismo courseId; una nota de actividad con otro entityId aparece en el libro, pero no altera la media del curso.

events

Eventos P2LRN normalizados con alumno, curso, intento, categoría, contexto y payload.

JSON · ejemplo reducido
{
  "learners": [{"id":"u-1","name":"Ana"}],
  "courses": [{"id":"c-1","title":"Matemáticas"}],
  "enrollments": [{"learnerId":"u-1","courseId":"c-1","progress":0.72}],
  "attempts": [{"id":"a-1","learnerId":"u-1","courseId":"c-1","activeTimeMs":840000}],
  "grades": [{"learnerId":"u-1","courseId":"c-1","value":82,"maxValue":100,"authoritative":true}],
  "events": [{"type":"p2lrn:progress","timestamp":"2026-10-28T10:00:00Z","learnerId":"u-1","courseId":"c-1"}]
}

6. DataSource HTTP

Si prefieres no usar el atributo src, crea un datasource. El helper usa credenciales del mismo origen por defecto y transmite los filtros del panel como parámetros de consulta.

JavaScript / TypeScript
import {
  createHttpAnalyticsDataSource
} from '@p2lrn/analytics';

const panel = document.querySelector('p2lrn-analytics');
panel.dataSource = createHttpAnalyticsDataSource({
  url: '/api/p2lrn/analytics/snapshot'
});
await panel.refresh();

El endpoint debe aplicar autenticación y autorización antes de devolver alumnos o notas. Analytics no eleva permisos ni descubre usuarios por su cuenta.

7. Eventos y tiempo activo

Los eventos de Player pueden convertirse a learning-event/1. Analytics entiende categorías de ciclo de vida, navegación, evaluación, progreso, finalización, atención, medios, interoperabilidad, colaboración y error.

Para tiempo activo, el panel acepta activeTimeMs del intento y eventos p2lrn:active-time/p2lrn:attention. Cuando recibe valores acumulados del mismo intento conserva el mayor, evitando sumar dos veces el mismo intervalo.

8. Señales de seguimiento

Las señales no son un diagnóstico ni una predicción automática. Son reglas visibles que el Host puede ajustar.

Inactividad

Por defecto, 14 días sin actividad en un curso no completado.

Progreso bajo

Por defecto, menos del 35 % cuando el alumno ya ha empezado.

Nota baja

Por defecto, menos del 60 % en una nota autoritativa.

Intentos fallidos

Por defecto, dos o más intentos con estado failed.

El panel muestra el motivo de cada señal para que una persona pueda interpretarla y decidir qué hacer.

9. API del componente

data

Asigna directamente un dataset en memoria.

dataSource

Objeto con load(filters) para conectar el Host.

refresh()

Recarga la fuente y vuelve a calcular las vistas.

setView(view)

Cambia entre overview, learners, courses, grades y activity.

selectLearner(id) / selectCourse(id)

Abren el detalle correspondiente.

exportCsv(kind)

Exporta alumnos, cursos o notas en CSV.

page-size / pageSize

Número de filas por página para alumnos y libro de notas. Predeterminado: 50; rango: 10–200.

10. API de agregación

También puedes usar Analytics sin montar el panel.

JavaScript / TypeScript
import {
  normalizeAnalyticsDataset,
  computeAnalyticsSnapshot,
  filterAnalyticsDataset,
  analyticsToCsv
} from '@p2lrn/analytics';

const dataset = normalizeAnalyticsDataset(raw);
const snapshot = computeAnalyticsSnapshot(dataset);
const csv = analyticsToCsv(snapshot, {kind:'courses'});

11. Eventos del Web Component

p2lrn-analytics-ready

El componente se ha registrado y está listo.

p2lrn-analytics-refresh

Una carga de datos terminó correctamente.

p2lrn-analytics-select

Se seleccionó un alumno o curso.

p2lrn-analytics-export

Se generó un CSV.

p2lrn-analytics-error

La carga de la fuente produjo un error.

12. Privacidad y seguridad

  • No incluyas alumnos, correos, notas o historial dentro de un paquete .p2lrn.
  • Autoriza el endpoint de Analytics según institución, rol, curso y alcance del usuario conectado.
  • No confíes en learnerId o courseId enviados por el navegador para decidir permisos.
  • El CSV contiene los datos visibles en el panel; su descarga debe respetar la política de tu plataforma.
  • Las puntuaciones informativas del navegador no deben convertirse silenciosamente en notas oficiales.
