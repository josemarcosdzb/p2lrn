Anatomía práctica

Un paquete final reúne manifiesto, entidades del grafo, representaciones y recursos. El proyecto editable añade la información necesaria para round-trip y reconstrucción.

conceptual package map
course.p2lrn
├─ manifest
│  ├─ format / version
│  ├─ profiles
│  └─ contentRoot
├─ graph
│  ├─ course
│  ├─ units
│  ├─ activities
│  └─ relations
├─ resources
│  └─ embedded / referenced payloads
└─ integrity
   └─ digests / verified paths

Grafo y puntos de entrada (entrypoints)

Las unidades, actividades y relaciones forman un grafo. Los entrypoints definen por dónde comienza la experiencia si el host no solicita un nodo específico.

Perfiles

Los perfiles declaran capacidades o reglas especializadas. El paquete puede exigir un perfil cuando su interpretación correcta depende de él, o marcarlo como opcional cuando aporta comportamiento adicional.

Integridad y reconstrucción

Si cambia un recurso o JSON que forma parte de la raíz de contenido, deben actualizarse digests y contentRoot. Los payloads externos opacos que deben preservarse se mantienen byte a byte cuando el contrato así lo exige.

No hagas esto

No modifiques archivos dentro del paquete sin recalcular la integridad. Usa Toolkit para abrir, editar y reconstruir.

Proyecto de autoría

p2lrn.project.json conserva IDs portables, orden del grafo, entrypoints, perfiles y metadatos necesarios para abrir un paquete como workspace y volver a construirlo sin pérdida lógica.

Autoría y derechos del contenido

El curso puede conservar cuatro datos portables mediante la extensión https://p2lrn.org/ext/course-rights/1. Son metadatos del contenido, no de la cuenta del usuario ni del sistema que creó el paquete.

author

Autor del contenido. Persona u organización responsable del contenido.

createdAt

Fecha de creación. Día original de creación en formato AAAA-MM-DD.

license

Licencia · Condiciones de uso y distribución. Texto o identificador de licencia que define cómo puede utilizarse o distribuirse el contenido.

copyrightHolder

Derechos de autor · Titular de los derechos. Persona u organización titular de los derechos.

No se añaden campos de IA ni de herramienta creadora.

El esquema sólo admite estos cuatro campos. Los cursos nuevos pueden recibir su fecha de creación al crearse; un curso importado conserva su valor existente o su ausencia.

Llevar la especificación a un paquete real

La guía Crear paquetes muestra el flujo completo desde un workspace vacío hasta build, validación, multipart y reproducción en el visor real.

Qué pertenece al host

  • Identidad y autenticación.
  • Roles, permisos y matrícula.
  • Credenciales y secretos.
  • Persistencia durable del progreso propia de la plataforma.
  • Telemetría, facturación y lógica comercial.
