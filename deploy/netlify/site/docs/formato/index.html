FORMATO

Formato P2LRN

La especificación del paquete portable: identidad, estructura, integridad, proyecto de autoría y límites entre contenido y plataforma.

Qué define el formato

P2LRN define una unidad portable de contenido formativo. Un paquete contiene la estructura del curso, activos, manifiestos y referencias necesarias para reconstruir y reproducir el contenido sin depender de la base de datos de una plataforma concreta.

$ p2lrn-inspect course.p2lrn
format          P2LRN
extension       .p2lrn
namespace       https://p2lrn.org/
authoring       p2lrn.project.json
events          p2lrn:*
virtual-sw      /__p2lrn__/v1/

Integridad del paquete

La integridad se basa en manifiestos, digests y contentRoot. El objetivo es poder comprobar que los recursos que se están abriendo corresponden al paquete que fue construido.

Regla práctica

Si un archivo o JSON cambia durante una reconstrucción, deben actualizarse los manifiestos y hashes asociados. Los payloads opacos externos que deben preservarse se mantienen byte a byte cuando el contrato lo exige.

Proyecto de autoría

El workspace editable utiliza p2lrn.project.json. Conserva IDs portables, orden del grafo, entrypoints, perfiles y payloads necesarios para poder abrir y volver a construir un paquete sin pérdida lógica.

Qué no pertenece al paquete

  • Identidad y autenticación de usuarios.
  • Permisos, roles y matrícula.
  • Credenciales y secretos.
  • Persistencia durable de progreso de una plataforma concreta.
  • Telemetría, facturación o lógica comercial del host.
