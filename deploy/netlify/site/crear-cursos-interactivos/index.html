CREAR / CURSOS INTERACTIVOS

Crea cursos interactivos sin empezar por el código.

P2LRN Studio reúne en un editor visual las lecciones, las actividades y la vista del alumno. Puedes preparar un curso, comprobarlo y exportarlo como un paquete .p2lrn para reproducirlo con Player.

DEL EDITOR AL CURSO

Cómo funciona, paso a paso

  1. 01

    Crea el curso y su estructura

    En Studio, pulsa «Crear curso» y organiza las unidades y lecciones que verá el alumno.

  2. 02

    Añade contenido y actividades

    Edita texto e imágenes desde la interfaz y utiliza «Añadir contenido» para incorporar evaluaciones y juegos compatibles.

  3. 03

    Comprueba la vista alumno

    Alterna entre la edición y «Vista alumno» para revisar el resultado antes de distribuirlo.

  4. 04

    Exporta el paquete

    Descarga el archivo .p2lrn y ábrelo con Player o intégralo en el entorno de destino.

PREGUNTA HABITUAL

¿Necesito instalar un LMS para crear el curso?

No. Puedes crear y exportar un paquete desde Studio. Si deseas matriculaciones, servicios de identidad u otras funciones de una plataforma, necesitarás integrarlo con el sistema correspondiente.
