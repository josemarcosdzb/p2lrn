Qué estás viendo

El visor no interpreta el paquete por su cuenta. El elemento <p2lrn-player> descarga y verifica el .p2lrn, selecciona el renderer apropiado y emite eventos de runtime.

Usarlo en tu web

HTML
<script src="https://p2lrn.netlify.app/player/current/dist/p2lrn.js"></script>
<p2lrn-player src="/courses/course.p2lrn"></p2lrn-player>
