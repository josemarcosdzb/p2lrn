01 · FORMATOS

Cualquier formato, dentro del paquete.

P2LRN integra dentro de un mismo paquete cualquier formato compatible —SCORM, H5P, cmi5, xAPI, QTI, HTML y otros— junto con sus recursos, estructura y metadatos. El mismo paquete puede utilizarse en web, LMS, aplicaciones y otros entornos sin tener que rehacer la integración para cada formato.

1

PACKAGE

El archivo .p2lrn conserva el curso y los formatos incorporados como parte de un único paquete portable.

2

RUNTIME

El visor identifica cada formato y carga el runtime necesario desde el CDN de P2LRN o desde los paquetes NPM instalados en la aplicación.

3

RENDER

Player reproduce cada contenido en el entorno adecuado y lo presenta dentro del curso como una experiencia unificada.

Una integraciónUn solo Player para web, LMS, aplicaciones y otros entornos. El visor resuelve desde CDN o NPM los runtimes que necesita para leer cada formato, reduciendo la integración a un flujo común y sin complicaciones innecesarias.

03 · CAPACIDADES

Más interacción sin perder portabilidad.

Las capacidades conectadas se apoyan en el mismo paquete y el mismo Player. El host añade servicios cuando existen; el contenido sigue siendo portable cuando no están disponibles.
