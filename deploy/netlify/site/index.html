FORMATO · PLAYER · TOOLKIT

El contenido formativo no debería depender de una plataforma.

P2LRN reúne estructura, recursos y contenido de aprendizaje en un paquete portable y verificable. El Player lo ejecuta en navegador. El Toolkit lo crea, valida, abre y transforma.

TOOLKIT DE AUTORÍA

Crear, abrir y reconstruir sin acoplar un editor a módulos internos.

La frontera pública de autoría es @p2lrn/toolkit/authoring. El Reader documental ligero forma parte del Toolkit.

Instalación
npm install @p2lrn/toolkit @p2lrn/player

import '@p2lrn/player';
Authoring API
import {P2LRNAuthoringWorkspace} from '@p2lrn/toolkit/authoring';

const workspace = P2LRNAuthoringWorkspace.open('course.p2lrn', './workspace');
workspace.setCourseMetadata({ title: 'Course title', incrementRevision: true });
workspace.addUnit({ key: 'unit-1', title: 'Unit 1' });
workspace.build('course-updated.p2lrn', { strictProfiles: true });

INICIO RÁPIDO

Instala localmente o carga desde el CDN.

Para flujos Node se instalan Toolkit y Player. Para reproducción directa en navegador se puede usar el loader CDN y el Web Component.

Paquetes Node

@p2lrn/toolkit y @p2lrn/player

Librerías H5P

@p2lrn/h5p-libraries cuando el contenido depende de librerías externas compartidas.

CONTRATO DEL PLAYER

Superficie pequeña, responsabilidades explícitas.

src

URL obligatoria del paquete para reproducir.

node

Nodo opcional del grafo. Si se omite se usa el entrypoint principal.

renderer

Selección opcional y estricta de renderer.

runtime-base-url

Origen alternativo para un runtime aislado de confianza.

Los eventos DOM usan el namespace p2lrn:*, incluyendo ready, rendered, actividad, progreso, estado, puntuación, finalización y error.

Límite del host. Identidad, permisos, matrícula, URLs protegidas, persistencia durable y telemetría pertenecen a la plataforma anfitriona, no al paquete.

COMPATIBILIDAD

Leer lo anterior sin convertirlo en la nueva autoridad.

Los paquetes P2RLN Alpha15, identificadores históricos, p2rln.project.json, <p2rln-player>, eventos antiguos y rutas previas de Service Worker se mantienen como entrada legacy.

Preservar no significa ejecutar. P2LRN distingue autoría, round-trip, lectura, preservación y deliver. Un formato externo no se declara ejecutable si no existe un runtime real que lo soporte.

LÍMITES DEL CDN

Runtime genérico, no cursos de usuarios.

Este CDN distribuye el Player, los hosts de runtime aislados y el corpus reutilizable de librerías H5P. Los cursos y los datos de usuario permanecen fuera de esta distribución.
