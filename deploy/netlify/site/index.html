01 · FORMATOS

Paquetes .p2lrn para web y LMS compatibles

P2LRN integra dentro de un mismo paquete cualquier formato compatible —SCORM, H5P, cmi5, xAPI, QTI, HTML y otros— junto con sus recursos, estructura y metadatos. El mismo paquete puede utilizarse en web, LMS, aplicaciones y otros entornos sin tener que rehacer la integración para cada formato.

1

PAQUETE

El archivo .p2lrn conserva el curso y los formatos incorporados como parte de un único paquete portable.

2

COMPATIBILIDAD

Player identifica el tipo de contenido y utiliza la capacidad adecuada para reproducirlo dentro del curso.

3

EXPERIENCIA

El alumno accede a las lecciones y actividades desde una experiencia unificada, aunque el curso combine distintos formatos.

Una integraciónUn solo Player para web, LMS y aplicaciones compatibles. Los detalles técnicos de instalación quedan en la documentación para que la experiencia principal siga siendo clara.
