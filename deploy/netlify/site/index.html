Release actual 0.5.0-alpha.10
01

EL MODELO

Un paquete. Un contrato. Distintos runtimes.

P2LRN concentra estructura, activos, manifiestos y contenido de aprendizaje en un paquete .p2lrn. La plataforma anfitriona conserva identidad, permisos, matrícula, persistencia y recursos protegidos.

A PACKAGE .p2lrn
B VERIFY manifest · digests · contentRoot
C RENDER Player · H5P · SCORM · otros runtimes
02

PLAYER WEB

Montarlo no debería ser la parte difícil.

La distribución del CDN registra el Web Component canónico y carga renderers y hosts especializados cuando hacen falta.

03

CONTRATO DEL PLAYER

Pocas propiedades. Sin esconder responsabilidades.

src

URL del paquete P2LRN. Es la única propiedad necesaria para iniciar la reproducción.

required
node

Nodo concreto del grafo. Si se omite, el Player usa el entrypoint principal del paquete.

optional
renderer

Selección estricta de renderer cuando la integración necesita fijarlo.

optional
runtime-base-url

Permite sustituir el runtime estático inferido por otro origen de confianza.

optional
04

TOOLKIT

Crear, abrir, validar, migrar y reconstruir.

El Toolkit contiene Reader, Creator, validación, autoría tipada, conversión, repack, delta y herramientas CLI. El Reader documental ligero vive en @p2lrn/toolkit/document-reader.

$ npm install @p2lrn/toolkit @p2lrn/player
p2lrn-validate p2lrn-reader p2lrn-document-reader p2lrn-create p2lrn-convert p2lrn-repack p2lrn-inspect p2lrn-delta p2lrn-trust

5.2

Compatibilidad

Los paquetes P2RLN Alpha15, identificadores históricos, p2rln.project.json, <p2rln-player>, eventos antiguos y rutas previas de Service Worker siguen siendo entradas legacy legibles.

Preservar no significa ejecutar. P2LRN distingue autoría, round-trip, lectura, preservación y deliver. Un formato externo no se declara ejecutable si no existe un runtime real que lo soporte.

5.4

Límite del CDN

Este despliegue sirve el Player, los hosts de runtime y el corpus reutilizable de librerías H5P. Los paquetes de cursos y los datos de usuario permanecen fuera del CDN.
