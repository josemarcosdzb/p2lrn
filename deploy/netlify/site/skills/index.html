Descargar las SkillsGuía de instalación

La Skill utiliza Toolkit oficial para crear, importar, editar y validar cuando está instalado y autorizado. Cuando el entorno no dispone de las herramientas completas, permite crear cursos sencillos. CÓMO FUNCIONA

De una instrucción a un curso descargable

  1. 01

    Descarga la Skill

    Elige la versión que corresponda al asistente que utilizas.

  2. 02

    Instala y habilita la Skill

    La Skill necesita permiso para ejecutar su herramienta y guardar el curso generado. La disponibilidad depende de las capacidades de tu cuenta o entorno.

  3. 03

    Describe el contenido formativo

    Solicita un curso con unidades, lecciones, cuestionarios o juegos y el formato .p2lrn.

  4. 04

    Verifica y reproduce

    Exige un archivo real validado y pruébalo en el Player o en Studio.

EJEMPLO PRÁCTICO

Crear un curso educativo con IA y comprobar el archivo real

Imagina que necesitas un curso de seguridad digital para principiantes. Pide al asistente que prepare dos unidades, cuatro lecciones, preguntas de repaso y una actividad de relacionar conceptos. Define también el nivel, los objetivos y el idioma antes de solicitar el paquete.

Una respuesta escrita de la IA no es un curso descargable. El archivo .p2lrn debe generarse con herramientas de ejecución autorizadas, y debe superar las comprobaciones del Toolkit. Si el asistente carece de esas herramientas, puede preparar un borrador, pero no debe afirmar que ha creado el paquete.

Antes de entregarlo al alumno, comprueba la exactitud del contenido, las licencias de imágenes, el resultado de los cuestionarios y la accesibilidad. Abre el archivo en Studio y pruébalo en Player. Para trabajar con cursos que ya existen en tu ordenador, utiliza el conector MCP autorizado, no una Skill de creación nueva.

Preguntas frecuentes sobre las Skills P2LRN

¿Puedo crear cursos educativos gratis con IA?

El generador incluido no necesita una API de pago de P2LRN, pero la capacidad de ejecutar herramientas depende del asistente que utilices. Comprueba las condiciones de la licencia P2LRN antes de redistribuir.

¿La Skill incluye juegos 3D ejecutables?

Puede describir actividades compatibles en el paquete, pero no prueba por sí sola el renderizado 3D. Para esa comprobación usa el Player oficial.

¿Los ZIP están publicados en los catálogos oficiales?

Se ofrecen para descarga e instalación. La aprobación en los directorios de cada proveedor es un proceso independiente.
