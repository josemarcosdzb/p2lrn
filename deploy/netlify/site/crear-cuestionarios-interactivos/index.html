GUÍA PASO A PASO

Cuatro pasos para preparar una evaluación completa

  1. 01

    Define qué se evalúa

    Redacta varias preguntas relacionadas con el objetivo de la lección. Evita respuestas ambiguas y comprueba si necesitas una evaluación o una actividad de práctica.

  2. 02

    Crea el cuestionario

    En Studio abre una lección, añade una evaluación y configura las preguntas. Mantén separadas las instrucciones, las respuestas y el contenido didáctico.

  3. 03

    Revisa los resultados

    Comprueba cuándo aparecen las correcciones y las puntuaciones. Recorre todas las preguntas antes de finalizar para verificar que el alumno no recibe soluciones anticipadas.

  4. 04

    Prueba el curso real

    Exporta el paquete .p2lrn, ábrelo en Player y comprueba navegación, teclado y desplazamiento en móvil hasta la última pregunta.

PREGUNTA FRECUENTE

¿Necesito instalar un LMS para crear cuestionarios?

No. Puedes crearlos en Studio y reproducir el archivo con Player. Las notas académicas oficiales, las matrículas y la identidad requieren una integración autorizada con el LMS.
