P2LRN Analytics

Panel de analítica educativa para consultar alumnos, cursos, progreso, actividad e intentos. También puedes abrir directamente un archivo .p2lrn-result de una entrega offline.

La vista inicial utiliza datos de demostración. Pulsa “Abrir resultado” para cargar un .p2lrn-result. Las puntuaciones offline se muestran como informativas; sólo una fuente autorizada puede convertirlas en calificaciones oficiales.

Cómo interpretar esta demostración

El panel de esta página utiliza datos de ejemplo para mostrar cómo se presentan los cursos, el avance de los alumnos, los intentos y los resultados. No corresponde a un centro educativo real y no certifica calificaciones oficiales.

Si has preparado una entrega sin conexión con Studio y tienes su archivo .p2lrn-result, utiliza la opción Abrir resultado para consultarlo. Distingue el resultado recogido en esa entrega de cualquier calificación que deba registrar tu institución.

Para conectar Analytics con datos reales de una plataforma, revisa la documentación de integración de Analytics. La identidad, los permisos y el origen autorizado de los resultados corresponden a la plataforma que integra el panel.
