## CI / verification

- Current branch workflow: `P2LRN product CI`.
- The workflow now rebuilds Player **before** Editor E2E so the Editor cannot pass against stale runtime assets.
- Editor E2E requires QTI, cmi5, LTI and xAPI runtime files to be served from the freshly rebuilt Player distribution.
- Capability claims are gated so partial external profiles do not advertise global `deliver`.
- At the time this status file was written, the self-hosted workflow for current branch commits was still queued/pending and had not executed test steps.
