# P2RLN 0.6.1

P2RLN is an experimental portable learning graph and package format. This development snapshot is based on **P2RLN 0.6.1 / Core 0.4.0** and advances the first-party **Creator/Toolkit 0.4.0a15** and **Reading System 0.4.0a15** with the modular native runtime, alternative renderers, native activity composition and a versioned host-event contract.

This repository is the canonical upload of the reconciled Alpha 15 + H5P hardened source delivered on 2026-09-12. It includes the full source tree, tests, specifications, Web SDK source/distribution metadata and release evidence. Large real-corpus binaries are kept separate from the canonical source tree because they are test fixtures/artifacts rather than implementation source.

Core remains `0.4.0`; Toolkit/Reader and Web SDK are `0.4.0a15` / `0.4.0-alpha.15`.

See the full project documentation and specifications in this repository after the source import completes.
